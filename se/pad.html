PAD
问题分析图 PAD - Problem Analysis Diagram
日本日立公司于1973年提出
为常用高级程序设计语言的各种 控制语句 都提供了对应的图形符号
将 PAD 图转换为对应的高级语言程序非常容易
特点 Features
执行顺序：自上而下、自左向右
设计过程：结构化的程序结构
结构清晰、层次分明
既可表示程序逻辑，也可用于描绘数据结构
用 def 逐步详细描述，可支持自顶向下、逐步求精的设计方法
基本符号 Symbols
1. 顺序结构
2. 分支结构
3. 循环结构
4. 标号
5. 定义

观察者模式

Observer

概述
是一种订阅-发布的机制
角色：

观察者 Observer

被观察者/目标 Subject

通常一个目标和很多观察者关联 - 一对多的联动需求
一旦目标状态发生变化，将通知所有观察者，观察者据此做出响应
如：用户（观察者）关注了某个公众号（目标），一旦公众号发布了新文章（状态改变），所有关注它的用户都会自动收到通知
参考代码
目标 Subject：负责维护观察者列表，并提供添加、删除和通知观察者的方法
class Subject {
  constructor() {
    this.observers = []
  }

  add(obj) {
    this.observers.push(obj);
  }

  remove(obj) {
    this.observers = this.observers.filter(item => item != obj)
  }

  notify(msg) {
    this.observers.forEach(item => item.update(msg))
  }
}
观察者：负责定义收到通知后的更新行为
class Observer {
  constructor(name) {
    this.name = name
  }
  update(msg) {
    console.log(this.name + 'get' + msg);
  }
}
运用
let ob1 = new Observer('gl')
let ob2 = new Observer('sh')
let sub = new Subject()
//订阅
sub.add(ob1)
sub.add(ob2)
//发布
sub.notify('hi')

    this.observers.push(obj);
  }

  removeObserver(obj) {
    this.observers = this.observers.filter(item => item != obj)

  }
}
观察者：构造函数接受一个函数，定义自己的业务逻辑
class Observer {
  constructor(updateFn) {
    this.update = updateFn;
  }
}
运用
const btn = document.getElementById('btnAdd');
const display = document.getElementById('displayCount');
const log = document.getElementById('logInfo');

let count = 0;

const eventBus = new Subject();

// A subscribe：构造观察者A，指定A的业务逻辑，展示消息
const observerA = new Observer((data) => {
  display.innerText = data;
  console.log(data);
});
eventBus.addObserver(observerA);

// B subscribe：构造观察者B，指定B的业务逻辑，统计消息
const observerB = new Observer((data) => {
  log.innerText = `日志：数量刚刚变成了 ${data}，时间是 ${new Date().toLocaleTimeString()}`;
  console.log(data);
});
eventBus.addObserver(observerB);

// publish
btn.addEventListener('click', () => {
  count++;
  // 通知事件中心，事件中心会自动通知 A 和 B
  eventBus.notify(count);
});

class Observer {
  constructor(name) {
    this.el = document.querySelector(name)
  }
  update(str) {
    this.el.innerHTML = str
  }
}

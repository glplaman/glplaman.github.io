状态图

State Diagram
状态图是一种动态行为模型 Behavioral Model
它通过描绘状态、转换、事件和活动，来展示一个特定对象在响应外部事件时，其生命周期内的状态变迁逻辑
状态图主要由以下四个要素构成，它们共同定义了对象的行为逻辑：
状态 State
表示对象在生命周期中的某个稳定阶段，在此期间它会满足某些条件、执行某些活动或等待某些事件
圆角矩形
属性包括：

状态名称

状态变量；可选

状态表；可选

特殊状态：

初态：实心圆 ；只能有1个

终态：同心圆，内为实心圆 ；可以有多个；也可以没有

转换 Transition
带方向的箭头
表示对象从一个状态迁移到另一个状态的过程
遵循事件[监护条件]/动作 的格式

事件 (Event)：状态的转换通常由事件触发，并可能伴随着守卫条件的判定。只有当条件满足时，转换才会真正发生

监护条件 (Guard Condition)：一个布尔表达式，用方括号 [] 包裹。只有当事件发生且条件为真时，转换才会发生

动作 (Action)：在转换过程中执行的原子性操作，写在斜杠 / 之后，如生成发货单、发送邮件通知

概念

Concept
软件工程用来解决由于软件变得太复杂且质量得不到保障而引发的软件危机
软件 Software
软件 = 程序 + 数据 + 文档
软件危机 Software Crisis
成本失控：预算超支，没钱了还没做完
进度延误：说好三个月上线，结果拖了三年
质量低劣：Bug满天飞，根本没法用
难以维护：代码写得像“面条”一样乱，改一个地方崩整个系统
软件工程 Software Engineering
1968年，北约（NATO）召开会议，首次正式提出“软件工程”
核心思想：

用工程化的方法：制定标准、流程、规范

用科学的管理：控制成本、进度、质量

目的：

解决软件危机，让软件开发变得可控、可预测、高质量

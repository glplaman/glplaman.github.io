数据库设计
1. 数据库的 逻辑 设计
数据长什么样
核心任务：画 E-R 图，确定表结构
产出物：E-R 图（实体-关系图）和数据字典

核心任务：建表语句，优化存储
产出物：具体的 SQL 建表语句
接口设计
定义协议细节
比如：是用 HTTP 还是 TCP？参数是 JSON 格式还是 XML？错误码怎么定义（1001代表密码错误，1002代表用户不存在）？
过程设计
这是详细设计最累人的部分

源码、反码、补码
为了区分正数和负数，需要拿出1位来表示符号，所以系统中的数分为2部分：符号位和数值位

正数：符号位为 0

负数：符号位为 1

以8位二进制为例
源码 Original Code
反码 One's Complement

正数：和源码相同

负数：符号位不变，其它各位取反

补码 Two's Complement

正数：和源码相同、和反码相同

负数：反码 +1

数据存储 Storage
计算机使用二进制表示和存储数据 - 体现的是数据的 多少/容量
电路实现简单；可靠性高、运算简单
位 Bit：存储数据的最小单位；单位用 b 表示；每个比特可以存储 0 或 1
字节 Byte：8个比特称为字节，单位用 B 表示；字节是计算机数据处理和存储的基本单位
字 Word：一个字由若干个字节组成，通常取字节的整数倍，是计算机一次存取、加工和传送的数据长度。常用的字长有8位、16位、32位和64位等

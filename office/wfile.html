文件 FIle
创建 New | Ctrl + N
创建一个新的空白文档
还可以在桌面 Desktop 或资源管理器 Explorer 中，右键鼠标 → 新建 → 对应的文件类型 → 双击文件打开
保存 Save | Ctrl + S
保存所做的编辑
每次新建文档后都应该 立即 保存
编辑过程中，应养成 随手保存 的好习惯
第一次保存，会提示用户指定保存位置/路径和文件名
可以通过"另存为"更改保存位置和名字
对已有的文档改名：选择文档 → 单击文档名字或按 F2，编辑名字并按 Enter 确定
在"选项" → "保存"中设置自动保存
建议开启文档后缀名，便于改名
=lorem(p,l)：快速生成 p 段 l 行的英文占位符|假文；视系统而定
=rand(p,l)：快速生成 p 段 l 行的中文占位符|假文；视系统而定
打开 Open | Ctrl + O
使用程序打开历史文档
Office会保存一定数量的历史文件，供用户快速选择以便再次编辑
在程序外，使用双击文件或将文件拖到程序图标上可以快速打开[]

导出 Export
为避免格式异常，分享文档时，通常导出为 PDF 格式，可以最大限度的消除版本差异带来的格式变化
如果已经定稿或不想被修改，也应导出为PDF格式
导出 PDF：导出 → 创建 PDF/XPS 文档 → 创建 PDF/XPS
关闭 Close | Alt + F4

选项 Options
Word 的全局设置
校对 Proofing：标记文档时，进行错误检测、语法检测等；可以选择只对当前文本
保存 Save：文档保存时的一些选项，如嵌入字体
语言 Language：第一次切换语言时，需要下载语言包
高级 Advanced：如图片大小和质量
自定义功能区 Customize Ribbon：配置菜单
快速访问工具栏 Quick Access Toolbar：定制常用的命令，避免来回切换选项卡
添加插入符号命令快速访问工具栏

创建文档
  1. 打开"资源管理器"
  2. 定位到"D"盘
  3. 创建个人工作文件夹，以学号命名
  4. 双击个人工作文件夹，进入
  5. 创建 Word 文档，以学号+姓名命名，如2026机械
  6. 按照实际情况编辑文档信息
  7. 导出为 PDF
  8. 保存并关闭所有文件

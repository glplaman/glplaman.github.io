基本使用
选择某个空单元格显示计算结果，输入 =，激活公式计算功能
除了手动计算还可以使用函数
输入函数开始几个字母，系统会出现可能的函数列表
使用 ↑、↓ 预览函数，注意阅读函数的基本使用信息
使用 TAB 选择函数，函数会出现顶部的公式栏；根据函数要求，指定参数，或者单击、或者拖动
所有参数都指定后，按回车 Enter 确认，完成计算
指定条件、范围，使用双引号 ""
可以使用通配符 Wildcard
如果结果异常，请查看参数是否正确、参数是否正确、符号是否正确、逻辑是否正确

IF
条件判断
适合单条件判定或两条件判定
也可以多级嵌套；多级条件推荐使用IFS
注意括号要匹配，不要丢失
更多案例，请访问 IF Function
# 两级制：成绩大于等于60，为及格，否则不及格
=IF(U112 >= 60, "及格", "不及格")

# 如果达标，显示通过，否则给出差额；这里绝对引用某个单元格的值
=IF(M2 > $M$11,"pass", $M$11-M2)

# 五级制：依次判定分数，嵌套较多，不建议使用
=IF(F3>=90,"A",IF(F3>=80,"B",IF(F3>=70,"C",IF(F3>=60,"D","F"))))
SUMIF(range, criteria, [sum_range])
根据条件 criteria 求和；如果省略求和区域 sum_range，将使用前面指定的区域 range
更多案例，请访问 SUMIF Function
可以通过引用指定条件
求水果类的营业额
=SUMIF(B2:B13,"水果",D2:D13)
进阶版：求水果和蔬菜的营业额；BiliBili-SUMIF
第1步：使用数组方法{}，分别求和各自的和
第2步：结果求和
=SUM(SUMIF(B2:B13,{"水果","蔬菜"},D2:D13))
进阶版：分别求不同类型的营业额
使用数据验证
求2026年5月1日后的营业额
方案1：直接使用日期
=SUMIF(C2:C13,">2026/5/1",D2:D13)
方案2：使用引用；注意条件的拼接 &
=SUMIF(C2:C13,">"&I8,D2:D13)
方案3：日期转换后再计算；适用于数据格式不规范的情况
日期是特殊的数据格式。使用前姚确保格式正确，不要和字符串混淆
IFS
多分支/条件判断，返回与第一个 true 条件匹配的值
范围要全覆盖，否则会提示值无效
如果有默认值，请使用 TRUE 指定
更多案例，请访问 IFS Function
# 有效
= IFS(A2 >= 90, "A", A2 >= 80, "B", A2 >= 70, "C", A2 >= 60, "D", TRUE, "F")

# 有效
= IFS(U112 > 90, "A", U112 > 80, "B", U112 >= "60", "C", U112<60, "D")

# 无效
= IFS(U112 > 90, "A", U112 > 80, "B", U112 < 60, "D")
其它例子
= COUNTIF(H2:H16, ">=60")：大于等于60，即及格的人数
= COUNTIF(B2:B18,"李*")
= COUNTIFS(L2:L9, ">=70", L2:L9, "<80")：大于等于70小于80的人数
= RANDBETWEEN(10, 20)
= ROUND(4.567, 0) // 5
= ROUND(4.567, 1) // 4.6
= ROUND(4.567, 2) // 4.57
= RANK(H2, $H$2:$H$16)

VLOOKUP(lookup_value, table_array,col_index_num,[range_lookup])
The VLOOKUP function looks for a given value in the leftmost column of a given table and then returns a value in the same row from a specified column.
查找：先在最左边垂直方向|行找到关键字 lookup_value，再水平方向找到目标|列索引 col_index_num 对应的值
查找关键字 lookup_value：必须位于查找区域第一列
查找区域 table：由关键字和结果值组成；通常使用绝对地址
列索引 col_index_num：正整数，第1列为1，第2列为2，以此类推
查找结果 range_lookup：模糊匹配 TRUE 或精确匹配 FALSE；默认是模糊匹配
模糊匹配：如果没有匹配的关键字，就根据关键字的升序排序空间，模糊匹配；匹配不到会先 #N/A；如成绩档次
精确匹配，通常配合其他错误函数一起使用
获取多个目标数据时，需要手动修改列数
更多案例，请访问 VLOOKUP Function
用法1：单值查询
根据查询学号对应的的平均成绩
学号在第 1 列
平均成绩在第 4 列
各个值都是固定的/静态的
公式可以写在任何位置
= VLOOKUP(K1,A1:E10,4,FALSE)
用法2：BiliBili-多个值查询；使用 COLUMN() 动态指定结果列
注意列索引之间的偏移
如果数据和范围以及计算结果都从第1列开始，则直接使用
=VLOOKUP($A4,$A$2:$H$18,COLUMN(),0)
如果计算结果不是从第1列开始，要减去单元格的偏移；计算结果放在第 11 列；从第 2 列开始查询
=VLOOKUP($A14,$A$2:$H$17,COLUMN()-9,0)
用法3：BiliBili-跨表多值查询 
=VLOOKUP($A2,学生成绩!$B$2:$H$18,COLUMN(学生成绩!C1)-1,0)
TEXT
根据指定的数字格式将数值转换成文本
格式串通常以 0：普通数字、YYYY：年；MM：月；DD：日；AAAA：星期
在 text 前加 -- 可以将结果转换为数字。前提是结果可以转换为数字
此外可以实现四舍五入、条件计算等功能，但是建议使用更加直观的函数
= TEXT(A3, "000-0000-0000") // 13707735418 → 137-0773-5418
= TEXT(B4, "yyyy年m月d日") // 2023/11/12 →  2023年11月12日
= TEXT(B4, "YYYY") // 2023/11/12 →  2023
= TEXT(B4, "MM") // 2023/11/12 → 11
= TEXT(B4, "DD") // 2023/11/12 → 12
= TEXT(B4, "AAAA") // 2023/11/12 → 星期日
= TEXT(B6, "0.0") // 4.567 → 4.6
= TEXT(B6, "0.00") // 4.567 → 4.57

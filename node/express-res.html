Express

@Response
res.json()
专门用于发送 JSON 格式数据，强制将数据序列化为 JSON，并设置 Content-Type: application/json
更常见
在写后端 API 时，优先使用 res.json()，这是行业惯例，也更安全、可读性更强
res.json({
  "errno": 0,
  "data": {
    "url": 'http://127.0.0.1:3000/upload/' + req.file.filename,
  }
})
res.send()
是 Express 提供的高级方法，功能更强大
通用响应方法，可发送字符串、Buffer、对象、数组等，Express 会根据内容类型自动设置 Content-Type
自动设置合适的 Content-Type（如 text/html、application/json 等）
自动处理多种数据类型：

字符串 → 发送为文本 text/html(字符串也看作 text/html”，这是 Express 的默认行为)

对象/数组 → 自动 JSON.stringify() 并设为 application/json

Buffer → 二进制数据

null/undefined → 发送空响应，状态码 204

app.get('/1.txt', (req, res) => {
  res.send('大树1.txt') // 自动处理 OK
})
自动设置状态码（如 200），也可配合 res.status(404).send(...) 使用
自动调用 res.end()，无需再手动结束
res.send('hi,there.') 
res.send('<h1>hi,there.</h1>') 
res.send({ id: 10, name: 'gl' })
res.write()
写回流时，需要显式指定结束 end()
argument: must be of type string or an instance of Buffer or Uint8Array
res.write(data)
res.end()
res.end()
不会自动设置 Content-Type 或状态码（除非你手动设置），否则可能出现乱码（因为没指定编码）
不支持自动序列化对象（传对象会报错或显示 [object Object]）
不建议使用；请使用 send()
app.get('/1.txt', (req, res) => {
  res.end('大树1.txt') // 乱码
})
app.get('/1.txt', (req, res) => {
  res.setHeader('Content-Type', 'text/plain; charset=utf-8')
  res.end('大树1.txt') // OK
})
在开发者工具中，使用 encodeURIComponent() 测试编码
res.sendFile()
发送文件；需要指定参考路径
直接传输文件，不需要将文件从用户空间拷贝到内核空间，文件传输效率提高；减少内存拷贝，减少CPU消耗，提高系统性能
只能用于发送静态文件，不能传输其他类型的数据
只能传输2GB以下的文件
res.sendFile('./www/index.html', { root: __dirname })
res.render()
渲染页面；页面路径依据配置的静态资源路径
res.render('home/index', {
  navIndex: 0
})
res.status()
设置 HTTP 响应的状态码。状态码是服务器返回给客户端的一个数字，用于表示请求的处理结果
成功的响应
res.status(200).json({ 'msg': 'ok' });
res.status(200).json({ 'code': 200, 'msg': 'Success', 'data': jsonData });
400 错误，并附带一个错误消息
res.status(400).json({ 'msg': 'Bad Request' });
res.status(400).json({ 'code': 400, 'msg': 'Invalid request parameters' });

方法

404
以中间件 use() 的形式实现
所有路由都匹配失败，则匹配 404；所以 404 中间件应该放在所有路由的 后面
注意路径的拼接
//其它路由

server.use((req, res) => {
  res.status(404).sendFile('./www//lost.html', { root: __dirname })
})
//其它路由

server.use((req, res) => {
  res.status(404).sendFile('lost.html', { root: __dirname + '/www/' })
})
中间件在 req 和res 之间执行；拿到 res 后就没有必要了

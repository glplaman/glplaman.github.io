字体

@Fontsource
Fontsource 提供多种使用方式
Steps
  1. 打开官网 Fontsource
  2. 搜索字体；如 MonteCarlo
  3. 单击进入字体页面，选择标签页"安装 Install"
  4. 安装字体
    5. npm install @fontsource/montecarlo
  5. 在组件 .jsx 中引入
    6. import '@fontsource/montecarlo';
  6. 引入组件对应的样式文件 .css
    7. import "./Rank.css";
  7. 在样式文件使用字体
    8. .title {
  font-family: 'MonteCarlo', cursive;
}

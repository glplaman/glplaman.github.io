@State
Introduction
状态
响应式数据
需要引入再使用
import { useState } from "react";
每个组件实例维护自己的状态，彼此互不影响
更多信息，请访问 useState、Updating the screen、Managing State
Syntax
const [state,setState] = useState(initial)
状态：state，即数据
函数：function，修改数据
命名：原则上任意，建议 something, setSomething
示例
基本数据类型
const [show,setShow] = useState(false)
function hansectioneClick(){
  setShow( true )
}
引用数据类型
const [showState,setShowState] = useState({show: false})
function hansectioneClick(){
  setShowState( {show: true} )
}

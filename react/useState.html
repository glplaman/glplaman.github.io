状态

@State
Introduction
状态
用来保存那些一旦改变，UI 必须跟着刷新的数据 - 响应式数据
仅仅用于需要更新 UI 的场合
Import
需要引入再使用
仅限在顶层引入 - Top Level
import { useState } from "react";
每个组件实例维护自己的状态，彼此互不影响
更多信息，请访问 useState、Updating the screen、Managing State
Define
const [state,setState] = useState(initial)
状态：state，即数据；在 React 中，State 被视为“ 不可变数据 ”，不能直接操作状态
函数：function，操作/更新状态

如果只是设置一个值，使用常规语法

如果你的新状态依赖于前一个状态，使用基于前一个状态的更新函数

命名：原则上任意，建议 something, setSomething
基本数据类型 - 以布尔为例
const [show,setShow] = useState(false)
const hansectioneClick = () => setShow( true )
引用数据类型 - 以多个属性的对象为例
使用更新函数；基于前一个状态进行更新
否则，直接更新的话，会覆盖/删除其它状态
const [user, setUser] = useState({
  id: 1000,
  name: 'mike',
  age: 18
})
修改数据
使用内联事件
<div>{user.name} {user.age}</div>
<button onClick={() => setUser((prev) => ({ ...prev, name: 'git' }))}>set name</button>
<button onClick={() => setUser((prev) => ({ ...prev, age: 20 }))}>set age</button>
使用独立函数
const setUserName = () => {
  setUser((prev) => ({ ...prev, name: 'git' }))
}
const setUserAge = () => {
  setUser((prev) => ({ ...prev, age: 20 }))
}
<div>{user.name} {user.age}</div>
<button onClick={setUserName}>set name</button>
<button onClick={setUserAge}>set age</button>
如果需要修改的数据字段为复合属性，如 address，如何实现？
const [user, setUser] = useState({
  id: 1000,
  name: 'mike',
  age: 18,
  address:{
    city:'gz',
    country:'CN'
  }
})

嵌套路由

@Nested
布局组件就是嵌套路由的应用
Requirement
course

front

back

Steps
  1. 通过嵌套 <Route> 实现子路由
    2. <Route path="course" element={<Course />}>
  <Route path="front" element={<Front />}></Route>
  <Route path="back" element={<Back />}></Route>
</Route>
  2. 在父路由组件 Course 中使用 <Outlet /> 作为占位符，渲染/使用子路由视图
    3. import { Outlet } from "react-router"
    // course header
// course content
<Outlet />
// course footer
index
可以使用 index 指定默认子路由（Index Route）；省略 path
使用 index 属性的路由，无法继续嵌套子路由
<Route path="course" element={<Course />}>
  <Route index element={<Front />}></Route>
  <Route path="back" element={<Back />}></Route>
</Route>
使用默认子路由时，应该保持为空
<NavLink to=''>Front-end</NavLink>
<NavLink to='back'>Back-end</NavLink>
不要写 to='front'：因为没有定义这个路由
end
使用 end 属性，以精确匹配路由，便于应用特定样式，如激活
多应用于子路由，特别是默认路由

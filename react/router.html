Install
npx create-vite@latest
Steps
  1. 引入浏览器路由 BrowserRouter
    2. import { BrowserRouter } from "react-router";
  2. 在 App 引入路由
    3. import { BrowserRouter, Routes, Route, NavLink } from "react-router";
  3. 在 <BrowserRouter> 中设计路由和使用路由
    4. <BrowserRouter>
  {/* 使用路由 */}
  {/* 设计路由 */}
</BrowserRouter>
  4. 设计路由；使用 <Routes> 和 <Route> 设计路由；其中 /:num 为动态路由
    5. <Routes>
  <Route path="/:num" element={<Test />}></Route>
  <Route path="/login" element={<Login />}></Route>
  <Route path="/register" element={<Register />}></Route>
  <Route path="/rank" element={<Rank />}></Route>
  <Route path="/center" element={<Center />}></Route>
  <Route path="/message" element={<Message />}></Route>
</Routes>
  5. 使用路由

    6. 可以指定查询参数 search/query、目标哈希 hash

    使用 <NavLink> 实现 声明式 导航；需引入再使用

    相比较 <Link>，<NavLink> 可以自动应用激活样式 active；需提前设计好

    <nav>
  <NavLink to='/12'>Test</NavLink>
  <NavLink to='/login'>Login</NavLink>
  <NavLink to='/register'>Register</NavLink>
  <NavLink to='/rank'>Rank</NavLink>
  <NavLink to='/center?id=1001'>Center</NavLink>
  <NavLink to={{
    pathname: '/message',
    hash: '#tar',
    search: 'id=10'
  }}>Message</NavLink>
</nav>

    使用 useNavigate 实现 编程式 导航；需引入再使用

    import { useNavigate } from "react-router"
    const nav = useNavigate()
    <p onClick={() => nav('/center')}>to Center</p>

    动态路由的获取需要使用 useParams 解析；需引入再使用

    import { useParams } from "react-router"
    let { num } = useParams()

React Router 7- 的版本中，使用 end 属性完全匹配；特别是存在嵌套路由的时候

登陆页面和注册页面
使用 <Link> 实现；无需应用激活样式
如果没有账号，则引导去注册页面
<div>Not have an acount? <Link to='/register'>Register</Link></div>
如果已有账号，则引导去登陆页面
<div>Already have an acount? <Link to='/login'>Login</Link></div>
设计激活样式
使用默认类名 active
a.active{
  color: #f40;
}
使用三元表达式 ?: 定制类名
isActive 是 <NavLink> 组件内置的、自动注入的参数
<NavLink 
  to='rank' 
  className={({ isActive }) => isActive ? 'red' : 'blue'}
>
  Rank
</NavLink>
基本路径 basename
默认情况下，项目发布后，部署在网站根目录
路由设计和使用可以使用 / 或者不使用 / 都可以；前例路由使用了 /
如果指定了基本路径 basename，表示当前项目是网站下的一个子目录，则应使用不带 / 的相对路径；否则会被编译为网站根目录
需要同时在 vite.config.js 中配置 base
export default defineConfig({
  plugins: [react()],
  base: '/common/rank',
})
<BrowserRouter basename="/common/rank">
  {/* 使用路由 */}
  {/* 设计路由 */}
</BrowserRouter>
设计
<Routes>
  <Route path=":num" element={<Test />}></Route>
  <Route path="login" element={<Login />}></Route>
  <Route path="register" element={<Register />}></Route>
  <Route path="rank" element={<Rank />}></Route>
  <Route path="center" element={<Center />}></Route>
  <Route path="message" element={<Message />}></Route>
</Routes>
使用
<nav>
  <NavLink to='12'>Test</NavLink>
  <NavLink to='login'>Login</NavLink>
  <NavLink to='register'>Register</NavLink>
  <NavLink to='rank'>Rank</NavLink>
  <NavLink to='center?id=1001'>Center</NavLink>
  <NavLink to={{
    pathname: 'message',
    hash: '#tar',
    search: 'id=10'
  }}>Message</NavLink>
</nav>

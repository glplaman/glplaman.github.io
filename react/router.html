Install
npm i react-router
Steps
  1. 在 App.jsx 引入路由
    2. import { BrowserRouter, Routes, Route, NavLink } from "react-router";
  2. 在 <BrowserRouter> 中设计/声明路由

    3. <BrowserRouter> 是 React Router 提供的路由根容器

    应该放置在应用组件树的最高层级

    <BrowserRouter>
  {/* 设计路由 */}
  {/* 使用路由 */}
</BrowserRouter>
  3. 设计路由

    4. 使用 <Routes> 和 <Route> 设计路由；其中 /:num 为动态路由

    对应的组件要导入

    <Routes>
  <Route path="/" element={<Home />}></Route>
  <Route path="/work" element={<Work />}></Route>
  <Route path="/team/:num" element={<Team />}></Route>
  <Route path="/rank" element={<Rank />}></Route>
  <Route path="/register" element={<Register />}></Route>
</Routes>
  4. 使用路由

    5. 可以指定查询参数 search/query、目标哈希 hash

    使用 <NavLink> 或 <Link> 实现 声明式 导航；需引入再使用

    相比较 <Link>，<NavLink> 可以自动应用激活样式 active；需提前设计好

    可以封装为组件

    <nav>
  <NavLink to='/'>Home</NavLink>
  <NavLink to='/work?id=1001'>Work</NavLink>
  <NavLink to='/team/101'>Team</NavLink>
  <NavLink to='/rank'>Rank</NavLink>
  <NavLink to='/register'>Register</NavLink>
  <NavLink to={{
    pathname: '/message',
    search: 'id=10'
    hash: '#tar',
  }}>Message</NavLink>
</nav>

pathname：根据路由情况使用；绝对路由，使用 /；相对路由，不使用 /，如嵌套路由多使用相对路由

search：会自动拼接 ?

hash：始终手动加 #；且不会自动跳转，需手动处理

全局布局/共享布局
所有页面都共享头部 Header 和底部 Footer
在路由设计外面添加 头部 Header 和底部 Footer
如果部分页面需要共享 UI，部分页面不需要，则需要 布局组件 实现
<BrowserRouter>
  <Header>
  {/* 设计路由 */}
  {/* 使用路由 */}
  <Footer>
</BrowserRouter>
登陆页面和注册页面
如果没有账号，则引导去注册页面
<div>Not have an acount? <Link to='/register'>Register</Link></div>
如果已有账号，则引导去登陆页面
<div>Already have an acount? <Link to='/login'>Login</Link></div>
active
使用 <NavLink> 导航时会自动添加激活样式类
默认类名是 active
a.active{
  color: #f40;
}
使用三元表达式 ?: 定制类名
isActive 是 <NavLink> 组件内置的、自动注入的参数
<NavLink 
  to='rank' 
  className={({ isActive }) => isActive ? 'red' : 'blue'}
>
  Rank
</NavLink>
直接使用 <a>，会污染其它 <a>
建议同时使用全局样式和 module 样式，以便和其它 <a> 区分
<NavLink className={`nav-item ${styles['nav-item']}`} to='/about'>test</NavLink>
基本路径 basename
默认情况下，项目发布后，部署在网站根目录
路由设计和使用可以使用 / 或者不使用 / 都可以；前例路由使用了 /
如果指定了基本路径 basename，表示当前项目是网站下的一个子目录，则应使用不带 / 的相对路径；否则会被编译为网站根目录
需要同时在 vite.config.js 中配置 base
export default defineConfig({
  plugins: [react()],
  base: '/common/rank',
})
<BrowserRouter basename="/common/rank">
  {/* 使用路由 */}
  {/* 设计路由 */}
</BrowserRouter>
设计
<Routes>
  <Route path=":num" element={<Test />}></Route>
  <Route path="login" element={<Login />}></Route>
  <Route path="register" element={<Register />}></Route>
  <Route path="rank" element={<Rank />}></Route>
  <Route path="center" element={<Center />}></Route>
  <Route path="message" element={<Message />}></Route>
</Routes>
使用
<nav>
  <NavLink to='12'>Test</NavLink>
  <NavLink to='login'>Login</NavLink>
  <NavLink to='register'>Register</NavLink>
  <NavLink to='rank'>Rank</NavLink>
  <NavLink to='center?id=1001'>Center</NavLink>
  <NavLink to={{
    pathname: 'message',
    hash: '#tar',
    search: 'id=10'
  }}>Message</NavLink>
</nav>

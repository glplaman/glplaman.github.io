@Event Handling
概述 Overview
使用原生方式 onXXX 添加交互，如 onClick、onChange、onSubmit、onMouseEnter
支持单独函数和内联函数
不支持事件侦听
更多信息，请访问 Responding to Events
Steps
  1. 定义函数 Define

    2. 事件处理函数通常使用 handle 作为前缀，如 handleXXX

    const HandleClick = () => {
  console.log('hi');
};
  2. 分配函数 Assign

    3. 以属性的形式传递给结构 - pass it as a special prop with on to the appropriate tag

    使用函数；传递的是一个函数的引用；单击时，触发函数执行

    <button onClick={HandleClick}>Click me</button>
  3. 调用函数

    4. 用户单击的时候，就会触发函数执行

    如果：分配函数的时候，带上 () 就表示立即执行

    <button onClick={HandleClick()}>Click me</button>
带参函数
注意和无参函数的区别
定义函数
const deleteById = (id) => {
  console.log(id);
};
分配函数
<button onClick={()=>deleteById(id)}>Click me</button>
如果直接指定带参函数，会立即执行 - 因为使用了()
<button onClick={deleteById(id)}>Click me</button>

还可以使用函数柯里化 Currying 进一步优化

内联事件 Inline event
简单逻辑，可以使用内联事件 Inline event
<button onClick={() => console.log('hi')}>Click me</button>
计算器加减
数据
const [count, setCount] = useState(0);
内联事件
<div>{count}</div>
<button onClick={() => setCount(count + 1)}>Inc</button>
<button onClick={() => setCount(count - 1)}>Dec</button>
<button onClick={() => setCount((prev)=>prev-1)}>Dec</button>

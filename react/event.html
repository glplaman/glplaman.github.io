@Event Handling
概述 Overview
使用原生方式 onXXX 添加交互
不支持事件侦听
定义 Declaration
定义一个事件处理函数 - define a function
以属性的形式传递给结构 - pass it as a prop to the appropriate tag
事件处理函数通常使用 handle 作为前缀，如 handleXXX
函数调用 Call
在 React 中，花括号 {} 代表“这里开始写 JavaScript 代码”
函数名带上 () 就表示立即执行
注意区分无参和有参的情况
更多信息，请访问 Responding to Events
无参函数
定义函数
const sayHi = () => {
  console.log('hi,there.');
};
使用函数；传递的是一个函数的引用；单击时，触发函数执行
<button onClick={sayHi}>Click me</button>
如果函数带上()，会立即执行
<button onClick={sayHi()}>Click me</button>
带参函数
定义函数
const deleteById = (id) => {
  console.log(id);
};
调用函数
<button onClick={()=>deleteById(id)}>Click me</button>
如果直接指定带参函数，会立即执行 - 因为使用了()；注意和无参函数的区别
<button onClick={deleteById(id)}>Click me</button>

还可以使用函数柯里化 Currying 进一步优化

简单逻辑，可以使用内联事件 Inline event
数据
const [count, setCount] = useState(0);
内联事件
<div>{count}</div>
<button onClick={() => setCount(count + 1)}>Inc</button>
<button onClick={() => setCount(count - 1)}>Dec</button>
<button onClick={() => setCount((prev)=>prev-1)}>Dec</button>

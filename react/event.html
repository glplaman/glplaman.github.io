Introduction
使用原生方式 onXXX 添加交互；handleClick 是事件处理函数
不支持事件侦听
定义一个事件处理函数 - define a function
以属性的形式传递给结构 - pass it as a prop to the appropriate tag
事件处理函数通常使用 handle 作为前缀，如 handlexxx
更多信息，请访问 Responding to Events
示例
function Button() {
  const handleClick = () => {
    console.log('click');
  };
  return (
    <>
      <button onClick={handleClick}>Click me</button>
    </>
  );
}
export default Button;
简单逻辑，可以使用内联事件 Inline event
function Button() {
  return (
    <>
      <button onClick={()=>alert('hi,there.')}>Click me</button>
    </>
  );
}
export default Button;

示例
阻止表单的默认提交
绑定 value 实现双向数据
import { useState } from 'react';
function Login() {
  const [uname, setUname] = useState('');
  const [upass, setUpass] = useState('');
  const handleSubmit = (e: any) => {
    e.preventDefault();
    console.log(e);
    alert(`'uname',${uname},'upass',${upass}`);
    setUname('');
    setUpass('');
  };
  return (
    <>
      <form onSubmit={handleSubmit}>
        <input
          type="text"
          placeholder="your name"
          value={uname}
          name="uname"
          onChange={(e) => setUname(e.target.value)}
        />
        <input
          type="password"
          placeholder="your pass"
          value={upass}
          name="upass"
          onChange={(e) => setUpass(e.target.value)}
        />
        <button type="submit">submit</button>
      </form>
    </>
  );
}
export default Login;

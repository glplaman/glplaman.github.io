路由样式

@active
Overview
使用 <NavLink> 导航时会自动添加激活样式类
默认类名是 active
a.active{
  color: #f40;
}
使用三元表达式 ?: 定制类名
isActive 是 <NavLink> 组件内置的、自动注入的参数
<NavLink 
  to='rank' 
  className={({ isActive }) => isActive ? 'red' : 'blue'}
>
  Rank
</NavLink>
直接使用 <a>，会污染其它 <a>
建议同时使用全局样式和 module 样式，以便和其它 <a> 区分
<NavLink 
  className={`nav-item ${styles['nav-item']}`} 
  to='/about'>test</NavLink>
使用函数混合样式
使用全局样式 nav-item
定制 module 激活样式 active
在函数返回中指定：始终保留 nav-item；激活时，使用 module 样式 active
<NavLink 
  className={({ isActive }) => `nav-item ${isActive ? styles.active : ''}`} 
  to='/about'>test</NavLink>

组件传参

@Props
父组件以属性 Props 的形式分享/传递数据给子组件 - React components use props to communicate with each other
子组件使用/解构使用父组件分享的数据
可以是普通数据，也可以是函数/方法
anything will be ok as a props
key: built-in props
更多信息，请访问 Passing Props to a Component
传递普通数据
数据只能从父组件流向子组件 - 单向数据流
1. 子组件 Greeting.tsx
子组件在函数中使用 props
子组件只接受一个参数 props - React component functions accept a single argument, a props object:
父组件分享的所有数据都在这个 props 对象中
通常从 props 中解构数据 - destructure it into individual props
同样可以指定默认参数 - Specifying a default value
const Greeting = (props) => {
  return <div>hi, {props.user}</div>;
};
export default Greeting;
const Greeting = ({ user = 'glpla' }) => {
  return <div>hi, {user}</div>;
};
export default Greeting;
2. 父组件
导入子组件
import Greeting from "./components/Greeting.tsx";
以属性 props 的形式指定属性 - 传递数据/通信
<Greeting user="glplaman"></Greeting>
传递函数
父组件分享函数给子组件
子组件执行父组件的函数，同时也向父组件传递数据
父组件根据子组件的数据执行相应的动作
很多实际业务场景中，子组件必须通过调用父组件的函数来完成特定任务
用户中心
修改用户信息
修改操作封装为一个组件；通过执行父组件函数来更新信息
父组件
const [user, setUser] = useState('glpla')
const setName = (e) => {
  setUser(e.tars.value)
}
<Input fn={setName} user={user}></Input>
子组件
const Input = ({ user, fn }) => {
  return (
    < >
      <input type="text" onChange={fn} value={user} />
    </>
  )
}

export default Input

Children

除了传递 Props 外，还可以以嵌套普通标签/组件的方式传递数据
相当于在子组件中预留了一个插槽 slot
这个数据被 props.children 接受
父组件
<SayHi title='glplaman'>
  <h1>hi,there.</h1>
</SayHi>
子组件
const SayHi = ({ title, children }) => {
  return (
    <>
      <p>hi,{title}</p>
      {children}
    </>
  )
}

export default SayHi

组件传参

@Props
父组件以属性 Props 的形式分享/传递数据给子组件 - Sharing data between components
子组件使用/解构使用父组件分享的数据
anything will be ok as a props
key: built-in props
更多信息，请访问 Passing Props to a Component
子组件 Greeting.tsx
在函数中使用 props
父组件分享的所有数据都在这个对象中
const Greeting = (props) => {
  return <div>hi, {props.user}</div>;
};
export default Greeting;
通常从 props 中解构数据，以便更清楚的查看数据
可以指定默认参数
const Greeting = ({ user = 'glpla' }) => {
  return <div>hi, {user}</div>;
};
export default Greeting;
父组件
导入子组件
import Greeting from "./components/Greeting.tsx";
以属性 props 的形式指定属性 - 传递数据/通信
<Greeting user="glplaman"></Greeting>

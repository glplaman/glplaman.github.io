钩子函数

@useEffect
将组件与外部系统同步
先引入再使用
更多信息，请访问 useEffect()
Syntax
useEffect(setup, dependencies?)

在开发环境中，React 会故意调用某些函数两次，以帮助发现潜在问题

确保您的副作用函数（如 API 调用）是幂等的，即多次调用不会产生副作用

React 的开发模式调试特性，只在开发环境出现，生产环境不会发生

示例
引入
import { useEffect } from "react";
使用
useEffect(()=>{
  console.log("components init");  
}, [])
加载数据
创建函数
const getRank = async () => {
  let res = await fetch("https://glplaman.github.io/utils/data/rank/202501.json");
  let data = await res.json();
  return data;
};
在钩子中使用函数
useEffect(() => {
  getRank();
}, []);

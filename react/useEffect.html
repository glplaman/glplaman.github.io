副作用

@useEffect
处理那些与 UI 渲染无关，但需要执行的操作。比如：发起网络请求、操作 DOM、设置定时器
将组件与外部系统同步
只能在客户端组件调用 - Effects only run on the client. They don’t run during server rendering.
更多信息，请访问 useEffect()
先引入
import { useEffect } from "react";
再使用
useEffect(setup, dependencies?)
setup：一个函数，用于定义副作用逻辑。这个函数会在组件挂载、更新或卸载时根据依赖项的变化执行
dependencies：可选参数；指定依赖，仅当依赖变化时，触发同步

在开发环境中，React 会故意调用某些函数两次，以帮助发现潜在问题

确保您的副作用函数（如 API 调用）是幂等的，即多次调用不会产生副作用

React 的开发模式调试特性，只在开发环境出现，生产环境不会发生

示例
初始化 - 执行1次
useEffect(()=>{
  console.log("components init");  
}, [])
指定依赖状态
useEffect(() => {
  console.log("state change");
}, [state]);
加载数据
const [ranks, setRanks] = useState([]);
在钩子中使用函数
useEffect(() => {
  getRank();
}, []);
创建函数
const getRank = async () => {
  const res = await fetch("https://glplaman.github.io/utils/data/rank/202501.json");
  const data = await res.json();
  setRanks(data);
};
在组件返回中渲染数据
return (
  <div>
    <ul>
      {todos.map((todo) => (
        <li key={todo.id}>
          {todo.id}-{todo.title}
        </li>
      ))}
    </ul>
  </div>
);
IDE 语法检测会提示类型错误；使用泛型并指定类型
interface Todo {
  id: number;
  title: string;
}
const [todos, setTodos] = useState<Todo[]>([]);
next.js 中，组件默认是服务端组件，不需要使用钩子，可以直接加载数据并使用
interface Todo {
  id: number;
  title: string;
}
export default async function Demo() {
  const res = await fetch("https://jsonplaceholder.typicode.com/todos");
  const todos = await res.json();
  return (
    <div>
      <ul>
        {todos.map((todo: Todo) => (
          <li key={todo.id}>
            {todo.id}-{todo.title}
          </li>
        ))}
      </ul>
    </div>
  );
}
监听状态变化
count 变化时，触发同步
import { useEffect, useState } from "react";
export default function Demo() {
  const [count, setCount] = useState(0);
  useEffect(() => {
    console.log("useEffect count", count);
  }, []);
  return (
    <div>
      <button onClick={() => setCount(count + 1)}>count: {count}</button>
    </div>
  );
}

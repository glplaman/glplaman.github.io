副作用

@useEffect
在组件 渲染完成 后，执行“副作用（Side Effect）”逻辑。所谓副作用，是指那些会影响组件外部世界、不受 React 控制的操作
处理那些与 UI 渲染无关，但需要执行的操作。比如：发起网络请求、操作 DOM、设置定时器、订阅事件
本质是将组件与外部系统保持同步
只能在客户端组件调用 - Effects only run on the client. They don’t run during server rendering.
更多信息，请访问 useEffect()
先引入
import { useEffect } from "react";
再使用
useEffect(setup, dependencies?)
setup：一个函数，用于定义副作用逻辑。这个函数会在组件挂载、更新或卸载时根据依赖项的变化执行
dependencies：可选参数；指定依赖，仅当依赖变化时，触发同步

不写依赖数组：每次组件渲染后都会执行

空数组 []：仅在组件首次挂载时执行一次，适合初始化数据请求或注册事件

有依赖项 [dep1, dep2]：在首次执行后，仅当依赖项发生变化时才会重新执行

注意事项
避免无限循环：如果在 useEffect 内部更新了状态，且该状态又是依赖数组中的一员，会导致“状态更新 → 重新渲染 → Effect 再次执行”的死循环
如果仅仅是为了根据某些 state/props 的变化来转换或计算另一个 state，不应该使用 useEffect，而应该在渲染期间直接计算或使用 useMemo

在开发环境中，React 会故意调用某些函数两次，以帮助发现潜在问题

确保您的副作用函数（如 API 调用）是幂等的，即多次调用不会产生副作用

React 的开发模式调试特性，只在开发环境出现，生产环境不会发生

示例
初始化 - 执行1次
useEffect(()=>{
  console.log("components init");  
}, [])
指定依赖状态：仅 msg 改变时触发
useEffect(() => {
  console.log("msg change");
}, [msg]);
指定多个依赖状态：msg 或 age 改变时触发
useEffect(() => {
  console.log("bothd change");
}, [msg, age]);
如果单独监听某些数据，可以多次使用
useEffect(() => {
  console.log("msg change");
}, [msg]);

useEffect(() => {
  console.log("age change");
}, [age]);
加载数据
const [todos, setTodos] = useState([]);
在钩子中使用函数
useEffect(() => {
  getRank();
}, []);
创建函数
const getRank = async () => {
  const res = await fetch("https://glplaman.github.io/utils/data/rank/202501.json");
  const data = await res.json();
  setTodos(data);
};
在组件返回中渲染数据
return (
  <>
    <ul>
      {todos.map((todo) => (
        <li key={todo.id}>
          {todo.id}-{todo.title}
        </li>
      ))}
    </ul>
  </>
);
IDE 语法检测会提示类型错误；使用泛型并指定类型
interface Todo {
  id: number;
  title: string;
}
const [todos, setTodos] = useState<Todo[]>([]);
next.js 中，组件默认是服务端组件，不需要使用钩子，可以直接加载数据并使用
interface Todo {
  id: number;
  title: string;
}
export default async function Demo() {
  const res = await fetch("https://jsonplaceholder.typicode.com/todos");
  const todos = await res.json();
  return (
    <div>
      <ul>
        {todos.map((todo: Todo) => (
          <li key={todo.id}>
            {todo.id}-{todo.title}
          </li>
        ))}
      </ul>
    </div>
  );
}

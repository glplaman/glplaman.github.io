组件

@Component

A component is a piece of the UI (user interface) that has its own logic and appearance.

React components are JavaScript functions that return markup.

创建组件
React 应用由各种各样的组件构成
函数即组件；一切皆函数
React 操作 js 并返回 DOM；在函数中返回 html 结构
组件函数名和组件文件名保持一致
组件名必须大写开头 - React component names must always start with a capital letter, while HTML tags must be lowercase
单一根节点 - shared parent
可以是空标签 - empty <>...</> wrapper
为了避免自动插入分号，return 使用 ()
如果返回只有一行代码，可以省略()；但是不建议
使用 javaScript 的组件后缀名为 .jsx
使用 TypeScript 的组件后缀名为 .tsx
更多信息，请访问 Creating and nesting components、Your First Component
使用具名函数
使用 export default 时，不需要强制指定函数名
实际的 React 开发中，为了调试方便、增加可读性，强烈建议保留函数名
不关是结构是单行还是多行，都建议使用 ()/分组运算符 进行分组
声明并导出
function HelloWorld() {
  return (
    <>
      <div>hi,there.</div>
    </>
  );
}
export default HelloWorld
直接导出
export default function HelloWorld() {
  return (
    <>
      <div>hi,there.</div>
    </>
  );
}
使用 箭头函数
更简洁
使用 {}，要显式的使用 return 返回结构
或者直接返回结构
export default HelloWorld = () => {
  return (
    <>
      <div>hi,there.</div>
    </>
  );
}
使用组件
父组件引入并使用
import HelloWorld from './components/HelloWorld.tsx';
function App() {

  return (
    <>
      <HelloWorld />
    </>
  );
}

export default App;

react.js 中，默认都是 client component

next.js 中，默认都是 server component

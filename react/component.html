@Component

A component is a piece of the UI (user interface) that has its own logic and appearance.

React components are JavaScript functions that return markup:

Introduction
React 应用由各种各样的组件构成
函数即组件；一切皆函数
在函数中返回 html 结构
组件函数名和组件文件名保持一致
组件名必须大写开头 - React component names must always start with a capital letter, while HTML tags must be lowercase
单一根节点 - shared parent；可以是空标签 - empty <>...</> wrapper
为了避免自动插入分号，return 使用 ()
如果返回只有一行代码，可以省略()；但是不建议
使用 javaScript 的组件后缀名为 .jsx
使用 TypeScript 的组件后缀名为 .tsx
更多信息，请访问 Creating and nesting components、Your First Component
示例
创建组件 HelloWorld.tsx
function HelloWorld() {
  return (
    <>
      <div>hi,there.</div>
    </>
  );
}
export default HelloWorld;
父组件引入并使用
import HelloWorld from './components/HelloWorld.tsx';
function App() {

  return (
    <>
      <HelloWorld />
    </>
  );
}

export default App;

组件

@Component

A component is a piece of the UI (user interface) that has its own logic and appearance.

React components are JavaScript functions that return markup.

概述
React 应用由各种各样的组件构成
函数即组件；一切皆函数
React 操作 js 并返回 DOM - 在函数中返回 html 结构
使用 javaScript 的组件后缀名为 .jsx
使用 TypeScript 的组件后缀名为 .tsx
更多信息，请访问 Creating and nesting components、Your First Component
管理组件
在 src 目录下创建 components 目录并集中管理
简单逻辑组件可以直接创建
复杂逻辑如嵌套组件，使用同名文件夹管理，主组件使用 index 命名，便于使用；组件函数名仍然要和文件夹名保持一致
组件对应的样式使用 module 隔离
 src
   components
     HelloWorld
       index.jsx
       HelloWorld.module.css
       Other.jsx
       Other.module.css
     Rank.jsx
创建组件
组件函数名和组件文件名保持一致
组件名必须 大写 开头 - React component names must always start with a capital letter, while HTML tags must be lowercase
单一根节点 - shared parent
必须闭合
可以是空标签 - empty <>...</> wrapper
为了避免自动插入分号，return 使用 ()
如果返回只有一行代码，可以省略()；但是不建议

扩展 ES7+ React/Redux/React-Native/JS snippets

PascalCase：大驼峰命名；每个单词的首字母都大写，单词之间没有空格或分隔符

camelCase：小驼峰命名法；第一个单词的首字母小写，后续每个单词的首字母大写，单词之间没有空格或分隔符

snake_case：蛇形命名法；所有字母均小写，单词之间使用下划线 _ 连接

使用具名函数创建组件
  1. 在 src 目录下创建组件目录 components
  2. 创建 helloworld 目录
  3. 创建 index.jsx 文件
  4. 输入 rfce 快速创建具名函数组件结构
    5. import React from 'react'

function index() {
  return (
    <div>index</div>
  )
}

export default index
  5. 修改函数名 index 为 HelloWorld
    6. import React from 'react'

function HelloWorld() {
  return (
    <div>HelloWorld</div>
  )
}

export default HelloWorld

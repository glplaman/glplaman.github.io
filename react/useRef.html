引用

@useRef
创建一个对元素的引用(Reference)
以便访问(Access)其 DOM 或 DOM 数据
多用于表单
可以应用于普通 DOM 元素
也可以应用于组件
更多信息，请访问 useRef
Steps
  1. 引入
    2. import { useRef } from "react"
  2. 创建引用
    3. const ipt = useRef()
  3. 为元素指定引用
    4. <input type="text" ref={ipt} />
  4. 在逻辑中访问 input 及其值
    5. ipt.current
    ipt.current.value

组件引用

在父组件中访问子组件实例
以便在父组件中调用子组件 暴露 的方法或属性
父组件中创建 ref，并将其作为 prop 传递给子组件
引用组件内部的函数组件
这里定义的2个 ref：ipt 用于普通元素；tmp 用于内部的函数组件
import { useRef } from "react"
// 函数组件
const Test = (props) => {
  return (
    // 指定 ref 属性！！！
    <div ref={props.ref}>test</div>
  )
}
const UseRef = () => {
  const ipt = useRef()
  const tmp = useRef()
  const handleIpt = () => {
    console.log(ipt.current);
    console.log(tmp.current);
  }
  return (
    <>
      <input type="text" ref={ipt} onChange={handleIpt} />
      <Test ref={tmp}></Test>
    </>
  )
}

export default UseRef
引用普通组件
子组件不需要引入 useRef：因为并没有创建新的 Ref，它只是把父组件给它的这个引用，原封不动地交给了它内部的元素
const Test = ({ ref }) => {
  return (
    <>
      <input type="text" ref={ref} />
    </>
  )
}

export default Test
父组件正常引入、创建并分配 ref
import { useRef } from "react"
import Test from "./Test"

const UseRef = () => {
  const ipt = useRef()
  const tmp = useRef()
  const handleIpt = () => {
    console.log(ipt.current);
    console.log(tmp.current.value);
  }
  return (
    <div>
      <input type="text" ref={ipt} onChange={handleIpt} />
      <Test ref={tmp}></Test>
    </div>
  )
}

export default UseRef

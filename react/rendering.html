Conditional rendering

条件渲染 - Show some content conditionally
更多信息，请访问 Conditional rendering 、Conditional rendering
if
在逻辑中使用
无法在结构中直接使用
const getAge = (age) => {
  if (age > 18) {
    return "成年";
  } else {
    return "未成年";
  }
};
<p>{getAge(user.age)}<p>
?:
三元操作符 ternary operator
直接在结构中使用数据
适合简单逻辑
<button disabled={isLoading}>submit</button>
<div>{isLoading ? "加载中" : ""}</div>
<p>{age > 18 ? "成年" : "未成年"}<p>
也可以先在逻辑中处理好数据，再在结构中使用
const age: number = 18;
const getAge = age > 18 ? "成年" : "未成年";
<p>{getAge}<p>
&&
使用逻辑运算符 && 的短路特性
先判断数据是否符合要求再使用
代码更健壮
如数据是否存在？数组长度是否为空？
show && <p>hi,there.</p>
Best Practice 最佳编码体验
分开写（Early Return）更适合逻辑控制
避免嵌套地狱：一旦状态变多（比如加上“空数据 Empty State”、“权限不足”等），三元运算符 ? : 会层层嵌套，代码变得极难阅读
优化 DOM 结构：为了包裹这些条件判断，通常需要最外层套一个容器，这有时会影响 CSS 布局
// 1. 加载中...
if (loading) return <p>加载中...</p>;

// 2. 出错了...
if (error) return <p>获取失败: {error}</p>;

// 3. 正常展示
return (
    <>
       <p>你的结构</p> 
    </>
);

Rendering lists

列表渲染 - Displaying a list
渲染集合中的数据，如数组
使用 key 区分数据项 - Each child in a list should have a unique "key" prop.
可以嵌套使用
更多信息，请访问 rendering-lists、Rendering lists
map()
使用 map 可以对数据源进行2次加工
示例
参考数据
const users = [
  { id: 0, name: "gl", gender: "male" },
  { id: 1, name: "gz", gender: "female" },
  { id: 2, name: "sz", gender: "male" },
];
方案1：在结构直接处理并使用数据；适合简单逻辑，不需要额外处理数据的情况
<ul>
  {users.map((item) => (
    <li key={item.id}>{item.name}</li>
  ))}
</ul>
方案2：先在逻辑中处理数据，再在结构中使用处理好的数据；适合复杂逻辑
const items = users.map((item) => <li key={item.id}>{item.name}</li>);
<ul>{items}</ul>
filter()
渲染指定数据
先过滤再渲染
建议先处理数据再使用
const items = users.filter((item) => item.gender == "male")
  .map((item) => <li key={item.id}>{item.name}</li>);

Rendering Object

方案1：少量数据
使用点语法
示例
数据
const address={ district: "xxx", city: "ay", province: "gx", code: "455112" }
使用
<p>城市：{address.city}</p>
<p>街道：{address.xxx}</p>
方案2：大量数据
不能直接使用列表渲染的方法直接渲染对象
使用 Object.entries() 将对象转换为二维数组，包括键 key、值 value，然后再用 .map() 渲染
示例
const address={ district: "xxx", city: "ay", province: "gx", code: "455112" }
数据全部使用
<ul>
  {Object.entries(address).map(([key, value]) => (
    <li key={key}>{key}-{value}</li>
  ))}
</ul>
数据部分使用；使用值 value；key 留空；会触发 key 告警
<ul>
  {Object.entries(address).map(([, value]) => (
    <li>{value}</li>
  ))}
</ul>

import "./demo.css";
interface Address {
  district: string;
  city: string;
  province: string;
  code: string;
}

interface User {
  id: number;
  name: string;
  age: number;
  gender: string;
  address: Address;
  msg: number[];
}

function Demo() {
  const users: User[] = [
    { id: 0, name: "gl", age: 18, gender: "male", address: { district: "xxx", city: "ay", province: "gx", code: "455112" }, msg: [0, 1, 2] },
    { id: 1, name: "gz", age: 15, gender: "female", address: { district: "yyy", city: "gl", province: "gd", code: "541000" }, msg: [0, 1, 2] },
    { id: 2, name: "sh", age: 28, gender: "male", address: { district: "zzz", city: "sh", province: "js", code: "200240" }, msg: [0, 1, 2] },
  ];

  const getMsg = (list: number[]) => {
    return list.length ? list.map((item) => <li key={item}>{item}</li>) : "暂无";
  };

  const getAddress = (obj: Address) => {
    return Object.entries(obj).map(([key, val]) => <li key={key}>{val}</li>);
  };

  const getGender = (gender: string) => (gender == "male" ? "男" : "女");

  const getAge = (age: number) => (age > 18 ? "成年" : "未成年");

  const items = users.map((item) => {
    return (
      <li key={item.id}>
        <p>Name：{item.name}</p>
        <p>Age：{getAge(item.age)}</p>
        <p>Gender：{getGender(item.gender)}</p>
        <p>Address：</p>
        <ul>{getAddress(item.address)}</ul>
        <p>Message：</p>
        <ul>{item.msg.length ? getMsg(item.msg) : "暂无"}</ul>
      </li>
    );
  });

  return (
    <>
      <ul>{items}</ul>
    <>
  );
}
export default Demo;

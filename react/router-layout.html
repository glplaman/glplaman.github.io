路由布局

@Layout
Overview
布局组件 Layout Component 是一种共享 UI（如 Header、Footer、Sidebar）与页面内容解耦的优雅方案
可以为不同路由组分配不同布局（如“带导航的主应用布局” vs “无导航的登录页布局”）
避免在每个页面重复编写相同的 UI 结构
保持路由配置的声明性和可维护性
<Outlet />
通过 <Outlet /> 占位符实现子路由内容的动态渲染
如果布局组件中没有 <Outlet />，子路由内容将无法渲染
页面路由
Home、Work、Team、Rank：需要导航
Contact：不需要导航

如果 Rank 需要头部 Header、底部 Footer，但是不需要主导航 MainNav。如何实现？
新增加一个布局组件 LayoutRank
<>
  <Header />
  <main>
    <Outlet />
  </main>
  <Footer />
</>
在路由设计中为 Rank 指定该布局组件
<BrowserRouter>
  <Routes>
    <Route element={<Layout />}>
      <Route path="/" element={<Home />} />
      <Route path="/work" element={<Work />} />
      <Route path="/team" element={<Team />} />
      <Route path="/rank" element={<Rank />} />
    </Route>
    <Route element={<LayoutRank />}>
      <Route path="/rank" element={<Rank />} />
    </Route>
    <Route path="/contact" element={<Contact />} />
  </Routes>
</BrowserRouter>

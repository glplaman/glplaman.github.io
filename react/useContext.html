@useContext
在 React 中，跨层级数据传递依赖于 Context API，主要涉及三个核心部分：createContext、Provider 和 useContext
同 Vue 相比，React 语法相对复杂
Steps
  1. 创建上下文：使用 createContext 创建一个 Context 对象，该对象本身不包含信息，仅作为信息的载体，并可指定一个默认值
  2. 提供数据：在组件树的上层，使用 Context.Provider 包裹子组件，将状态或数据通过 value 属性传递下去
    3. <Context.Provider value={...}>
    或
    <Context value={...}>
  3. 读取数据：在下层任意深度的组件中，通过调用 useContext(SomeContext) Hook 来读取并订阅该上下文。当 Context 的值发生变化时，React 会自动重新渲染读取了该 Context 的组件
页面切换
  1. 创建上下文目录 context 并创建文件 index.jsx
    2. import { createContext, useState } from "react";

const MyCtx = createContext();

const MyProvider = (props) => {
  const [stage, setStage] = useState(false)

  return (
    <>
      <MyCtx.Provider value={{
        // your share data here
        stage,
        setStage
      }}>
        {props.children}
      </MyCtx.Provider>
    </>
  )
}
export {
  MyCtx,
  MyProvider
}
  2. 在主文件 main.jsx 引入 MyProvider 并包裹 App
    3. import { MyProvider } from "./context/index.jsx";
    <MyProvider>
  <App />
</MyProvider>
  3. 在 App 中引入上下文 MyCtx 及使用的组件 Login、Register
    4. import Login from "./components/Login";
import Register from './components/Register'
import { MyCtx } from "./context";
  4. 实例化上下文并使用
    5. const ctx = useContext(MyCtx)
  5. 添加业务逻辑
    6. <>
  {ctx.stage ? <Login></Login> : <Register></Register>}
  <button onClick={() => ctx.setStage(!ctx.stage)}>switch stage</button>
</>

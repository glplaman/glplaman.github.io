路由

@Router
基本路由
每个路由对应一个文件夹 - 文件夹即路由
路由对应的视图文件 view 必须是 page.tsx
路由可以嵌套
路由示例

创建文件夹 team

在 team 文件夹创建视图文件 page.tsx；组件名/函数名同文件夹名

export default function Team() {
  return <div>hi, team</div>;
}

在浏览器中访问路由

http://localhost:3000/team
嵌套路由
以嵌套文件夹的形式指定
单独布局
以上为共享布局
每个路由可以定制自己的布局 layout.tsx
组件名为路由名+Layout
export default function TeamLayout({ children }: Readonly<{ children: React.ReactNode }>) {
  return (
    <div>
      <h1>Demo</h1>
      {children}
    </div>
  );
}
动态路由
创建路由文件夹的时候，使用 [] 额外指定动态路由参数 params
在 IDE 中推荐使用创建文件的方式指定路由和 params
team/[id]/page.tsx
在 page.tsx 中使用异步-等待获取路由参数 params 并使用
export default async function House({ params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  return <div>hi, house {id}</div>;
}

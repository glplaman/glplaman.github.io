累计归约

@useReducer
是一个迭代方法
设计同数组的 Array.prototype.reduce()；按照一定顺序对数组中所有元素执行特定回调函数并累计为一个值
React 中用来管理状态
更多信息，请访问 useReducer
Syntax
const [state, dispatch] = useReducer(reducer, initialArg, init?)
reducer：回调函数；接受2个参数

state：状态

action：指令/动作；完成状态转化的关键

const reducer = (state, action) => {}
initialArg：初始值
init：可选；初始值

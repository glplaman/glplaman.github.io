组件嵌套

@Children
像普通 html 标签嵌套那样，使用 children 实现组件嵌套
在组件内部整合
<Super>
  <Child />
</Super>
引入组件
import Rank from "./Rank";
创建组件；使用 children 属性为嵌套的组件预留位置；可以是任何内容，如多个组件
function Desc({ children }) {
  return (
    <div className="desc">
      <p>desc content start</p>
      {children}
      <p>desc content end</p>
    </div>
  );
}
整合组件；可以使用多个组件
export default function Card() {
  return (
    <>
      <Avatar />
      <Desc>
        <Rank />
      </Desc>
    </>
  );
}

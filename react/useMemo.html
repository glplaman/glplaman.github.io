缓存

@useMemo
在组件 渲染期间 执行，必须是纯函数
用于性能优化的 Hook
核心作用是缓存复杂计算的结果。类似于 Vue 中的 computed
不能执行副作用；像请求接口、修改 DOM 等操作绝对不能放在里面，应使用 useEffect
const memoizedValue = useMemo(() => {
  // 执行耗时的计算逻辑
  return expensiveCalculation(a, b);
}, [a, b]); // 依赖数组
工作机制：只有当依赖数组（如 [a, b]）中的值发生变化时，才会重新执行计算函数。如果依赖项不变，它会直接返回上一次缓存的结果，从而跳过不必要的计算

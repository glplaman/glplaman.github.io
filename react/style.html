引入并使用
React 使用 className 取代 class 作为元素的样式类
默认是全局样式：某组件引入后，会影响到其它使用样式类的组件
import './reset.css';
<div className = "warn">Notice</div>
导航菜单
包括基本样式和高亮样式
菜单项选中时，应用高亮样式类 active
ind 是响应式数据，表示当前选择的菜单项
使用三元表达式 ?:
<div className={ind == 0 ? "active" : ""}>home</div>
<div className={ind == 1 ? "active" : ""}>work</div>
<div className={ind == 2 ? "active" : ""}>team</div>
<div className={ind == 3 ? "active" : ""}>about</div>
多个类的情况下，使用 模板字符串
所以：整体使用嵌套双花括号 {{}}
<div className={`link ${ind == 3 ? "active" : ""}`}>about</div>

CSS Module

使用 CSS module 实现样式隔离
作用域仅限当前组件
文件组织
src
   components
     HelloWorld
       index.jsx
       HelloWorld.module.css
       Other.jsx
       Other.module.css
     Rank.jsx
命名规则
组件文件
xxx.jsx
组件样式文件：使用 module 标识
xxx.module.css
在组件中引入到 styles 中再使用
import styles from './xxx.module.css';
<div className={styles.warn}>hi,there</div>
编译后，会带上组件对应的哈希；如 warn_xxx
如果类名是蛇形命名 snake_case，使用数组形式
<div className={styles['menu-item']}>hi,there</div>
全局样式和 Module 样式混用
<NavLink className={`nav-item ${styles['nav-item']}`} to='/about'>test</NavLink>

内联样式 Inline Style

仍然使用数据绑定方式， style={}；并提供一个样式对象 - 值对
整体使用双花括号 {{}}：外层括号“进入 JS 世界”，内层括号“定义一个对象”
对象是键值对，所以属性值必须使用引号；且复合属性不支持连字符 -；应使用小驼峰，如 fontSize
静态样式
<div style={{fontWeight: '600'}}>hi,there.</div>
<div style={{color: '#f40'}}>hi,there.</div>
<div style={{borderBottom: '1px solid #f40'}}>hi,there.</div>
动态样式
其中，m 是响应式数据
<div style={{margin: m + 'px'}}>hi,there.</div>
<div style={{fontSize: m + 'px'}}>hi,there.</div>

练习 Drill

使用动态类 - 表单验证
使用 <input> 的 text
密码长度不够，以告警类 warn，如红色字体提示
<div className={upass.length < 6 ? "warn" : ""}>length at leaset 6</div>
提前 计算 derived state 类名；适合复杂条件
const warnClass=upass.length < 6 ? "warn" : ""
<div className={warnClass}>length at leaset 6</div>
使用动态类 - 用户须知
使用 <input> 的 checkbox
单击后为真，否则为假
flag 和 setFlag 为响应式数据
e.target.value 默认是 on，和是否选中无关
应检查 e.target.checked
<label>
  <input type="checkbox" name="cb" onChange={(e) => setFlag(e.target.checked)} />
  <span className={flag ? "" : "warn"}>Lorem ipsum dolor sit.</span>
</label>
直接取反
<label>
  <input type="checkbox" name="cb" onChange={() => setFlag(!flag)} />
  <span className={flag ? "" : "warn"}>Lorem ipsum dolor sit.</span>
</label>
使用动态类 - 切换主题
使用下拉菜单 <select>
theme 和 setTheme 是响应式数据
dark 和 light 是对应的主题样式类
<select name="theme" onChange={(e) => setTheme(e.target.value)}>
  <option value="">Please Select</option>
  <option value="dark">dark</option>
  <option value="light">light</option>
</select>

<div className={theme}>hi,there</div>

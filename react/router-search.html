查询路由

@useSearchParams
Overview
查询路由使用?和值对拼接
查询路由无需事先定义；可以直接使用
<NavLink to='test?id=1010'>test</NavLink>
引入并使用
import { useSearchParams } from "react-router"
使用 useSearchParams 解析/获取查询路由 search 参数
调用 Hook，返回一个数组（类似 useState）
const [params, setParams] = useSearchParams()
id = params.get('id')
searchParams 本质上是一个 URLSearchParams 对象，常用的方法有：

get(key): 获取指定 key 的值（字符串）。如果 key 有多个值，只返回第一个

getAll(key): 获取指定 key 的所有值（数组），适用于 ?tag=js&tag=react 这种情况

has(key): 判断是否存在某个 key，返回布尔值

entries(): 遍历所有参数

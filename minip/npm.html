包管理

@NPM
  • 需要 Node.js 环境支持
  • 更多信息，请访问 NPM

Steps

  1. 定位到小程序的 miniprogram 目录；默认包管理目录
  2. 初始化；也可以通过安装依赖强制生成，但是会丢失部分信息，不建议
  3. 安装依赖
  4. 构建 NPM；构建完毕后，目录 miniprogram 变为 miniprogram_npm
  5. 引入包 - require
  6. 使用包

手动构建 NPM

  • 也可以通过修改配置更改小程序的包管理目录，如更改至在项目根目录
  • 打开项目配置文件 project.config.json，修改相关字段如下
  • 重新启动开发者工具
  • 执行构建
    • "packNpmManually": true,
"packNpmRelationList": [
  {
    "packageJsonPath": "./package.json",
    "miniprogramNpmDistDir": "./miniprogram/"
  }
],
[] 使用 Day.js 格式化 日期和时间

云函数端使用

云函数单独使用

  • 每个云函数除了主逻辑文件 index.js 外，还有一个 package.json，用以管理 NPM
  • 定位到当前云函数目录，安装依赖并引入、使用
  • 不需要上传 module

包管理

@NPM
  • 需要 Node.js 环境支持
  • 更多信息，请访问 NPM

Steps

  1. 在小程序 package.json 所在的目录中执行命令安装 npm 包：也就是项目根目录；不是小程序的 miniprogram 目录
  2. 构建 NPM；构建完毕后，目录 miniprogram 变为 miniprogram_npm
  3. 引入包
  4. 使用包

手动构建 NPM

  • 打开项目配置文件 project.config.json，修改相关字段如下
  • 重新启动开发者工具
  • 执行构建
    • "packNpmManually": true,
"packNpmRelationList": [
  {
    "packageJsonPath": "./package.json",
    "miniprogramNpmDistDir": "./miniprogram/"
  }
],
[] 时间格式化 Day.js
  1. 安装依赖

    2. . 在小程序项目根目录空白处，右键 → 打开内建终端|小黑屋；或在选择 "在外部终端窗口中打开"

    npm install dayjs
  2. 构建 NPM

    3. . 菜单栏 → 工具 → 构建 npm

  3. 引入包

    4. . 在逻辑中引入

    const dayjs = require('dayjs')
  4. 使用包

    5. . 默认格式 - 使用当前时间

    console.log(dayjs().format());

    . 指定格式 - 使用某个日期变量

    console.log(dayjs(var_date).format('YYYY-MM-DD HH:mm:ss'));

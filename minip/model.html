双向绑定

@model

概述 Overview

  • Two-way binding
  • 视图层可以影响到逻辑层
  • 逻辑层也可以影响到视图层
  • 视图层 逻辑层
  • 多用于表单元素的：value、checked、selected 等
  • 目前只支持绑定 简单数据类型 （如字符串、数字、布尔值），不支持对象（Object）或数组（Array）等复杂数据结构
  • 推荐这些元素使用：input 的 value 是字符串 string；checkbox 的 checked 是布尔值 boolean；slider 的 value 是数字 number
  • 更多信息，请访问 简易双向绑定

特点 Feature

  • 为 value 添加 model 修饰符即可实现双向数据绑定
  • 只能是一个单一字段的绑定，不支持复杂表达式
  • 省略了触发事件，如 bindchange 或 bindinput
  • 可以抛弃 <form> 这个壳
  • 借助调试器的 AppData 查看绑定情况

值绑定

. 绑定的是元素的值 value

<input>

  • 添加 model 前缀即可
    • <input type="text" model:value='{{msg}}' />
  • 无法双向绑定复合数据
    • <input type="text" model:value='{{obj.name}}' />
  • 失败：仅实现逻辑层到视图层的绑定；Two-way binding does not support complex data paths currently. This two-way binding is ignored.
  • 调整：还原为普通事件流 bindchange
    • <input type="text" value='{{obj.name}}' bindinput="getName"/>
    getName(e) {
    this.setData({
        'obj.name':e.detail.value

[] 商品搜索
  • 根据商品名称部分或全部关键字搜索
  • 单击搜索按钮触发搜索 - 普通事件
  • 输入完毕后，按输入/搜索建触发搜索；需指定确认类型 confirm-type 和确认事件 bindconfirm
  • 页面加载时，自动获取焦点
  • 搜索前，移除前后空白
  • 如果处理结果为空，则给出提示；否则执行搜索，并根据搜索结果渲染页面
  • 请分别在模拟器和移动端测试
    • <view>
  <view>
    <text class="iconfont icon-search"></text>
    <input type="text" 
      focus 
      placeholder="请输入你要查询的商品名称" 
      confirm-type="search" 
      bindconfirm="doQuery" 
      model:value='{{keywords}}' />
  </view>
  <button bind:tap="doQuery">搜索</button>
</view>

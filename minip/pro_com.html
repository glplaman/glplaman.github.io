底线组件 deadline
页面抵达底部时或者没有更多数据可以加载时，给出提示
逻辑：需要一个提示信息，字符串类型，指定默认内容
properties: {
  tips: {
    type: String,
    value: '我是有底线的'
  }
}
结构：渲染提示信息
<view class="deadline">- {{tips}} -</view>
样式略
空组件 emptyCom
应用：购物车或收藏等为空时，利用条件渲染展示空组件
属性：图标和标题；图标使用 阿里字体图标 Iconfont
逻辑 - 仅定义图标和标题属性；默认是购物车
properties: {
  icon: {
    type: String,
    value: 'icon-cart-empty'
  },
  title: {
    type: String,
    value: '购物车'
  }
}
结构
<view class="empty-com">
  <text class="iconfont {{icon}}"></text>
  <text>{{title}}空空的，去逛逛吧</text>
</view>
样式 - 使用到了字体图标，需要额外引用一次；其他略
@import '../../utils/iconfont.wxss';
商品组件 product
展示商品图片、名称和价格等基本信息
其它信息使用插槽拓展
逻辑 - 定义一个对象，传递商品信息
properties: {
  product: Object
}
结构
<view class="product">
  <view class="img-wrap">
    <image src="{{product.imageThumb}}" mode="aspectFit" />
  </view>
  <view class="info">
    <view class="title">{{product.title}}</view>
    <view class="item">￥<text class="price">{{product.price}}</text> 销量{{product.sold}}</view>
    <slot name="extra"></slot>
  </view>
  <slot></slot>
</view>
标签组件 tabCard
单击时，当前项为活动项，active 样式类生效
定义一个数组类型的属性 lists，标签列表数据
lists: {
  type: Array,
  value: []
}
定义自己的数据 ind，用来指示当前高亮项
ind: 0
定义组件方法 selTab：标签切换及事件触发；使用事件对象获取携带的参数
selTab(e) {
  const ind = e.currentTarget.dataset.ind
  this.setData({
    ind
  })
  this.triggerEvent('tabTap', ind)
}
数据列表渲染；绑定自定义属性；指定事件处理函数
<view class="tab-card card-item">
  <view class="tab-item {{ind==index?'active':''}}" wx:for="{{lists}}" wx:key="id" data-ind='{{index}}' bind:tap="doTab">
    <text>{{item.label}}</text>
    <text class="iconfont {{item.icon}}"></text>
  </view>
</view>

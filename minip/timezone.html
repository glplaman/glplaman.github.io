日期和时间

@UTC

UTC

  • Universal Time Coordinated
  • 协调世界时，又称世界统一时间、世界标准时间、国际协调时间
  • 标准时间 UTC+0
  • 北京时间 UTC+8

时间戳

  • 没有时区的概念
  • Date.now()

    静态方法：直接调用，无需创建 Date 实例，性能更好

    返回值：从1970年1月1日00:00:00 UTC 开始的毫秒数

  • new Date().getTime()

    实例方法：需要先创建 Date 对象，再调用 getTime()

    返回值：同样是从1970年1月1日00:00:00 UTC 开始的毫秒数

    功能相同：与 Date.now() 返回相同结果

小程序端时间

  • 北京时间 UTC+8

服务器端时间/云端时间

  • 标准时间 UTC+0
  • db.serverDate() 是一个数据库服务器时间占位符对象
  • 控制台会自动将时间转换为你的本地时区（如 UTC+8）展示 - 时区转换
  • 只能在小程序端直接用于数据库操作
  • 当通过云函数调用传递时，它会被序列化为普通对象，失去特殊含义，甚至告警
使用
  1. 小程序端直接操作数据库，无论是使用小程序端时间还是服务器端时间，控制台都会正常显示为北京时间
    2. db.collection('test').add({
  data: {
    timeC: new Date(),
    timeS: db.serverDate(),
  }
})
  2. 使用云函数，不传递时间；效果同上
    3. wx.cloud.callFunction({
  name: 'test',
})
    const res = await db.collection('test').add({
  data: {
    timeCloudC: new Date(),
    timeCloudS: db.serverDate(),
  }
})
  3. 使用云函数

    传递本地时间：时间会少8个小时；CloudBase 会认为小程序端传递过来的是UTC+0，会自动-8个小时，转换为UTC+8显示；但是会保存为 String 类型，丢失了日期特点，如无法参与排序

    wx.cloud.callFunction({
  name: 'test',
  data: {
    time: new Date(),
  }
})

    传递服务器端时间：告警；无法传递服务器端时间

    wx.cloud.callFunction({
  name: 'test',
  data: {
    time: db.serverDate()
  }
})

最佳编码体验

  • 优先使用服务器端时间或在服务器端创建时间
  • 如果需要传递参数，在小程序端传递时间戳给服务器端，由服务器端根据时间戳生成时间
    • wx.cloud.callFunction({
  name: 'test',
  data: {
    time: new Date().getTime()
  }
})
    const time = new Date(event.time)
  • 如果直接保存时间，宜采用日期格式，方便排序
  • 前端展示时，可以根据需要格式化，如借助 dayjs 或手动格式化；否则需要+8个小时
小程序端格式化时间
  • YYYY-MM-DD HH:mm:ss
  • 2025-09-29 17:48:36
  • 定位到 miniprogram 目录；右键单击，选择内建终端打开
  • 初始化；如果没有包管理文件 package.json，需要初始化；只需初始化一次
    • npm init -y
  • 安装
    • npm i dayjs
  • 构建 NPM：工具 → 构建 NPM
  • 引入
    • const dayjs = require('dayjs');
  • 使用

    格式化日期

    const dd= dayjs(new Date()).format('YYYY-MM-DD HH:mm:ss')
console.log(dd);

    格式化字符串；需要指定字符串映射格式

    const str= dayjs('2025-09-29 17:48:36', 'YYYYMMDDHHmmss').format('YYYY-MM-DD HH:mm:ss');
console.log(str);
云端格式化时间
  • 在对应的云函数目录下安装依赖并使用
  • 更多信息，请访问 NPM
时间排序
  • 日期类型可以直接排序
    • arr.sort((a, b) => a.time - b.time)
  • 生成的时间转换为String，无法直接排序
    • time = new Date().toLocaleString()
  • 需借助 localeCompare()
    • arr.sort((a, b) => a.time.localeCompare(b.time))

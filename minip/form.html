表单 <form>
表单容器；行内元素 inline
默认情况下，表单大小为0，即使添加了表单元素
生产环境下，通常是 垂直方向 分布各表单元素
布局上，为了 优雅分隔 各表单元素，通常增加一个内层元素 <view>，由它布局，而仅仅将 <form> 当作一个 功能元素 
<form bindsubmit="submit">
    <view class="form-cont">
        // 其它表单元素
        //按钮指定表单类型，可以触发表单的默认提交行为
        <button form-type="submit">submit</button>
    </view>
</form>
提交时，可以在事件对象 e.detail 中获取表格各元素的值；需要配合指定了 form-type 为 submit 属性的按钮 <button> 一起使用
多数情况下，抛弃表单元素 <form>，使用普通结构，通过 数据双向绑定 和自定义事件提交数据
submit(e) {
    console.log(e.detail);
}

业务 - 全选/全不选
  • 购物车中商品的操作
  • 如果全选为真，则所有商品为选中状态
  • 如果全选为假，则所有商品为取消状态
  • 只有所有商品都是选中状态，全选才为真
  • 只要有一个商品是取消状态，则全选为假
  • 数据：每个商品数据有有一个字段 selected 用来标记是否为选中状态
    • data:{
  carts:[],
  isAll: false
}
  • 商品列表渲染：每个商品项和一个 <checkbox> 关联并绑定 tap 事件 toggleItemSelection；使用自定义数据携带 id，便于修改其选择状态；其它内容略
    • <view wx:for="{{carts}}" wx:key="item">
  <checkbox checked="{{item.selected}}" bind:tap="toggleItemSelection" data-id='{{item.id}}' />
  // ...
</view>
  • 全选 <checkbox> 并绑定 tap 事件 toggleSelectAll
    • <label>
  <checkbox checked="{{isAll}}" bind:tap="toggleSelectAll" />全选
</label>
  • 全选逻辑：获取商品数据 carts 和全选标记 isAll；如果 isAll 之前是假，单击后，将变为真；所以将 isAll 取反后给每一个商品更新状态；最后更新数据
    • toggleSelectAll() {
  const {
    carts,
    isAll
  } = this.data
  carts.map(cart => cart.selected = !isAll)
  this.setData({
    carts,
    isAll: !isAll
  })
}
  • 单个商品的选择状态逻辑：获取所有商品数据及当前商品数据 id；取反当前商品数据的状态状态；然后根据当前所有商品数据的选择状态，决定 isAll 的真假；使用数组方法 every 实现 - 只要每一个商品数据都是选中状态， isAll 才是真；否则为假；最后更新数据
    • toggleItemSelection(e) {
  console.log(e.currentTarget);
  const {
    carts
  } = this.data
  const id = e.currentTarget.dataset.id
  const updatedCarts = carts.map(cart => {
    if (cart.id == id) {
      cart.selected = !cart.selected
    }
    return cart
  })
  const isAll = updatedCarts.every(cart => cart.selected)
  this.setData({
    carts: updatedCarts,
    isAll
  })
}

<picker>
块元素 block
从底部弹起的滚动选择器，如：时间选择器、日期选择器、地区选择器
除了下述通用的属性外，不同的 mode，picker 拥有不同的属性；如时间类的都有开始 start、结束 end 等
内部结构和样式受到一定限制，不能像普通 view 组件那样直接使用弹性盒子 Flexbox来控制其内部元素的排列
在内部增加一个子容器，对该容器使用 Flex，见后续案例

item desc

time：时间选择器；hh:mm

region：省市区选择器
range 数据列表|范围
bindcancel 取消选择时触发
bindchange 选择时触发

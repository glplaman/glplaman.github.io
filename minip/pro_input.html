昵称 Nickname
  • 用户中心
  • 可以直接获取昵称
  • 还可以手动输入，并使用软键盘确定
    • <input type="nickname" 
    value="{{userInfo.userName}}" 
    placeholder="your nickname" 
    confirm-type="done" 
    bindinput="onIpt"
    bindconfirm="onIptConfirm" />
  • 定义数据绑定
    • userInfo: {
  userName: ''
}
  • 使用 bindinput() 修改数据
  • 为了防抖，可以把视图更新放在确认 bindconfirm()
    • onIpt(e) {
  this.data.userInfo.userName = e.detail.value
}
  • 使用 bindconfirm() 更新数据
  • 如果选择了用户昵称，则不会有 log()
  • 如果其他业务中有需要更新视图的数据，则一起更新输入数据，避免多次 setData()
    • onIptConfirm(e) {
  console.log('confirm', e);
  this.setData({
    'userInfo.userName': e.detail.value
  })
  // 其他业务，如入库
}
搜索 Search
  • 与修改昵称不同，用户还可以单击按钮开始执行逻辑
  • 结构上多了一个按钮，并绑定事件处理函数；同输入确认事件函数
  • 事件处理函数是共享的，所以只能获取数据；无法获取使用事件对象
  • 其它：自动聚焦；软键盘为搜索
    • <input type="text" focus 
    value='{{keywords}}'
    placeholder="请输入你要查询的商品名称" 
    confirm-type="search" 
    bindinput="setQuery" 
    bindconfirm="doQuery" />
<button bind:tap="doQuery">搜索</button>

  this.data.keywords = e.detail.value

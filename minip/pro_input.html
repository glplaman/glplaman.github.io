<input type="nickname" 
    value="{{userInfo.userName}}" 
    placeholder="your nickname" 
    confirm-type="done" 
    bindfocus="onIptFocus"
    bindinput="onIpt"
    bindconfirm="onIptConfirm"
    bindblur="onIptBlur" />
数据
userInfo: {
  userName: '',
}

tmp: ''
使用 onIptFocus()：获取焦点时候，保存当前值
onIptFocus(e) {
  this.data.tmp = this.data.userInfo.userName
  console.log('focus');
}
使用 bindinput()：改变当前值
onIpt(e) {
  this.data.userInfo.userName = e.detail.value
  console.log('input');
},
使用 bindconfirm()：改变当前值
onIptConfirm(e) {
  this.data.userInfo.userName = e.detail.value
  console.log('confirm');
},
onIptBlur()：失去焦点时，判断前后是否相等；相等返回；不等则更新当前值；代码略

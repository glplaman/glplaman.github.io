<swiper-item>
轮播项
仅可放置在 swiper 组件中
宽高自动设置为100%
通用属性 - swiper
item desc
indicator-dots 指示器
indicator-color 指示器颜色
indicator-active-color 当前指示器颜色
autoplay 自动播放；false
current 当前项目索引；0
interval 自动切换时间间隔；5000
duration 滑动动画时长；500
circular 是否采用衔接滑动；false
vertical 纵向；false
bindchange current 改变时会触发；可以获取当前项：e.detail.current
bindtransition swiper-item 的位置发生改变时会触发
bindanimationfinish 动画结束时会触发
自动、循环轮播图
这里使用静态数据
使用列表渲染结构，仅仅改变图片的名字；适合数据相对固定的情况
指定循环、自动播放以及指示器的样式
<swiper class="swiper" indicator-dots indicator-color="#fff" indicator-active-color="#f40" autoplay circular>
  <swiper-item wx:for="{{5}}" wx:key="index">
    <image class="img" src="https://glplaman.github.io/utils/car/car{{index}}.png" mode="aspectFill" />
  </swiper-item>
</swiper>
也可以把请求地址设置为一个数据变量
指定样式

没有使用额外容器

宽度：通栏显示；100%

高度：16/9；aspect-ratio 在小程序的兼容性不是很好，谨慎使用

.swiper{
  height: calc(100vw/16*9);
}
// 也可以在全局样式中定义
.img{
  width: 100%;
}
封装为组件使用
加载外部数据
大树小站 请求图片，或自行准备资源服务器
在页面的 onLoad() 中请求；imgs 是 data 中的定义的数据
wx.showLoading({
  title: 'Loading...',
})
wx.request({
  url: 'https://glpla.github.io/utils/data/swiper.json',
  success: res => {
    this.setData({
      imgs: res.data.cont
    })
  },
  fail:err=>{
    console.log(err);
    },
  complete:()=>{
    console.log('done');
    wx.hideLoading()
  }
})
<swiper class="swiper" indicator-dots indicator-color="#fff" indicator-active-color="#f40" autoplay circular>

    <image class="img" src="{{item.url}}" mode="aspectFill" />
  </swiper-item>
</swiper>

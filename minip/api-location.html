Component

<map>
  • 渲染地图
  • 以属性的形式设置各种地图插件
  • 默认大小 300*150
<map id="myMap" show-location />
常用属性
item desc
longitude 经度；必填；数值 number
latitude 纬度；必填；数值 number
show-location 显示带有方向的当前定位点
show-scale 显示缩放标尺
show-compass 显示罗盘
markers
在地图上显示标记的位置；结合地图服务API - 地点搜索实现
latitude：标记经度； 必填
longitude：标记维度； 必填
iconPath：标记图片路径； 必填
id：标记id；数值 number；每个标记的 id 应该不同； 必填
width：标记宽度；实际开发 必填
height：标记高度；实际开发 必填
label：标签；在标记下方显示信息；对象类型
callout：单击标记，在上方显示content信息，单击地图其它地方，信息消失；对象类型
bindtap 单击地图，获取单击点经纬度信息
bindmarkertap 单击地图标记，获取标记点id
bindcallouttap 单击标记的气泡触发
bindlabeltap 单击标记的标签触发

API

wx.createMapContext(string mapId, Object this)
  • 深入控制地图：根据地图组件 map 的 mapId 创建其上下文 MapContext 对象，与地图交互
  • 不需要显示的使用 #
Page({
  onReady: function (e) {
    // 使用 wx.createMapContext 获取 map 上下文
    this.mapCtx = wx.createMapContext('myMap')
  }
})
MapContext 常用方法
item desc
getCenterLocation(Object object) 获取当前地图中心的经纬度；返回 gcj02 坐标系，可以用于 wx.openLocation()
moveToLocation(Object object) 将地图中心移置当前定位点；地图组件 需 设置 show-location 为 true；经纬度非必须
addMarkers(Object object) 在地图上添加标记 marker
removeMarkers(Object object) 移除地图上标记 marker
wx.getLocation(Object object)
  • 分类：位置接口
  • 只针对部分限定类目的小程序开放
  • 获取当前的地理位置、速度
  • 需要在 app.json 中声明使用到的 API；详情请查看 具体规则公告
    • "requiredPrivateInfos": [
    "getLocation"
]
  • 默认 type 是 GPS，推荐使用 gcj02
    • "getLocation:fail the api need to be declared in the requiredPrivateInfos field in app.json/ext.json"
  • 需要开通权限：[开发] → [开发管理] → [接口设置]中自助开通
  • 提示：增加调用频率限制
    • wx.getLocation({
    type: 'gcj02',
    success: res => console.log('getLocation ok', res),
    fail: err => console.log('getLocation fail', err)
})
wx.openLocation(Object object)
  • 分类：位置接口
  • 使用微信内置地图查看位置，并将指定的地点居中显示；通常用于在用户需要查看某个特定位置的详细地图和周边情况
  • 如果不提供 latitude 和 longitude，地图将以用户当前位置为中心
  • 坐标必须是数值
  • wx.openLocation() 通常与 wx.getLocation() 或 wx.chooseLocation() 结合使用，先获取位置信息，然后使用这些信息打开地图
  • 会提供返回中心点、导航、打车、收藏等信息
  • 需要在 app.json 中配置权限
    • "permission": {
  "scope.userLocation": {
    "desc": "你的位置信息将用于小程序位置接口的效果展示"
  }
}
    打开桂林市体育中心；坐标可以事先查阅好
    wx.openLocation({
    latitude: 25.252899,
    longitude: 110.309388,
    name: '桂林市体育中心',
    address: '七星区穿山东路12号'
})
wx.chooseLocation(Object object)
  • 需要在 app.json 中声明开放权限
    • "requiredPrivateInfos": [
  "chooseLocation"
]
  • 分类：位置接口
  • 打开地图选择位置
    • chooseLoc() {
    wx.chooseLocation({
        success: res => console.log('chooseLocation ok', res),
        fail: err => console.log('chooseLocation fail', err)
    })
}
wx.choosePoi(Object object)
  • 分类：位置接口
  • 打开 POI 列表选择位置
  • choosePoi:fail 开发者工具暂时不支持此 API 调试，请使用真机进行开发
    • choosePoi() {
    wx.choosePoi({
        success: res => console.log('choose poi ok', res),
        fail: err => console.log('choose poi fail', err)
    })
}
wx.chooseAddress(Object object)
  • 分类：开放接口
  • 获取用户收货地址
  • 调起用户编辑收货地址原生界面，并在编辑完成后返回用户选择的地址
    • chooseAddr() {
    wx.chooseAddress({
        success: res => console.log('chooseAddress ok', res),
        fail: err => console.log('chooseAddress fail', err)
    })
}

练习 Drill

在地图上展示固定位置
  • 多用于广告、营销
  • 先通过 wx.chooseLocation，获取目标地点坐标；也可以使用 经纬度查询，但是精度好像不够
  • 视图：在地图上定位到目标点并通过标记的形式显示目标地点
    • <map class="map" 
  longitude="{{longitude}}" 
  latitude="{{latitude}}" 
  markers="{{markers}}" 
  show-location/>
  • 逻辑：准备中心点坐标数据和一个标记数据
    • data: {
  latitude: '25.242754',
  longitude: '110.319972',
  markers: [{
    id: 0,
    latitude: '25.242754',
    longitude: '110.319972',
    width: 18,
    height: 32,
  }]
}
进阶版
  • 父组件使用地图组件展示位置
  • 地图组件接收父组件的坐标并展示标记
  • 子组件单击标记，传递自定义方法 openLocation 给父组件
  • 父组件处理自定义事件：打开坐标位置
  • 地图组件无法直接使用属性，必须在组件的生命周期函数中赋值
  • 子组件
    • Component({
  properties: {
    latitude: {
      type: Number,
      value: 0
    },
    longitude: {
      type: Number,
      value: 0
    }
  },

  data: {
    markers: [{
      id: 0,
      latitude: 0,
      longitude: 0,
      width: 24,
      height: 32,
    }]
  },

  methods: {
    tapMarker(e) {
      this.triggerEvent('openLocation');
    }
  },
  lifetimes: {
    attached() {
      console.log('hi');
      const lat = this.properties.latitude;
      const lng = this.properties.longitude;
      this.setData({
        'markers[0].latitude': lat,
        'markers[0].longitude': lng
      })
    }
  }
})

  • 在 Page 外部声明全局地图上下文变量 mapCtx，在页面 onLoad 中初始化，可以避免使用 this
  • 在 data 中声明经纬度变量、标记点；标记用来显示地图中心
  • 在 onLoad 中同时获取位置信息
    • let mapCtx;

Page({
  data: {
    longitude: "",
    latitude: ""
    markers: []
  },

  onLoad(options) {
    mapCtx = wx.createMapContext('myMap')
    wx.getLocation({
      type: 'gcj02',
      success: res => {
        this.setData({
          longitude: res.longitude,
          latitude: res.latitude
        })
      },
      fail: err => console.log('getLocation fail', err)
    })
  }
})
  • 添加标记点函数，使用经纬度作为形参
    • addCenterMarkers(lati, long) {
    let markers = this.data.markers
    let ind = markers.length
    let marker = {
        id: ind,
        latitude: lati,
        longitude: long,
        iconPath: '../../utils/marker.png',
        width: 32,
        height: 32,
        callout: {
            content: 'top',
            color: '#ff4400',
            textAlign: 'center',
            display: 'BYCLICK'
        },
        label: {
            content: 'center',
            color: '#ff4400',
            textAlign: 'cneter'
        }
    }
    markers.push(marker)
    this.setData({
        markers
    })
}
  • 单击返回中心，使地图回到中心点

        latitude: this.data.latitude
    })

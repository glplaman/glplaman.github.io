字符串函数 String

  1. 一般操作
    • len(String)：字符串的长度
      • len('hi,there.') # 9
  2. 大小写转变
    • upper()：大写
      • 'Hi,there.'.upper() # HI,THERE.
    • lower()：小写
      • 'Hi,there.'.lower() # hi,there.
    • title()：首字母大写
      • 'Hi,there.'.title() # Hi,There.
    3. 不影响原来的变量
  3. 空格去除
    • lstrip()：去除左边末尾空格 left space
      • ' hi,there. '.lstrip()
    • rstrip()：去除左边末尾空格 right space
      • ' hi,there. '.rstrip()
    • strip()：去除两侧空格
      • ' hi,there. '.strip()

      使用长度函数验证空格去除效果

  4. 前后缀移除
    • removeprefix()：移除指定前缀
      • 'https://glplaman.github.io'.removeprefix('https://') # glplaman.github.io
    • removesuffix()：移除指定后缀
      • 'fav.icon'.removesuffix('.icon') # fav

Boolean Type

布尔类型
Boolean Type
数值类型 Numeric（int、float、complex） 的子集
只有2个值：真 True 和假 False
更多信息，请访问 Boolean Type
常见假对象 False
除了 False，以下对象也都被当做假
任何形式的数字0；整型 0或浮点型 0.0
空的序列或集合：''、[]、()、{}、range(0)、set()
None
可以使用内置函数 bool() 将值转换为对应的布尔类型
bool(0) # False
bool(0.0) # False
bool('') # False
bool(None) # False
bool([]) # False
bool(()) # False
bool({}) # False
bool(set()) # False
bool(range(0)) # False

While-for

循环流
while
for
固定次数循环
依次遍历列表中的每一个元素，直至结束
无法实现无限循环
使用数字列表
for item in [0,1,2,3,4]:
  print(item)
使用 range() 构造数字列表，输出：0-4
for num in range(5):
  print(num)
使用字符串
for char in 'hi,there.':
  print(char)
使用复杂数据
continue
break
使用 Usage
遍历字符串的函数
mehods = dir(str)
for method in mehods:
    if method.startswith("__"):
        continue
    print(method)

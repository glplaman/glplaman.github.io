Overview

概述
  • 解释型语言
  • 使用缩进表达逻辑
  • 使用 input 获取到的数据都是字符串 string
  • 没有 switch 语句
  • 使用 try-except 捕获异常；使用 raise 抛出异常

变量 Variable

  • 变量名：字母、数字、下划线
  • 变量名不能以数字开头
  • 变量名区分大小写
  • 变量名应语义化，以提高可读性
  • 变量名不能使用关键字
  • 变量名不能使用特殊字符
  • 变量名不能使用 Python 保留字
  • 变量名不能使用 Python 模块名
  • 变量名不能使用 Python 类名
  • 变量名不能使用 Python 方法名
    • user_name # ok
    u123 # bad

赋值 Assignment

  • 使用 =，将右边的值赋值给左边的变量
    • user_age = 18

常量 Const

  • 程序存续期间，值不变
  • 常量一般大写；可以使用下划线分隔单词
  • 定义并赋值
    • PORT = 443 # 端口号 443
    CLIENT_DOMAIN = 'glplaman.github.io'

输出 print

  • 也可以作为一种调试手段

注释 Comment

  • 使用 # 为代码添加注释
  • 其后面的代码不会被编译、执行
  • 用于解释或说明代码功能
  • 可以放在代码任何位置
  • 通常单独放在1行，使用一个空格和注释内容分开
    • # this is a comment.

Range

范围
概述 Overview
序列的一种
生成一定范围的数字 numbers
不可变 immutable sequence
更多信息，请访问 Python - range
语法 Syntax
class range([start=0,] stop[, step=1])
参数必须是整型 integers
1个值的时候，表示 stop；start=0；step=1
2个值的时候，表示 start 和 stop，step=1
3个值的时候，表示 start、stop 和 step
  1. step 为正数/positive ，序列从 start 递增到 stop
    2. r[i] = start + step*i
i >= 0 and r[i] < stop
    range(2,5) # 2,3,4
    range(0,5,2) # 0,2,4
    range(5) # 0 1 2 3 4
  2. step 为负数/negative ，序列从 start 递减到 stop
    3. r[i] = start + step*i
i >= 0 and r[i] > stop
    range(5,2,-1) # 5，4，3
    range(0,-5,-1) # 0 -1 -2 -3 -4
    range(2,-5,-1) # 2 1 0 -1 -2 -3 -4
    range(-2,-5,-1) # -2 -3 -4
    range(-5,-2) # -5 -4 -3
特殊的
range(5,2) # 空；5没有办法递增到2
range(-2,-5) # 空；-2没有办法递增到-5
使用 Usage
可用于创建序列
多见于 for 循环中
list(range(5)) # [0,1,2,3,4]
list(range(5,2)) # []
list(range(-2,-5)) # []
list(range(5,2,-1)) # [5,4,3]
list(range(-2,-5,-1)) # [-2,-3,-4]

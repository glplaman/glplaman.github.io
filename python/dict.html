字典
标准映射类型 Mapping - A mapping object maps hashable values to arbitrary objects.
花括号 {} 括起来的，以逗号分隔的，键值对集合 key-value pairs 
{author:'glpla',url:'glpla.github.io'}
更多信息，请访问 Mapping Types
键 key
必须是不可变且可哈希（hashable）的对象
可以作为 key 的对象：字符串、数字、元组等
不可以作为 key 的对象：列表
通常使用字符串作为 key；字符串 key 应使用''或""
唯一、不能重复：在一个字典中，每个 key 只能出现一次；重复使用，会覆盖前面的 key
字典一旦创建，key 就确定下来，无法更改；如果你想改 key，必须：删除旧 key；添加新 key
值 Value
任意类型
可哈希的 Hashable
一个对象是 可哈希的（hashable），当且仅当：
它在其整个生命周期中具有不可变的值（即内容不能改变）
它实现了 __hash__() 方法（返回一个整数哈希值）
它实现了 __eq__() 方法，并且 相等的对象必须有相同 的哈希值
key不变 → 哈希值不变(hash(key)) → 定位不变(bucket/index) → 根据定位存取数据 → O(1) 平均时间复杂度

测试用例
d = {'name': 'glpla','age': 18}
访问 dict[key]
基于 key 访问；不是基于索引
d["age"] # 18
如果不存在，会告警 KeyError
获取 dict.get(key, default=None)
更加优雅的获取；如果不存在，则返回 None
d.get('name','not found') # glpla
d.get('unit','not found') # not found
改 dick[key] = value
基于 key 修改；如果 key 存在，则修改；如果不存在，就添加一个键值对
d["unit"] = '54414'
删除 dict.pop(key)
删除指定 key 的值对并返回删除的值
如果 key 不存在，则告警 KeyError
d.pop('name') # {'age': 18}
t = d.pop('name') # glpla
也可以使用 del d[key]删除 key 对应的值对
del d['name'] # {'age': 18}
键值对 dict.items()
返回字典所有值对的视图；动态
d.items() #dict_items([('name', 'glpla'), ('age', 18)])
键 dic.keys()
返回字典所有键的视图
d.keys() # dict_keys(['name', 'age'])
值 dict.values()
返回字典所有值的视图
d.values() # dict_values(['glpla', 18])
使用list()可将视图转换为列表
清空 dict.clear()
删除所有值对，返回 None

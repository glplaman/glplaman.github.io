关键路径法

CPM
概述
Critical Path Method
项目由多个任务组成
每个任务都有不同的时间参数
通过计算每个活动的最早/最晚开始/结束时间，找出总时差为0的活动构成的路径 - 即关键路径
实际应用中，我们通常在 PDM 网络图上执行 CPM 的计算
任务关系
FS：Finish to Start
A结束后，B才开始
SS：Start to Start
A开始时，B也开始
FF： Finish to Finish
A结束时，B也结束
SF： Start to Finish
A开始时，B才能结束
时间类别
最早开始时间 ES - Earliest Start Time
最迟开始时间 LS - Latest Start Time
最早完成时间 EF - Earliest Finish Time
最迟完成时间 LF - Latest Finish Time
浮动时间 Total Float：

TF = LS – ES = LF - EF

关键任务：浮动时间为 0 的任务
关键路径
由关键任务形成
最长路径
最短工期
总浮动时间为 0
可能不止一条

正推法：最早开始时间和最早完成时间

逆推法：最晚开始时间和最晚完成时间

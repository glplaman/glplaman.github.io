1.1 PDM - Precedence Diagramming Method

也叫单代号网络图、优先图法、节点法

1.2 ADM - Arrow Diagramming Method

也叫双代号网络图、箭线法、活动箭线图 AoA - Active On the Arrow
节点和箭线都要编号
可以使用虚拟活动 Dummy Activity 表示依赖关系；虚拟活动不消耗工期

5. 关键路径法 CPM

项目由多个任务组成

每个任务都有不同的时间参数

5.1 概念

  • 最早开始时间 ES - Earliest Start Time
  • 最迟开始时间 LS - Latest Start Time
  • 最早完成时间 EF - Earliest Finish Time
  • 最迟完成时间 LF - Latest Finish Time
  • 浮动时间 Total Float：TF = LS – ES = LF - EF
  • 关键任务：浮动时间为 0 的任务

5.2 关键路径

  • 由关键任务形成
  • 最长路径
  • 最短工期
  • 总浮动时间为 0
  • 可能不止一条

对一个任务进行进度估算时；A 是乐观者，估计用 6 天完成；B 是悲观者，估计用 24 天完成；C是有经验者，认为最有可能用12天完成。这个任务的历时估算介于10天到16天的概率是多少？

E =(O + 4m + P)/6 = (6 + 4*12 + 24)/6 = 13

δ =(P - O)/6 = (24 - 6)/6 = 3

根据统计学中的正态分布规律（68-95-99.7法则）：

±1 个标准差范围内的概率约为 68.3%

±2 个标准差范围内的概率约为 95.5%

±3 个标准差范围内的概率约为 99.7%

下限：E - δ = 13 – 3 = 10

上限：E + δ = 13 + 3 = 16

所以 [10, 16] 概率的为 68.3%

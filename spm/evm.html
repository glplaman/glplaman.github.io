挣值分析法

EVM
  • Earned Value Management
  • 是一种项目管理中常用的绩效衡量方法
  • 通过整合项目的范围、进度、成本三个维度，帮助管理者客观地评估项目当前状态、预测未来趋势
  • 分析目的：计划花的钱、实际花的钱、以及已经完成的工作所值的钱，这三者是否匹配？
  • 也称已获价值分析

BAC

  • Budget at Completion
  • 完工预算
  • 项目全部计划完成时，对应的预算总金额
  • 开始前你计划要花的总钱数
  • 是整个项目的 总预算，是一个固定值

BCWS

  • Budgeted Cost of Work Scheduled
  • 计划完成工作的预算成本
  • 到某个时间点，按计划应完成多少工作量/预算
  • 也称计划价值 PV (Planned Value)
    • BCWS = 计划工作量*计划单价

BCWP

  • Budgeted Cost of Work Performed
  • 已经完成工作的预算成本
  • 到某个时间点，实际完成的工作量/预算
  • 也称已获价值、挣值 EV (Earned Value)
    • BCWP = 实际工作量*计划单价

ACWP

  • Actual Cost of Work Performed
  • 已经完成工作的实际成本
  • 到某个时间点，实际已经发生的成本/花的钱
  • 也称实际价值 AC (Actual Cost)
    • ACWP = 实际工作量*实际单价
挣值分析
item calc concept
成本偏差
Cost Variance		 CV = BCWP – ACWP
=（挣值 − 实际成本）

CV > 0：节约

CV < 0：超支
进度偏差
Scheduled Variance		 SV = BCWP – BCWS
=（挣值 − 计划值）

SV > 0：超前

SV < 0：滞后
成本绩效
Cost Performance Index		 CPI = BCWP / ACWP
=（挣值 / 实际成本）

CPI > 1：节约

CPI < 1：超支
进度绩效
Scheduled Performance Index		 SPI = BCWP / BCWS
=（挣值 / 计划值）

SPI > 1：超前

SPI < 1：滞后
某工厂计划生产一批汽车，一共100台，工厂每天生产10台，10天之内完工，项目预算为100万元。项目进行到第6天时，工厂老板来查看项目执行情况发现：

前6天一共生产了40台车

实际花费50万元

AC = 50 万

EV = 40*1 = 40 万

PV = 60*1 = 60 万

一个任务原计划3个人全职工作2周完成。而实际上只有2个人参与这个任务，到第二周末完成了任务的50%，求CPI。

CPI是比值和实际单位无关；按人周(Person-weeks)为成本单位计算

BAC = 3 × 2 = 6 人周

BCWP = 50% × BAC = 3 人周 = EV

ACWP = 2 × 2 = 4 人周 = AC

CPI = BCWP/ACWP = 0.75

CPI < 1 → 目前为止，该任务超出预算

某项目计划工期为4年，预算总成本为800万元。在项目实施过程中，通过对成本的核算和有关成本与进度的记录得知：

开工后两年末实际成本发生额为200万元，所完成工作的计划预算成本额为100万元。

与项目预算成本比较可得知，当工期过半时，项目的计划成本发生预算应该为400万元。

求该项目对应的：

成本偏差CV

进度偏差SV

成本绩效指数CPI

计划4年，预算成本800万

已经实施2年，预算成本BCWS = 400万

实际成本ACWP = 200万，挣值BCWP = 100万

成本偏差 CV = 挣值-实际成本 = 100万-200万 = -100万

进度偏差 EV = 挣值-计划价值 = 100万-400万 = -300万

CPI = 挣值/实际成本 = 100/200=50%

每花 1 元只完成 0.5 元价值，效率很低

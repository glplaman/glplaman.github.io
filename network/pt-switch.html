交换机 Switch

Cisco CLI中，命令关键字不区分大小写

命令可以使用简写，不需要打全，使用 Tab 主动补全

通常输入命令关键字的前3个字母即可；应确保对应的命令唯一

强制退出命令行卡顿：Ctrl + Shift + 6

操作模式 Mode
操作模式
Switch> 用户模式，en 进入特权模式
Switch# Privileged EXEC Mode
特权模式，conf ter 进入全局配置模式
Switch#conf 全局配置
Switch(config-if) 接口配置
Switch(config-vlan) VLAN 配置
Switch(config-line) console 配置

使用 ↑、↓ 可以选择历史命令；如果没有出现，则表明该命令不适用当前模式

查看 Show
switch>show ver 查看版本信息
switch#show running-config 查看运行配置
switch#show flash 查看已用/可用空间
switch#show arp 查看ARP缓存
switch#show mac-addr 查看 MAC 转发表
switch#show interface 查看所有端口
switch#show interface fa0/1 查看指定端口 fa0/1
switch#show interface fa0/1 switchport 查看指定端口模式
switch#show ip interface 查看IP端口信息
switch#show history 查看历史命令
Switch#show mac-address-table 查看交换机的MAC表
清除 Clear
Switch#clear mac-address-table 清除交换机的MAC表 - 特权模式
退出 Exit
返回上一级
一层一层退出
结束 End
直接回到特权模式 #
从任意深层的配置子模式（如全局配置模式、接口模式等）直接一步返回到特权模式
你已经身处特权模式，所以该命令是无效的
写入 Write
保存配置参数
模拟环境中，使用 Ctrl + S 即可
实际环境中，不会反复启动设备，必须养成随手写入的好习惯

交换机的日常执勤中，很少直接操作交换机

初始化配置：通常使用PC的串口RS232连接交换机，在PC上操作交换机，配置其基本参数，如主机名、登陆权限等

日常运维:使用串口；使用telnet远程登陆

主机名 Hostname
修改交换机的系统网络名
Hostname 可以不唯一
switch(config)#hostname huali
特权密码 Password
配置交换机特权模式密码
默认情况下，用户模式进入特权模式没有密码
huali(config)#ena pass xxx // 明文密码
huali(config)#ena secret xxx // 密文密码
串口密码 Console
配置交换机串口密码
为了方便用户首次初始化配置，Console 访问交换机默认没有密码
huali(config)#line console 0 // 选择 Console 口
huali(config-line)#password xxx // 配置密码
huali(config-line)#login // 登陆时检测密码
远程登陆密码 Telnet
配置远程登陆密码
huali(config)#line vty 0 4
huali(config-line)#password huali
huali(config-line)#login

安全起见，应为不同的模式配置不同的密码

建议根据需要选择合适的密码前缀

PT中的交换机 Switch

2960
类型：普通二层交换机
定位：接入层
用途：连接终端用户（PC、打印机、IP 电话等），负责 VLAN 划分和二层隔离
特点：纯二层交换，不支持路由功能，不支持 PoE（此型号）
356024PS
类型：三层交换机（多层交换机）
定位：汇聚层 / 核心层（适用于中小型网络或 PT 实验）
用途：VLAN 间路由、OSPF / 静态路由、高速数据转发
特点：

24 个端口

支持 PoE（可为下联 AP、摄像头等供电）

标准软件镜像（Standard Image）

365024PS
类型：三层交换机（多层交换机）
定位：汇聚层 / 核心层（与 3560 定位相同，性能更强）
用途：VLAN 间路由、动态路由、策略控制、高速转发
特点：

24 个端口

支持 PoE（若下联 AP / 摄像头可用）

是 3560 的升级版，性能更强，功能更丰富

标准软件镜像（Standard Image）

PoE：Power over Ethernet，以太网供电

VLAN Command

接入模式 Access
  1. 创建VLAN
  2. 指定名字（可选）
  3. 选择端口并进入端口配置模式
  4. 设置端口交换模式
  5. 把端口划入指定的 VLAN
    6. switch>en
switch>conf ter
switch(config)#vlan 10
switch(config-vlan)#name gl
switch(config)#inte fa0/1
switch(config-if)#swi mode access
switch(config-if)#swi acc vlan 10
switch(config-if)exit
switch#
中继模式 Trunk
基本设置大同小异
更改端口模式
Switch(config-if)#switchport mode trunk
VLAN 放行
Switch(config-if)#switchport trunk allowed vlan 20
Switch(config-if)#switchport trunk allowed vlan 20, 30
Switch(config-if)#switchport trunk allowed vlan 20-30
查看 Show
switch#show vlan
Switch#show vlan brief
switch#show vlan id 1
switch#show vlan name xit
Switch#show interfaces trunk
Switch#show interfaces fa0/4 switchport

3层交换机 Layer3 Switching

以上操作适用于 PT 的2层交换机 2960
下述内容以 PT 的3层交换机 3560 为例
概述 Overview
带有路由功能
默认没有开启；使用时，需要启动路由功能
Switch(config)#ip routing
如何检查是否启动了路由功能
方案1：show ip route
方案2：show running-config
Switch#show running-config

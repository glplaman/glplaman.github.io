交换机 Switch

操作模式
操作模式
Switch> 用户模式，en进入特权模式
Switch# 特权模式，conf ter进入全局配置模式
Switch#conf 全局配置
Switch(config-if) 接口配置
Switch(config-vlan) VLAN配置
Switch(config-line) console配置
Show
查看命令
switch>show ver 查看版本信息
switch#show running-config 查看运行配置
switch#show flash 查看已用/可用空间
switch#show arp 查看ARP缓存
switch#show mac-addr 查看MAC转发表
switch#show interface 查看所有端口
switch#show interface fa0/1 查看指定端口fa0/1
switch#show interface fa0/1 switchport 查看指定端口模式
switch#show ip interface 查看IP端口信息
switch#show history 查看历史命令
clear
clear mac-address-table
Exit
返回上一级
End
直接回到特权模式#
write
保存配置参数
基本配置
交换机的日常执勤中，很少直接操作交换机
初始化配置：通常使用PC的串口RS232连接交换机，在PC上操作交换机，配置其基本参数，如主机名、登陆权限等
日常运维:使用串口；使用telnet远程登陆
修改交换机的系统网络名
switch(config)#hostname huali
配置交换机特权模式密码
huali(config)#ena pass xxx // 明文密码
huali(config)#ena secret xxx // 密文密码
配置交换机串口密码
huali(config)#line console 0 // 选择console口
huali(config-line)#password xxx // 配置密码
huali(config-line)#login // 登陆时检测密码
配置远程登陆密码
huali(config)#line vty 0 4
huali(config-line)#password huali
huali(config-line)#login

VLAN Command

查看所有VLAN
switch#show vlan
查看指定id的VLAN
switch#show vlan id 1
查看指定name的VLAN
switch#show vlan name xit
创建VLAN
switch(config)#vlan 10
switch(config-vlan)#name gl
添加端口
switch(config)#inte fa0/1
switch(config-if)#swi acc vlan 10

子网掩码 Subnet Mask
为了标识子网，引入了子网掩码 Subnet Mask
子网掩码长度 32bits：使用连续的 1 表示网络号和子网号；使用连续的 0 表示主机号
默认子网掩码
A类 255.0.0.0
B类 255.255.0.0
C类 255.255.255.0
IP地址要配合子网掩码一起使用，才能确定属于哪个网络
网络地址 = IP地址 & 子网掩码
通常不作区分：子网掩码 = 地址掩码 = 掩码

已知某台设备的 IP 地址是 177.189.120.25，其子网掩码为 255.224.0.0，求：
1. 这台设备的主机号是多少？
2. 网络前缀是多少？
3. 子网内第一个可用 IP 地址是多少？
4. 网络地址是多少？
答：

IP 地址：10110001.10111101.01111000.00011001

子网掩码：11111111.11100000.00000000.00000000

网络前缀11位

主机号（11位掩码部分取0）：00000000 00011101 01111000 00011001 → 0.29.120.25

IP所在的网络地址：IP 地址 & 子网掩码 = 177.189.120.25 & 255.224.0.0 = 177.160.0.0

第一个可用 IP 地址：网络地址 + 1 = 177.160.0.1

子网划分细节
IP 地址 177.189.120.25
子网掩码 255.224.0.0
网络地址 177.160.0.0
等长子网划分 FLSM，Fixed Length Subnet Mask
使用相同的子网掩码划分子网
每个子网的 IP 地址数量相同
仍然会造成浪费
可变长度子网掩 VLSM，Variable Length Subnet Mask
更灵活的子网划分（见CIDR）
使用不同的子网掩码划分子网
不会造成 IP 地址的浪费
按需划分

@Subneting
从 主机号 中拿出若干位充当 子网号
IP地址从原来的2级结构变为3级结构
进行了子网划分的 IP 地址结构
Network ID Subnet ID Host ID
n bits m bits (32-m-n) bits
子网掩码 Subnet Mask
为了标识子网，引入了子网掩码 Subnet Mask
子网掩码长度 32bits：使用连续的 1 表示网络号和子网号；使用连续的 0 表示主机号
默认子网掩码
A类 255.0.0.0
B类 255.255.0.0
C类 255.255.255.0
通常不作区分：子网掩码 = 地址掩码 = 掩码

子网计算 Subnet Calculations

核心：三类/个关键地址
网络地址 Network Address
标识一个子网本身的地址
主机部分 host bits 全为 0
子网中最低位的IP地址
不能分配给主机使用
IP地址 & 子网掩码 = 网络地址
广播地址 Broadcast Address
用于将数据包发送给同一子网中的所有主机
网络部分与子网相同
主机部分 host bits 全为1
子网中最高位的IP地址
不能分配给主机使用
主机地址 Range of Hosts
分配给主机使用
网络地址和广播地址之间的IP地址
已知某个网络的IPv4地址为 218.75.230.0，使用子网掩码 255.255.255.128 进行子网划分，请给出划分的细节。
答：
1. IP地址类别
→ 默认掩码
2. 子网掩码 → 借用了几位主机号充当子网
→ 确定子网数量
→ 确定每个子网的IP地址数量
→ 网络地址、最小主机地址、最大主机地址、广播地址
C类地址划分细节
C类IP地址 218.75.230 0
218.75.230 0000 0000
默认子网掩码 255.255.255 0
255.255.255 0000 0000
子网掩码 255.255.255 128
255.255.255 1000 0000
从主机位借了 1 位划分子网
可以划分为 0 号子网和 1 号子网
子网划分细节
0号子网 218.75.230 0000 0000 网络地址
218.75.230 0000 0001 最小主机地址
218.75.230 ... 其它主机地址

1号子网 218.75.230 1000 0000 网络地址

218.75.230 ... 其它主机地址
218.75.230 1111 1110 最大主机地址
218.75.230 1111 1111 广播地址
[结论]
网络号：24位
子网号：1位，可以划分的子网数量为2个，0号子网、1号子网
主机号：8 - 1 = 7位，每个子网共有IP地址：27，可供分配的主机IP地址：27-2个

6. 子网内第一个可用IP地址是多少

IP地址：10110001.10111101.01111000.00011001

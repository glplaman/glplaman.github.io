概念 Concept
虚拟专用网 VPN - Virtual Private Network 是一种通过公共网络（如互联网）建立加密、安全、逻辑隔离通信通道的技术

虚拟：非物理专线，而是逻辑通道

专用：数据仅限授权用户访问

网络：可实现点对点或网络对网络通信

日常生活中的应用
核心技术 Core
  1. 隧道技术 Tunneling

    将原始数据包“封装”进另一个数据包中传输 类比：把信件装进带锁的快递箱

  2. 加密 Encryption

    使用对称/非对称加密算法 如AES、RSA 保护数据 防止窃听、篡改

  3. 身份认证 Authentication

    确保通信双方身份合法 如用户名/密码、数字证书、双因素认证

  4. 数据完整性校验

    使用哈希算法 如SHA 确保数据未被篡改

应用 Application
企业远程办公 - 如疫情期间
跨国公司内网互联
保护公共Wi-Fi下的上网安全
绕过地理内容限制 - 如流媒体

总结

@Summary
RIP（Routing Information Protocol）
使用 UDP，端口号为 520
RIP 是一种距离矢量路由协议，适用于小型网络
它定期广播或组播路由更新，UDP 的轻量级特性适合这种简单、周期性的通信
OSPF（Open Shortest Path First）
直接使用 IP 协议，协议号为 89
OSPF 不依赖 TCP 或 UDP，而是封装在 IP 数据包中直接传输
它自己实现了可靠传输机制（如确认、重传等），因此不需要 TCP 的可靠性保障
BGP（Border Gateway Protocol）
使用 TCP，端口号为 179
BGP 是一种路径矢量协议，用于在自治系统（AS）之间交换路由信息（即 EGP，外部网关协议）
选择 TCP 是因为其连接可靠、有序、面向连接，适合长时间运行的对等会话

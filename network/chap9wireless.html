无线网络

@Wireless Network
无线广域网 WWAN
Wireless Wide Area Network
主要指移动通信的范畴，如：2G、3G、4G和5G，它们代表了不同代际的无线网络技术标准
几十公里至全国/全球（依赖蜂窝基站和卫星）
1. 2G（第二代移动通信技术）
标志着从模拟信号向数字信号的转变，主要提供语音服务和低速数据服务，如短信（SMS）和彩信（MMS）。2G技术包括GSM、CDMA等
2. 3G（第三代移动通信技术）
在2G的基础上大幅提升了数据传输速度，使得移动互联网成为可能，支持视频通话、移动电视等更丰富的多媒体服务
3G技术主要包括WCDMA、CDMA2000等
3. 4G（第四代移动通信技术）
以更快的速度和更低的延迟为特点，提供了高质量的移动宽带体验，支持高清视频流、在线游戏等高带宽应用
4G技术主要指的是LTE（长期演进）及其增强版本LTE-Advanced
4. 5G（第五代移动通信技术）
进一步提高了速度和减少了延迟，同时增加了连接密度，能够支持物联网（IoT）、智能城市、自动驾驶等新型应用场景
5G不仅关注人与人之间的通信，还致力于实现设备间（物与物）的高效通信
手机通信、移动互联网、车联网、远程监控、物联网（如智能电表）、应急通信
无线城域网 WMAN
Wireless Metropolitan Area Network
5Km–50Km（城市级）
城市宽带接入（尤其在光纤未覆盖区域）、企业专线替代、农村互联网接入（历史上应用较多，现逐渐被4G/5G取代）
WMAN
application standard memo

已基本淘汰
无线局域网 WLAN
Wireless Local Area Network
10m–100m（室内），可达数百米（室外定向）
家庭/办公室无线网络、公共场所热点（机场、咖啡馆）、企业内网、智能家居、视频会议、在线游戏
WLAN
application standard memo
Wi-Fi IEEE 802.11
无线个域网 WPAN
Wireless Personal Area Network
<10m（通常1m–3m）
无线耳机/键盘/鼠标、智能手环/手表、智能家居设备（如灯控、传感器）、无接触支付（NFC）、精准定位（UWB）
WPAN
application standard memo
Bluetooth IEEE 802.15.1

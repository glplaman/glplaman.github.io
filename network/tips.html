Tips

  • Loopback in IPv4 is 127.0.0.1, while in IPv6 is ::1.
  • log2(x) = log10(x) / log10(2)
  • ARP - determine a device's Media Access Control (MAC) address based on its Internet Protocol (IP) address.
  • IP - The IP address of a host is partitioned by the network’s subnet mask into two parts, a network ID and a host ID.
  • A router connects devices across multiple networks. Switch’s main objective is to connect various devices in a network.

主机路由

@Host Route
指向特定主机的路由；精确路由
子网掩码为 /32
Router(config)# ip route 192.168.10.5 255.255.255.255 10.0.0.2
优先级较高
在网络设计、故障排除和精细化流量控制中扮演着重要角色
下图中的L路由就是主机路由，是发给路由器的数据，不需要转发

这是现代操作系统和路由器自动生成一些隐式的主机路由

应用 Application
策略路由 / 特定路径控制：强制某个主机的流量走特定链路（如备份线路、高安全性路径）
故障排除与测试：临时添加一条主机路由，测试某台服务器的连通性
安全策略：将可疑主机的流量引导到防火墙、IDS/IPS 或黑洞（null0）接口
负载均衡或冗余：某些集群环境中，为主机单独配置最优路径
避免路由环路或冲突：当存在多条可能匹配的路由时，用主机路由覆盖默认行为

实操 Drill

隔离问题主机 点击下载PT文件
为问题主机配置主机路由，将其下一条指向空
使用 null0 虚拟"黑洞"接口，所有发往这里的包都会被丢弃
步骤 Steps
  1. 搭建拓扑
  2. 配置IP
  3. 测试直接路由的连通性：PC0 ping PC1
    4. ping 192.168.2.100
  4. 配置主机路由
    5. Router(config)# ip route 192.168.2.100 255.255.255.255 null0
  5. 再次测试连通性
    6. ping 192.168.2.100
  6. 删除主机路由
    7. Router(config)# no ip route 192.168.2.100 255.255.255.255 null0
  7. 再次测试连通性
    8. ping 192.168.2.100

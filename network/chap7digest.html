消息摘要

@Digest
又称散列函数、哈希函数
是一种将任意长度输入转换为固定长度输出的单向密码学函数
Feature
确定性：相同输入总是产生相同输出
单向性（Pre-image Resistance）：从摘要无法还原原始消息
抗碰撞性（Collision Resistance）：极难找到两个不同输入生成相同摘要
雪崩效应：输入微小变化导致输出显著不同
MD5
Message Digest Algorithm 5
输出长度：128 位
速度快，曾广泛用于文件校验、密码存储和游戏客户端防篡改
现已被完全攻破，不能用于身份认证、数字签名、密码保护等安全相关场景
在线工具：MD5MA
SHA
Secure Hash Algorithm
安全散列算法
  1. SHA-1

    输出长度：160 位

    Google于2017年宣布攻破 SHA-1

    美国国家安全局NSA设计，并由美国国家标准与技术研究院NIST发布

  2. SHA-2

    SHA-256：256 位输出，最常用，安全性高

    SHA-384：384 位输出，更高强度

    SHA-512：512 位输出，适用于高安全需求

    当前仍被认为是安全的

    广泛应用于 TLS、数字证书、区块链（比特币）、密码派生

  3. SHA-3

    NIST 于 2012 年选出，基于 Keccak 算法

    结构与 SHA-2 不同，抗攻击能力更强

    提供多种输出长度（如 SHA3-256、SHA3-512）

    未来发展方向，但目前尚未大规模取代 SHA-2

    高安全要求系统、后量子时代准备

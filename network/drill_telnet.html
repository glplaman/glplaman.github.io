远程登陆

Telnet

实验内容
远超登陆交换机
实验目的
掌握远超登陆的方法
前置知识
要成功地建立 Telnet 连接，除了要求掌握远程计算机上的账号和密码外，还需要远程计算机开启“Telnet服务”，并去除 NTLM 验证
也可以使用专门的 Telnet 工具来进行连接，比如STERM，CTERM等工具（win11程序和应用可选功能更多window功能）
先配置网络基础，再使用 Telnet 功能
实验思路
先使用主机 PC0 通过 Console 口配置交换机；配置完毕，这条链路就可以拆除了
再使用主机 Laptop0 远超登陆交换机进行运维
简便起见，也可以只使用一个主机完成实验
实验步骤
  1. 搭建拓扑

    1台 PC

    1台 Laptop

    1台 2960 交换机

  2. PC0 通过 Console 口连接交换机
  3. 安全起见，要设置特权密码；交换机的第一道安全防线
    4. Switch(config)#enable password 2026
  4. 配置 telnet 远程登陆信息，允许用户通过虚拟终端线路远程接入

    vty：Virtual Teletype Terminal，表示虚拟电信终端

    vty 0 4：表示允许5个线路/用户远程登陆该设备；默认至少4个；最多15个

    5. Switch(config)#line vty 0 4
Switch(config-line)#password tel2026
Switch(config-line)#login
  5. 网络管理并保存

    通常配置 vlan1 为管理地址

    交换机 Switch0 和远超主机 Laptop0 的 IP 地址必须是同一网段

    6. Switch(config)#int vlan 1
Switch(config-if)#ip add 192.168.1.254 255.255.255.0
Switch(config-if)#no shutdown
Switch(config-if)#end
Switch#write
  6. 查看交换机配置
    7. Switch#show running-config
  7. 配置 Laptop0

    192.168.1.1

    255.255.255.0

  8. 在命令行 Command Prompt 远程登陆交换机，输入密码
    9. C:\>telnet 192.168.1.254
Trying 192.168.1.254 ...Open

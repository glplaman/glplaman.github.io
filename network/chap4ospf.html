开放最短路径优先 OSPF

概述 Overview
Open Shortest Path First，开放最短路径优先
内部网关协议 IGP，用于在单一自治系统 AS 内路由选择
基于 链路状态 路由状态的协议，路由器会收集并维护整个网络的拓扑信息
特点 Features
快速收敛：能够快速适应网络拓扑变化
无环路：保证无环路
支持VLSM：支持可变长子网掩码
支持认证：提供简单密码认证和MD5认证
支持多路径负载均衡：最多支持等价多路径负载均衡
层次化设计：通过划分区域实现网络扩展性
触发更新：只有在网络状态改变时才发送更新
基本概念
区域 Area：OSPF将网络划分为不同区域，减少路由更新流量
Router ID：路由器的唯一标识符
邻居关系：路由器之间建立邻居关系来交换路由信息
邻接关系 Adjacency：形成完全邻接关系的路由器之间交换完整的链路状态数据库
链路状态通告 LSA：用于在OSPF域内传播路由信息
链路状态数据库 LSDB：存储区域内所有路由器的链路状态信息
指定路由器 DR：在多路访问网络中负责收集和分发链路状态信息
备份指定路由器 BDR：DR的备份，在DR失效时代替DR工作
OSPF区域类型
骨干区域 Backbone Area (Area 0)：连接所有其他区域的核心区域
标准区域 Standard Area：常规的OSPF区域
末节区域 Stub Area：不接收外部路由信息的区域
完全末节区域 Totally Stubby Area：Cisco专有特性，只保留默认路由
次末节区域 NSSA：允许引入外部路由但不传播到其他区域
OSPF路由器类型
内部路由器 Internal Router：所有接口都在同一区域内的路由器
区域边界路由器 ABR：连接多个区域的路由器
自治系统边界路由器 ASBR：连接OSPF域和其他自治系统的路由器
骨干路由器 Backbone Router：至少有一个接口连接到骨干区域的路由器
LSA类型详解
type name desc creator range
Type 1 Router LSA 描述路由器接口状态和成本 所有路由器 本区域内
Type 2 Network LSA 描述多路访问网络的链路状态 DR 本区域内
Type 3 Summary LSA 描述区域间路由 ABR 整个AS内除产生区域外
Type 4 ASBR Summary LSA 描述到ASBR的路由 ABR 整个AS内除产生区域和末节区域外
Type 5 AS External LSA 描述到AS外部路由 ASBR 整个AS内（除末节区域）
Type 7 NSSA External LSA NSSA区域内的外部路由 ASBR（NSSA区域内） 仅在NSSA区域内
OSPF邻居建立过程
Down状态：初始状态，没有收到邻居的Hello包
Init状态：收到邻居的Hello包，但对方Hello包中未包含自己的Router ID
Two-way状态：双方已互相发现，形成双向通信
Exstart状态：协商主从关系，确定数据库描述包的序列号
Exchange状态：交换数据库描述包DD，描述各自的LSDB
Loading状态：请求并发送详细的LSA信息
Full状态：邻居完全同步，形成邻接关系
OSPF度量值计算
OSPF使用开销(Cost)作为路由度量值
默认情况下，Cost = 参考带宽 / 接口带宽
参考带宽默认为100Mbps，可通过auto-cost reference-bandwidth命令修改
路径总Cost为经过的所有接口Cost之和
OSPF配置要点
启用OSPF进程：router ospf [process-id]
宣告网络：network [network] [wildcard-mask] area [area-id]
调整接口Cost：ip ospf cost [cost-value]
设置Router ID：router-id [ip-address]
配置认证：ip ospf authentication [选项]
OSPF与RIP对比
管理距离：OSPF为110，RIP为120
度量值：OSPF使用Cost，RIP使用跳数(Hop Count)
最大跳数限制：OSPF无跳数限制，RIP最大15跳
收敛速度：OSPF收敛更快
资源消耗：OSPF占用更多内存和CPU资源
适用网络规模：OSPF适用于大型网络，RIP适用于小型网络
特性 OSPF RIP
路由协议类型 链路状态路由协议 距离矢量路由协议
管理距离 110 120
度量值 Cost（带宽相关） Hop Count（跳数）
最大跳数限制 无限制 15跳（16跳视为不可达）
收敛速度 快速收敛 较慢收敛
资源消耗 较高（CPU、内存） 较低
适用网络规模 大型网络 小型网络（小于15跳）
更新方式 触发更新 周期性更新（30秒）
算法 Dijkstra SPF算法 Bellman-Ford算法
网络环路 无环路 可能产生环路（需水平分割等机制避免）
VLSM支持 支持 RIPv2支持，RIPv1不支持
认证支持 支持（明文和MD5） RIPv2支持，RIPv1不支持

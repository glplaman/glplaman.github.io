概述 Overview
RIP-Routing Information Protocol
路由信息协议，属于内部网关路由协议IGP
每个路由器维护一组从它自己到其它每一个目的网络的距离向量记录

基于距离矢量 DV - Distance Vector

使用跳数Hop count作为度量Metric到目标网络的距离，即：路由器到目标网络所经过的路由器个数

当前版本为RIP2
基本过程 Procedure
使用UDP协议，端口520，按照固定时间间隔，以广播RIP报文的方式，和 相邻路由器交换全部路由信息 - 分布式路由选择协议

全部 - What

每经过一个网络，跳数+1

特点二 Feature
好消息传的快

指网络拓扑变得更好，比如新链路建立、新网络可达、或到达某个网络的路径变短了

总是选择距离最短的路径

坏消息传的慢 - 慢收敛

指网络拓扑变差，比如链路断开、网络不可达、或到达某个网络的路径变长了

可能 基于邻居的过时信息产生错误路由，导致错误信息在邻居间循环，距离不断增加直到达到16跳的上限

网络N1路由故障后，R1立即设置距离为16，表示网络不可达
R2在收到R1的更新报文之前，还发送原来的报文 - 因为这时 R2 并不知道 R1 出了故障
R1收到R2的更新报文后，误认为可经过R2到达网N1，于是更新自己的路由表，说：“我到网络N1的距离是3，下一跳经过R2”。然后将此更新信息发送给 R2
R2收到R1的路由信息，更新自己的路由信息
如此反复，直到距离增加为16，才知道网络N1是不可达

配置

交换机 Switch

分类

按交换方式
存储转发 store and forward

接收/缓存完整的数据帧，校验（CRC）、过滤碎片，最后转发。转发是由专门的ASIC交换芯片实现

优点：提供差错校验和速率不一致的非对称交换

缺点：时延长

直通式 cut-through

不做缓存。不做校验，收到即转发，可能有坏帧；和存储转发的特点刚好相反

碎片过滤式 fragment free

融合了以上2种优势。转发前先检验数据帧的长度是否够64个字节；如果大于或等于就转发；如果不够，就作为碎片丢弃；（以太网帧 >= 64字节）

目前硬件的转发速度够快，基本可以忽略时延的影响。路由通常由软件实现

交换协议
二层交换机

链路层交换；如无特别说明，默认都是指二层交换机

三层交换机

集成了路由功能；路由器默认都是三层

多层交换机
按交换结构
固定端口交换机

接入交换机一般都是固定端口的交换机

通常有24口、48口

24口：24个电（接电脑或终端或用户）的下行端口；还有4个光的上行端口

48口：48个电（接电脑或终端或用户）的下行端口；还有4个光的上行端口

可扩展端口交换机
按部署层次
核心交换机
汇聚交换机

楼栋/部门汇聚，一栋楼放1-2台

接入交换机

接用户，每个楼层放3-5台

规格

端口类型
电口 RJ45
光口 SC/GBIC/SFP（千兆口）/SFP+（万兆口）/SFP28）
传输模式
半双工
全双工
交换容量
端口数*端口速率*2
如：48个千兆电+4个千兆光的交换机容量是：( 48*1G+4*1G )*2=104Gbps
MAC地址数
交换机MAC地址表中可以存储最大的MAC地址的数量
Vlan表项
交换机最大支持的vlan的数量，一般都是4094个，俗称4K
包转发率
单位时间内发送64字节数据包的个数 1000Mbps/8/(64+8+12)=1.488Mbps

基本配置
交换机的日常执勤中，很少直接操作交换机
初始化配置：通常使用PC的串口RS232连接交换机，在PC上操作交换机，配置其基本参数，如主机名、登陆权限等
日常运维:使用串口；使用telnet远程登陆
修改交换机的系统网络名
switch(config)#hostname huali
配置交换机特权模式密码
huali(config)#ena pass xxx // 明文密码
huali(config)#ena secret xxx // 密文密码
配置交换机串口密码
huali(config)#line console 0 // 选择console口
huali(config-line)#password xxx // 配置密码
huali(config-line)#login // 登陆时检测密码
配置远程登陆密码
huali(config)#line vty 0 4
huali(config-line)#password huali
huali(config-line)#login

串口初始化

Console

实验内容
Console 初始化交换机
实验目的
掌握利用 Console 口配置交换机的方法
前置知识
生产环境中，新交换机第一次启用需要使用 Console 进行初始化配置
实验步骤
  1. 搭建拓扑

    1台 Laptop

    1台 2960 交换机

  2. 使用串口线 Console 分别连接 Laptop0 的RS-232 接口和交换机 Switch0 的串口 console
  3. 打开：Laptop0 → 桌面 Desktop → 终端程序 Terminal，使用默认的参数，单击 "OK"，连接交换机
  4. 进入命令行界面；按回车 Return 开始配置交换机。当前是用户模式 >
    5. Switch>

    可以简写命令

    也可以使用 Tab 补全命令

  5. 进入特权模式 #；默认不需要密码
    6. Switch>en
Switch#
  6. 进入全局配置模式/终端配置模式
    7. Switch#conf ter
Enter configuration commands, one per line.  End with CNTL/Z.
Switch(config)
  7. 修改主机名为 SWxxxx；xxx是你的学号后4位，如2019
    8. Switch(config)#hostname SW2019
SW2019(config)#
  8. 设置特权密码为 2026；建议先查看命令再设置
    9. SW2019(config)#enable ?
  password  Assign the privileged level password
  secret    Assign the privileged level secret
SW2019(config)#enable pass 2026
  9. 返回用户模式；

    先 end 直接回到特权模式 #

    再 exit 退回到用户模式 >

  10. 再次进入特权模式 #，提示输入密码
    11. SW2019>en
Password:
    取消特权密码；进入特权的全局配置模式
    SW2019(config)#no ena pass
  11. 还原主机名
    12. SW2019(config)#no hostname
  12. 其它感兴趣的命令 – 配合?使用

    查看设备信息 show ter

    查看端口信息 show interfaces status

    查看运行配置 show running-config

串口初始化配置交换机
  1. 搭建拓扑：利用串口线（console）分别连接主机 PC0 和交换机 Switch0 的串口
  2. 打开：PC0 → 桌面（Desktop）→ 终端程序（terminal），使用默认的参数，单击 "OK"，连接交换机；提示按回车 Return 开始
  3. 修改主机名为 net2026
    4. Switch>
Switch>en
Switch#conf ter
Enter configuration commands, one per line.  End with CNTL/Z.
Switch(config)#hostname net2026
net2026(config)#
  4. 设置特权密码；先查看命令再设置
    5. net2026(config)#enable ?
  password  Assign the privileged level password
  secret    Assign the privileged level secret
net2026(config)#enable pass 2026
  5. 返回用户模式；先 end，再 exit
  6. 进入特权模式，提示输入密码
    7. net2026>en
Password:
    取消特权密码；进入特权的全局配置模式
    net2026(config)#no ena pass
  7. 还原主机名
    8. net2026(config)#no hostname
  8. 查看其它感兴趣的命令 – 配合?使用
Telnet 远程登陆交换机
要成功地建立 Telnet 连接，除了要求掌握远程计算机上的账号和密码外，还需要远程计算机开启“Telnet服务”，并去除 NTLM 验证
也可以使用专门的 Telnet 工具来进行连接，比如STERM，CTERM等工具（win11程序和应用可选功能更多window功能）
学完网络层再回来做这个实验
  1. 搭建拓扑
  2. 使用配置设置特权密码
    3. Switch(config)#enable password 2026
  3. 配置 telnet 远程登陆密码

    vty：Virtual Teletype Terminal，表示虚拟电信终端

    vty 0 4：表示允许5个线路/用户远程登陆该设备；默认至少4个；最多15个

    4. Switch(config)#line vty 0 4
Switch(config-line)#password xit
Switch(config-line)#login
  4. 管理 IP 地址

    交换机 Switch0 和主机 PC0 的 IP 地址必须是同一网段

    通常配置 vlan1 为管理地址

Switch(config-if)#ip add 192.168.1.254 255.255.255.0
Switch(config-if)#no shutdown
Switch#write
  5. 查看交换机配置
    6. Switch#show running-config
  6. 配置PC并远程登陆交换机

跨交换机的 VLAN 的划分 点击下载PT文件
  1. 搭建拓扑

    Switch：2台2层交换机 2960

    PC：若干台

    VLAN 10：A、B

    VLAN 20：C、D

    VLAN 30：E、F

  2. 配置各主机IP（略）
  3. 创建 VLAN 10，VLAN 20，VLAN 30（略）
  4. 划分端口到相应的 VLAN（略）
  5. 两侧交换机设置互联端口为 trunk 模式并放行 VLAN 20

    交换机某一侧已经设置为 trunk 模式的前提下，对端交换机可以不设置 trunk - 系统会自动调整

    且会让所有的 VLAN 都通过

    建议双方交换机都显式的设置为 trunk 并指定允许通过的 VLAN

    6. Switch#conf ter
Enter configuration commands, one per line.  End with CNTL/Z.
Switch(config)#inter fa0/4
Switch(config-if)#switchport mode trunk
Switch(config-if)#switchport trunk allowed vlan 20
Switch(config-if)#end

3层交换机构建 VLAN 点击下载PT文件
  1. 构建网络拓扑

    3层架构

    Switch：2台2层交换机 2960；1台3层交换机 3560

    PC：若干台

  2. 接入交换机 (2960)：划分 VLAN，将终端端口划入对应 VLAN
  3. 汇聚交换机 (3560)：配置 VLAN 接口（SVI），实现 VLAN 间路由；配置 Trunk 连接核心
  4. 核心交换机 (3560)：配置路由（静态或 OSPF），连接汇聚和出口
  5. 出口路由器 (2911)：配置 NAT，默认路由指向外部网络
  6. 终端设备：配置 IP 地址和默认网关

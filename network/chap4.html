协议栈 Protocol Suite
IP

Internet Protocol

网际协议；是网络层的核心协议

ICMP

Internet Control Message Protocol

在IP网络中发送错误消息和操作信息，例如当数据包无法到达目标时发送"目标不可达"消息

需要使用IP协议；如IP数据报出现问题时，ICMP发送相应的错误报告

IGMP

Internet Group Management Protocol

管理IP组播组成员关系，允许主机向路由器报告它们希望接收特定组播组的数据

需要使用IP协议；如实现组播、管理组成员等等

ARP

Address Resolution Protocol

将网络层的IP地址解析为数据链路层的物理MAC地址，以便在同一局域网内正确传输数据帧

是IP协议的支撑协议而非依赖协议；为IP提供地址解析服务

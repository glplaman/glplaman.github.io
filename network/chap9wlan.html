无线局域网

@WLAN
WLAN - Wireless Local Area Network
IEEE 802.11
无线局域网通常使用 2.4 GHz 和 5 GHz 频段
每一个频段划分为若干个信道，供各无线局域网使用
802.11b 使用 2.4 GHz 频段，带宽约 85 MHz
定义了 11 个部分重叠的信道集
相邻信道的中心频率相差 5 MHz
每个信道的带宽约为 22 MHz
凡使用 802.11 系列协议的局域网又称为 Wi-Fi
WLAN是技术，WiFi是这项技术的认证
Wi-Fi 由 Wi-Fi 联盟基于 IEEE 802.11 标准认证和推广

架构 Architecture

基本服务集 BSS
Basic Service Set
无线局域网的最小构件
BSS 包括一个接入点 AP(Access Point) 和若干个移动站 MP(Mobile Point)
BSS 所覆盖的地理范围叫做一个基本服务区 BSA(Basic Service Area)
BSS 的服务范围是由 AP 所发射的电磁波的辐射范围确定的
使用标识符 SSID(Service Set Identifier)区分不同的 BSS
SSID 是一个字符串，最多 32 字节
无线客户端通过 SSID 来识别并连接到特定的无线网络 - 你家 Wi-Fi 名称 “Home_WiFi_5G” 就是一个 SSID
同一物理区域内的多个 AP 可以广播相同的 SSID，形成一个逻辑上的统一网络（即 ESS）
每个 BSS 都有一个 SSID，但多个 BSS 可以共享同一个 SSID
Ad Hoc 网络中采用独立基本服务集 IBSS
分配系统 Distribution system
是连接多个 AP 的有线网络基础设施（例如交换机、路由器等）
实现 BSS 之间的通信与数据转发
扩展服务集 ESS(Extended Service Set)
多个 BSS 通过有线或无线方式连接在一起，构成一个更大的逻辑网络，称为 ESS
用户可以在不同 BSS 之间漫游，而不会中断连接
ESS 还可为无线用户提供到 802.x 局域网（非802.11无线局域网）的接入。通过门户 (Portal) 设备实现。门户相当于一个网桥
使用扩展服务集标识符 ESSID 区分不同的 ESS
ESSID 不是一个独立的技术参数，而是对“用于 ESS 的 SSID”的一种习惯性称呼
AP(Access Point)
也称 WAP(Wireless Access Point)
每个 AP 负责管理其所在 BSS 内的 MP 设备
每个 AP 分配一个唯一的 48 位 MAC 地址，名称是基本服务集标识符 BSSID
每个 AP 分配一个通信信道
Mobile Station (MS)
连接到 WLAN 的终端设备，如笔记本电脑、手机等
移动站 A 漫游到位置 A1 时，选择和信号较强的一个 AP 联系。当漫游到位置 A2 时，就只能和 AP2 联系
移动站只要能够和其中一个 AP 联系上，就可以一直保持与另一个移动站 B 的通信
终端设备 Endpoint是更广泛的概念，不是 IEEE 802.11协议的标准术语
[] 配置解析
假设某商场部署了 10 个 AP，全部配置如下：

SSID = “Mall_Free_WiFi”

相同的加密方式（如 WPA2-Enterprise）

每个 AP 构成一个 BSS，各自的 SSID 都是 “Mall_Free_WiFi”
这 10 个 BSS 一起组成一个 ESS
ESS 的标识 ESSID 就是 “Mall_Free_WiFi”，本质上它仍是 SSID
当顾客从 A 区走到 B 区，手机自动从 AP1 切换到 AP2，但 Wi-Fi 名称不变，网络不断

核心功能 Core

关联 Association
一个移动站若要加入到一个 BSS，就必须先与某个 AP 建立关联
建立关联：表示这个移动站加入了选定的 AP 所属的子网，并和这个 AP 之间创建了一个虚拟线路
只有关联的 AP 才能向这个移动站发送数据帧，而这个移动站也只有通过关联的 AP 才能向其他站点发送数据帧
安全 Security
用户在和附近的接入点 AP 建立关联时，一般还要键入用户密码
初期加密方案：有线等效的保密 WEP (Wired Equivalent Privacy)
现在加密方案：无线局域网受保护的接入 WPA (WiFi Protected Access) 或 WPA2
冲突避免 CSMA/CA
CA - Collision Avoidance
无线环境
无法感知；无法监测，不适合使用 CSMA/CD - 隐藏终端
只能避免；尽量减少碰撞发生的概率
焦点

争用信道（Channel Contention）

推迟接入（Defer Access）

退避机制（Backoff）

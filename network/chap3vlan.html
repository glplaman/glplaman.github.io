传统以太网的局限性
  • 资源的竞争
  • 通信的私密性
  • 通信过程中，会产生大量广播帧/广播风暴 Broadcast Storm；会严重消耗设备的 CPU 和带宽资源，导致网络瘫痪
  • 集线器 Hub：不隔离广播域；所有端口在同一广播域
  • 交换机 Switch：默认不隔离广播域。交换机收到广播帧时，会将其从除接收端口外的所有其他端口转发出去。因此，默认情况下，连接在同一台交换机上的所有设备属于同一个广播域

广播域 Broadcast Domain - 广播可以抵达的地方；这个区域越小越好

网络中能够接收到同一个广播帧（目的 MAC 地址为 FF:FF:FF:FF:FF:FF）的所有设备的集合

当一个设备发送广播时，同一广播域内的所有设备都会收到并处理这个数据包（即使它们并不需要）

广播域越大，广播风暴的风险越高

Broadcast Storm is a network condition in which so many broadcasts are occurring that normal communication is disrupted.

continually sending out broadcast messages

the wire is continually busy

虚拟局域网 Virtual LAN

虚拟局域网 VLAN - Virtual LAN
不是一种新的局域网，而是一个服务/应用
通过配置，将一个物理的局域网在逻辑上划分为若干个虚拟的 LAN
将一个物理网络划分为多个逻辑上独立的广播域
VLAN 内的主机间可以直接通信，而 VLAN 间不能直接互通
VLAN 是一把双刃剑
特点 Feature
  • 限制/隔离广播域：

    广播域被限制在一个 VLAN 内

    一个 VlAN 就是一个一个广播域

    节省带宽，提高网络的处理能力

  • 增强局域网的安全性：

    不同的 VLAN 用户不能和其它 VLAN 用户直接通信

    不同 VLAN 内的报文在传输时是相互隔离的

  • 提高网络的健壮性：

    故障被限制在一个 VLAN 内

    本 VLAN 内的故障不会影响其他 VLAN 的正常工作

  • 灵活构建虚拟工作组：

    划分不同的用户到不同的工作组，网络构建和维护更方便灵活、更容易

    一个交换机可以划分多个 VLAN

    一个 VLAN 也可以跨域多个交换机

默认情况下，所有端口都属于 VLAN 1

早期标准（经典以太网时代）

早期网络不仅有以太网，还有 Token Ring（令牌环网）等其他局域网技术。这两种网络对 MAC 地址的“比特传输顺序”理解是相反的

CFI = 0： 表示这个数据帧是以太网格式（最常用，绝大多数情况都是 0）

CFI = 1： 表示这个数据帧是 Token Ring 格式（非以太网格式）

随着 Token Ring 技术的消亡，整个网络世界几乎只剩下了以太网。因此，CFI 字段常年固定为 0，失去了原本“指示格式”的意义

丢弃 eligible 指示符 DEI (Drop Eligible Indicator)

现代标准（数据中心与 QoS 时代）

IEEE 组织在 802.1Q-2011 标准中，把这个闲置的比特位重新定义，赋予了它新的生命，用来支持现代网络拥塞控制（QoS）

DEI = 0： 表示这个数据帧“不可随意丢弃”（Drop Ineligible）。网络拥堵时，尽量保留它

DEI = 1： 表示这个数据帧“可以优先丢弃”（Drop Eligible）。如果网络交换机缓存满了，这种包会被优先扔掉

比如 IP 电话（VoIP）的语音数据包，会设置高优先级（PCP=5或6）并且 DEI=0，保证通话不卡顿；而普通的文件下载数据包，可能会被标记为 DEI=1，拥堵时直接丢弃，等网络空闲了再重传

处理过程 Process
接收：交换机每收到一个以太网帧，就打上 VLAN 标签：插入 4 Bytes 的 VLAN 标记，变成 IEEE 802.1Q 帧
转发：根据 VLAN 号转发到相应的端口，去掉标签后转发出去
IEEE 802.1Q 帧只在交换机内部识别并处理，用户主机并不能识别
VLAN 帧的封帧和拆包
单个交换机无法直接查看到 802.1Q 的封帧情况
VLAN 帧的 TCI 字段的值 0x14 表示什么
下一个交换机连接的如果是另一台交换机（Trunk 链路），带着 VLAN 标记继续转发，直到到达目的主机
下一个交换机连接的如果是终端设备（Access 链路），去掉 VLAN 标记，还原为普通帧交付

    Virtual LAN, or VLAN, is a networking technology that allows networks to be segmented logically without having to be physically rewired.

    Each station can be assigned a VLAN identification number (ID), and stations with the same VLAN ID (no matter what physical switch they are connected to) can act and function as though they are all on the same physical network segment. Broadcasts sent by one host are received only by hosts with the same VLAN ID.

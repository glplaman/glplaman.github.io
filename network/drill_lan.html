虚拟局域网 VLAN
跨交换机的 VLAN 的划分 点击下载PT文件
  1. 搭建拓扑

    Switch：2台2层交换机 2960

    PC：若干台

    VLAN 10：A、B

    VLAN 20：C、D

    VLAN 30：E、F

  2. 配置各主机IP（略）
  3. 创建 VLAN 10，VLAN 20，VLAN 30（略）
  4. 划分端口到相应的 VLAN（略）
  5. 两侧交换机设置互联端口为 trunk 模式并放行 VLAN 20

    交换机某一侧已经设置为 trunk 模式的前提下，对端交换机可以不设置 trunk - 系统会自动调整

    且会让所有的 VLAN 都通过

    建议双方交换机都显式的设置为 trunk 并指定允许通过的 VLAN

    6. Switch#conf ter
Enter configuration commands, one per line.  End with CNTL/Z.
Switch(config)#inter fa0/4
Switch(config-if)#switchport mode trunk
Switch(config-if)#switchport trunk allowed vlan 20
Switch(config-if)#end

3层交换机构建 VLAN 点击下载PT文件
  1. 构建网络拓扑

    3层架构

    Switch：2台2层交换机 2960；1台3层交换机 3560

    PC：若干台

  2. 接入交换机 (2960)：划分 VLAN，将终端端口划入对应 VLAN
  3. 汇聚交换机 (3560)：配置 VLAN 接口（SVI），实现 VLAN 间路由；配置 Trunk 连接核心
  4. 核心交换机 (3560)：配置路由（静态或 OSPF），连接汇聚和出口
  5. 出口路由器 (2911)：配置 NAT，默认路由指向外部网络
  6. 终端设备：配置 IP 地址和默认网关

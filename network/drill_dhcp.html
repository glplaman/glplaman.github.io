常用命令
命令 说明
dhcp enable 启动 DHCP
ip pool [pool_name] 命名地址池
network [NETWORK] mask [MASK] 指定网络
lease day [days] hour [hours] minute [minutes] 租期；天数 day 是必填项，小时和分钟是可选；
如果不配置，华为设备默认租期通常为 1 天
excluded-ip-address [start_ip] [end_ip] IP排除
dns-list [] 指定 DNS
gateway-list [] 指定网关 Gateway
display ip pool 查看地址池
display ip pool name [name] 查看指定名称的地址池
实验步骤
  1. 搭建拓扑
  2. 配置各主机采用 DHCP 方式获取 IP
  3. 路由器基本设置（主机名为DHCP+学号后2位，如DHCP58）
    4. system-view
undo infor-center enable
sysname DHCP58
  4. 路由器配置网关

    配置端口 IP

    inter [interface]

    配置 IP 地址

    ip address [network] [mask]

    全局获取

    dhcp select global
  5. 路由器开启 DHCP
    6. dhcp enable
  6. 路由器配置 IP 地址池

    指定 IP 地址池名称

    ip pool [pool_name]

    指定网络和掩码

    network [network] mask [mask]

    指定 DNS

    dns-list [dns]

    指定网关 Gateway

    gateway-list [gateway]

    设置租期

    lease day [days] hour [hours] minute [minutes]

    排除网关、DNS 等保留地址

    excluded-ip-address [start_ip] [end_ip]
  7. 返回用户视图
    8. return
  8. 路由器保存配置
    9. save
  9. 各主机使用 IPCONFIG 查看 IP 地址获取情况
  10. 各主机使用 PING 命令，测试各设备的连通性
  11. 主机侧利用 Wireshark 查看 DHCP DORA 四步交互过程

    主机启动抓包、先释放，再更新

    ipconfig /release
    ipconfig /renew
  12. 路由器侧利用 Wireshark 查看 DHCP DORA 四步交互过程

    主机启动抓包、先释放，再更新

    ipconfig /release
    ipconfig /renew
  13. 其它

路由器配置参考命令（主机名为DHCP+学号后2位，如DHCP58）
system-view
undo info-center enable
sysname DHCP58
dhcp enable                         // 1. 全局开启DHCP服务（必须最先做）

ip pool mypool                      // 2. 提前建好池子
network 10.1.58.0 mask 24
gateway-list 10.1.58.1
dns-list 8.8.8.8
lease day 0 hour 0 minute 30
excluded-ip-address 10.1.58.2 10.1.58.100  // 注意：替换为实际IP，不要带中括号
quit

interface g0/0/0                    // 3. 配置接口并关联全局池
ip address 10.1.58.1 255.255.255.0
dhcp select global
quit

return
save

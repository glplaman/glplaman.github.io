DHCP

实验内容
动态主机配置 DHCP
实验目的
熟悉 DHCP 的建立与释放过程
掌握 DHCP 服务器的工作原理
熟悉 DHCP 报文格式与关键字段
掌握配置变更的风险控制技能
实验学时
2
实验类型
验证型
实验器材
eNSP 网络模拟平台
路由器 AR2220 1台
交换机 2960 2台
主机 PC 诺干台
前置知识
网关
命令 说明
dhcp enable 启动 DHCP
ip pool [pool_name] 命名地址池
network [NETWORK] mask [MASK] 指定网络
dns-list [] 指定 DNS
gateway-list [] 指定网关 Gateway
display ip pool 查看地址池
display ip pool name [name] 查看指定名称的地址池
实验步骤
  1. 搭建拓扑
  2. 配置各主机采用 DHCP 方式获取 IP
  3. 路由器基本设置
    4. system-view
undo infor-center enable
sysname AR1
  4. 配置路由器网关

    配置端口 IP

    inter [interface]

    配置 IP 地址

    ip address [network] [mask]

    全局获取

    dhcp select global
  5. 开启 DHCP
    6. dhcp enable
  6. 配置 IP 地址池

    指定 IP 地址池名称

    ip pool [pool_name]

    指定网络和掩码

    network [network] mask [mask]

    指定 DNS

    dns-list [dns]

    指定网关 Gateway

    gateway-list [gateway]

    设置租期

    lease day [days] hour [hours]

    排除网关、DNS 等保留地址

    excluded-ip-address [start_ip] [end_ip]
  7. 返回用户视图
    8. return
  8. 保存路由器配置
    9. save
  9. 利用 IPCONFIG 查看各主机 IP 地址获取情况
  10. 利用 PING 命令，测试各设备的连通性
  11. 主机侧利用 Wireshark 查看 DHCP 协议的执行过程

    主机先抓包、再释放，然后更新

    ipconfig /release
    ipconfig /renew
  12. 路由器侧利用 Wireshark 查看 DHCP 协议的执行过程

    主机先抓包、再释放，然后更新

    ipconfig /release
    ipconfig /renew
  13. 其它

常用命令
命令 说明
dhcp enable 启动 DHCP
ip pool [pool_name] 命名地址池；全局模式
network [NETWORK] mask [MASK] 指定网络
dhcp select interface/global 选择接口池/全局池
lease day [days] hour [hours] minute [minutes] 租期；天数 day 是必填项，小时和分钟是可选；
如果不配置，华为设备默认租期通常为 1 天
excluded-ip-address [start_ip] [end_ip] IP排除
dns-list [] 指定 DNS
gateway-list [] 指定网关 Gateway
display ip pool 查看地址池
display ip pool name [name] 查看指定名称的地址池
实验步骤
更多内容，请访问 DHCP Server
  1. 搭建网络拓扑
  2. 配置各主机采用 DHCP 方式获取 IP
  3. 路由器基本设置（主机名为DHCP+学号后2位，如DHCP58）
    4. system-view
undo infor-center enable
sysname DHCP58
  4. 开启 DHCP
    5. dhcp enable
  5. 配置 DHCP
    6. ip pool mypool 	# 指定 IP 地址池名称
network 10.1.58.0 mask 24 	#指定网络和掩码
dns-list 8.8.8.8 	#指定 DNS
gateway-list 10.1.58.1 	#指定网关 Gateway
lease day 0 hour 0 minute 30 	# 设置租期
excluded-ip-address 10.1.58.1 10.1.58.10 	#排除网关、DNS 等保留地址
quit
  6. 接口配置，与全局池绑定
    7. inter g0/0/0	# 选择端口
ip address 10.1.58.1 24 	# 配置IP
dhcp select global	# 让接口使用全局地址池分配 IP
quit
  7. 返回用户视图并保存配置
    8. return
save
  8. 交换机侧利用 Wireshark 查看 DHCP DORA 四步交互过程
  9. 各主机使用 IPCONFIG 查看 IP 地址获取情况
  10. 各主机使用 PING 命令，测试各设备的连通性
  11. 主机侧利用 Wireshark 查看 DHCP DORA 四步交互过程

    主机启动抓包、先释放，再更新

    ipconfig /release
    ipconfig /renew
  12. 路由器侧利用 Wireshark 查看 DHCP DORA 四步交互过程

    主机启动抓包、先释放，再更新

    ipconfig /release
    ipconfig /renew
  13. 其它

权衡 trade-off：牺牲存储资源，换取执行效率

空间：仅原始数据

可以先用 Map 或 Object 建立索引 - 给数据项打标签

空间：多了一个哈希表，占用额外内存；约多 100 万个指针/引用

属于 集合类（Collection）数据结构，用于存储键值对 key-value pairs

查找时直接根据key获取数据；不需要比较，直接“跳”到目标位置；效率较高；O(1)

Why
当网络很大时，查找路由表 要花费很多时间
在出现突发通信时，缓存会溢出，引起分组丢失、传输时延增大和服务质量下降
Solution
MPLS - MultiProtocol Label Switching
利用面向连接技术，使每个分组携带一个叫做标签 (label) 的小整数。标签交换路由器用标签值检索转发表，实现分组的快速转发
Frame
在以太网帧首部和 IP 数据报首部之间插入一个 4byte的首部
Procedure
在 MPLS 域的入口处，给每一个 IP 数据报打上固定长度标签

控制逻辑在网络层；实际封装在链路层 - 2.5层协议

对打上标签的 IP 数据报在第二层（链路层）用硬件进行转发
采用硬件技术对打上标签的 IP 数据报进行转发就称为标签交换
可以使用多种数据链路层协议，如 PPP、以太网、ATM 以及帧中继等
根据标签转发
label port
label0 1
label1 5
label2 2
... ...
在网络入口打标签，中间节点靠标签交换，出口剥标签还原 IP，全程走预建的标签路径（LSP），实现高效、灵活、可控的转发
Concept
MPLS域 - MPLS domain
标记交换路由器 LSR

Label Switching Router

只根据标签进行交换 Swap，不关心 IP 内容；无需解析 IP 头，显著提升转发效率

标签分配协议 LDP - Label Distribution Protocol
标签交换路径 LSP

Label Switched Path

一条从源到目的的单向标签路径

入口节点 - ingress node
出口节点 - egress node
Feature
MPLS 并没有取代 IP，而是作为一种 IP 增强技术
支持面向连接的服务质量
支持流量工程，平衡网络负载
有效地支持虚拟专用网 VPN

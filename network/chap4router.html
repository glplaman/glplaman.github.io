路由表 Router Table
路由表中的每一个条目 Entry 代表一条路由信息，指导路由器如何转发数据包。其包含三个主要部分：
  1. 网络地址 Network：

    目标网络的 IP 地址和子网掩码，采用CIDR记法；如 128.1.2.192/26

  2. 转发端口 Port：

    数据包应该从路由器的哪个物理或逻辑接口（如端口 0、1、3）发送出去

  3. 下一跳IP地址 Next Hop IP：

    如果目标网络不是直连的，数据包需要先发给另一个路由器，这个字段就是下一个路由器的 IP 地址

    如果目标网络是直连的，这个字段通常显示为 “-”，表示直接交付，无需经过其他路由器

路由表的转发
路由表
network port next hop ip
128.1.2.192/26 1 -
128.1.2.128/26 2 -
128.1.3.64/26 3 192.168.3.2

凡是目标 IP 在 128.1.2.192/26 这个网段内的数据包，路由器会直接通过端口 1 发送出去，因为该网络是直连的

凡是目标 IP 在 128.1.2.128/26 这个网段内的数据包，路由器会直接通过端口 2 发送出去，同样是直连网络

目标网络 128.1.3.64/26 不是直连的。路由器会将数据包通过端口 3 转发给下一跳路由器，下一跳路由器的 IP 地址是 192.168.3.2

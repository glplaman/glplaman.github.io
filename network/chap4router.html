路由表 Router Table
路由表中的每一个条目 Entry 代表一条路由信息，指导路由器如何转发数据包。其包含三个主要部分：
  1. 网络地址 Network：

    IP地址和子网掩码，采用CIDR记法；如 128.1.2.192/26

  2. 转发端口 Port：

    指明数据包应该从路由器的哪个物理或逻辑接口发送出去；如0、1、3

  3. 下一跳IP地址 Next Hop IP：

    如果目标网络不是直接连接在本路由器的端口上，那么数据包需要先发送到另一个路由器（即“下一跳”）

    这个字段就是那个“下一跳”路由器的IP地址

    如果目标网络是直连的（如前两行所示），则此字段为“–”，表示数据包可以直接交付，无需经过其他路由器

PT中的路由器 Router

第一代 (G1)：2811（百兆接口，性能最低，属于“能用但落后”的型号）
第二代 (G2)：2901 < 1941 < 2911（性能依次递增，2911最强）
第四代 (4000)：4321 < 4331（4321是入门，4331是主流）

思科在推出ISR G2（第二代）之后，直接跨越到了以全新架构设计的ISR 4000系列（第四代）

之所以没有G3，是因为4000系列进行了颠覆性的革新，为了强调这种代际飞跃，他们选择直接命名为“第四代”

2811
类型：第一代集成多业务路由器（ISR G1）
定位：出口路由器（早期经典款）
用途：连接外部网络（如互联网），执行 NAT、ACL 访问控制、DHCP 服务等出口功能
性能已落伍，PT 中仍可用，但百兆接口不匹配千兆交换机，不推荐作为主力出口
特点：

整机吞吐量约 61 Mbps

内置 2 个 10/100 Mbps 百兆以太网口（FastEthernet）

默认内存：DRAM 256MB，Flash 64MB

支持 12.x / 15.x IOS（部分功能受限）

1941
类型：第二代集成多业务路由器（ISR G2）
定位：出口路由器（入门级）
用途：连接外部网络，执行 NAT、ACL、DHCP 等出口功能，适用于小型企业或分支机构
性能低于 2911，可作为小型网络出口，若网络规模较大建议升级
特点：

整机吞吐量约 100 Mbps

内置 2 个 10/100/1000 Mbps 千兆以太网口（GigabitEthernet）

默认内存：DRAM 512MB，Flash 256MB

支持 15.x IOS，功能较全面

2901
类型：第二代集成多业务路由器（ISR G2）
定位：出口路由器（经济型）
用途：连接外部网络，执行 NAT、ACL、DHCP 等出口功能，适用于小型分支机构
性能在 G2 系列中最低，性价比不如 1941 和 2911，不推荐选型
特点：

整机吞吐量约 75 Mbps

内置 2 个 10/100/1000 Mbps 千兆以太网口（GigabitEthernet）

默认内存：DRAM 512MB，Flash 256MB

支持 15.x IOS

2911
类型：第二代集成多业务路由器（ISR G2）
定位：出口路由器（中型分支 / 实验首选）
用途：连接外部网络，执行 NAT、ACL、DHCP、VPN 等出口功能，适用于中型分支机构或作为 PT 实验的标准出口设备
PT 中最推荐的出口路由器型号，能完美匹配 3560/3650 三层交换机
特点：

整机吞吐量约 180 Mbps

内置 3 个 10/100/1000 Mbps 千兆以太网口（GigabitEthernet）

默认内存：DRAM 512MB，Flash 256MB

支持完整的 15.x IOS 功能

是 G2 系列中性价比最高的型号，接口丰富，性能充足

4321
类型：第四代集成多业务路由器（ISR 4000 系列）
定位：出口路由器（新一代入门级）
用途：连接外部网络，执行 NAT、ACL、DHCP、VPN 等出口功能，支持 SD-WAN 等新特性
性能与 1941 相当，可作为 1941 的新一代替代品，但在 PT 中功能差别不大
特点：

整机吞吐量约 100 Mbps

内置 2 个 10/100/1000 Mbps 千兆以太网口（GigabitEthernet），支持扩展模块

默认内存：DRAM 4GB，Flash 4GB

基于 x86 架构，支持更高级的加密和应用可视化

4331
类型：第四代集成多业务路由器（ISR 4000 系列）
定位：出口路由器（新一代主流级）
用途：连接外部网络，执行 NAT、ACL、DHCP、VPN 等出口功能，支持 SD-WAN、应用可视化等前沿特性
如果想体验新一代平台，这是首选，性能与 2911 相当，功能更现代
特点：

整机吞吐量约 200 Mbps

内置 3 个 10/100/1000 Mbps 千兆以太网口（GigabitEthernet），支持扩展模块

默认内存：DRAM 4GB，Flash 4GB

基于 x86 架构，是 2911 的直接升级替代品

首选 2911 经典稳定，性价比最高，PT 实验最稳妥

次选 4331 新一代平台，性能与 2911 持平，功能更新

备选 1941 / 4321 小型网络出口，规模较小时可用

不推荐 2811 / 2901 性能落后（2811 百兆口，2901 吞吐量低），不匹配千兆交换机

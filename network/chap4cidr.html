无分类域间路由 CIDR

CIDR - Classless Inter-Domain Routing
为每个IP地址分配一个数字 n 作为前缀 prefix
表示IP地址的前 n 位用于标识网络，而剩余的 32-n 用于标识主机
相应地，对应的掩码就是前 n 位是1，其他为0
消除了地址分类和子网划分的概念，IP地址重新归于2级结构
无分类域间路由
network prefix host ID
n bit (32-n)bit
[] 128.14.35.7/20
红色部分是网络部分，20 位；其它 32 - 20 = 12 位是主机部分
将IP地址中，将主机部分全置0，就是网络地址
将IP地址中，将主机部分全置1，就是广播地址

特殊的CIDR地址块
网络前缀位数n=32，全部是前缀，没有主机，称为主机路由
网络前缀位数n=31，主机号只有1位，所以只有2个IP地址，没有终端主机；用于点对点链路(无编号网络)
网络前缀位数n=30，主机号只有2位，所以只有4个IP地址
网络前缀位数n=0，IP地址也为0，即：0.0.0.0/0，称默认路由

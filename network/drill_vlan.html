实验步骤
  1. 创建网络拓扑
  2. 各主机配置 IP 地址
  3. 检查各主机ARP缓存表
    4. arp -a
  4. 查看各交换机的 MAC 地址表
    5. display mac-address
  5. PC1 PING PC4，成功
    6. ping 192.168.1.4
  6. 检查各主机缓存表
    7. arp -a
  7. 查看各交换机的 MAC 地址表
    8. display mac-address
  8. 查看老化时间

    等待一段时间（180s），再次检查各主机缓存表

    等待一段时间（300s），再次检查各交换机 MAC 地址表

  9. 创建 VLAN 并划分端口
  10. 查看 VLAN
    11. dis vlan
  11. 测试连通性

    PING

    Wireshark

  12. 指定 Trunk 口并放行 VLAN
  13. 查看各交换机端口模式
    14. display port vlan
  14. 测试连通性

    PING

    Wireshark

  15. 逐步退出 quit 或直接 return 退出到用户视图，保存各交换机设置
    16. save

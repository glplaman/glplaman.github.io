概述 Overview
每个互联网节点Node分配一个全世界范围内唯一的标识符 - unique
长度32bit，由1、0组成
为方便使用，通常使用点分十进制记法 - in dotted-decimal notation
每8个bit一组；共4组
采用两级结构：网络号、主机号
两个唯一

网络号在整个互联网中唯一

主机号在所连接的网络中唯一

有效IP地址 Valid
  • 网络号不能是127 - The network ID cannot be 127.
  • 网络号和主机号不能都是255 - The network ID and host ID cannot both be 255.
  • 网络号和主机号不能都是0 - The network ID and host ID cannot both be 0.
  • 对给定网络，网络号必须唯一 - The host ID must be unique for a given network ID.

基本概念 Concept
网络地址 Network Address

主机号全为 0 的地址

不能分配给用户主机使用

广播地址 Broadcast Address

主机号全为 1 的地址

不能分配给用户主机使用

公网IP地址 Public Address

在互联网上标识和定位一个设置

通常需付费或由ISP提供

私网IP地址 Private Address

在私有网络上标识和定位一个设置，如局域网

必须通过网络地址转换 NAT 才能访问公网

10.0.0.0 - 10.255.255.255 (10.0.0.0/8)

172.16.0.0 - 172.31.255.255 (172.16.0.0/12)

192.168.0.0 - 192.168.255.255 (192.168.0.0/16)

保留IP地址块 Reserved Address

不能用于普通公网主机分配的特殊 IP 地址或地址段

回环地址：127.0.0.0/8

广播地址：255.255.255.255

默认网络：0.0.0.0/8

多播地址：224.0.0.0 – 239.255.255.255

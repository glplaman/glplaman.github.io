代码托管

@Git
概述 Overview
分布式版本控制系统，即管理代码仓库的工具
常见的仓库：Github 或 Gitee
更多 Git 应用，请访问 Git Details
下载和安装 Download & Installment
打开 Git 官网，选择对应的操作系统和版本，点击下载并安装
选择 vs code 为默认编辑器
使用 main 覆盖默认分支
查看版本 View
右键点击桌面空白处，选择 Git Bash Here，打开终端窗口，输入以下命令
Git Bash 就是一个迷你型的 Linux 系统哦
$ git -v
$ git --version
配置 Config
使用户名和邮箱将 Git 和代码仓库关联起来
用户名和邮箱仅仅作为签名，用于提交记录，以区分提交用户，和代码仓库账号没有关系，不涉及登录或权限
如果没有关联，无法提交 commit
$ git config --global user.email 1942194789@qq.com
$ git config --global user.name glpla

应用 Application

克隆仓库 clone
将远程仓库复制到本地
通常是第一次使用别人的仓库；后续直接拉取 pull 就可以和仓库保持一致
$ git clone url
拉取仓库 pull
在第一次克隆 clone 的基础上，通过拉取和原来仓库保持一致
$ git pull <name> <branch>
如果之前提交使用 -u 设置了追踪，可以直接拉取
$ git pull
项目首次推送项目到远程仓库
  1. 在项目目录，右键 → GIT BASH
  2. 初始化；交给 Git 托管
    3. $ git init
  3. 追踪文件；点表示所有文件
    4. $ git add .
  4. 提交到本地仓库
    5. $ git commit -m "project first commit"
  5. 添加远程仓库 url，并指定别名 origin
    6. $ git remote add origin url
  6. 推送到远程仓库
    7. $ git push -u origin main
  7. 后续项目如果有更新，则重复 add、commit 和 push
    8. $ git add .
$ git commit -m "project first commit"
$ git push
查看关联的远程仓库 remote
使用 -v 可以查看关联仓库的详细信息
$ git remote -v
origin  https://github.com/glpla/glpla.github.io.git (fetch)
origin  https://github.com/glpla/glpla.github.io.git (push)
本地撤销 reset
场景：某次 commit 中，提交了一个大文件，导致 push 失败，需要返回到前面某次版本
  1. 以单行形式查看前面5次提交的 commitid
    2. $ git log --oneline -5
  2. 撤销提交
    3. $ git reset --soft commitId
  3. 重新 add
  4. 重新 commit
  5. 重新 push
版本回退 revert
已经提交了5次
经过测试，发现第2次提交的版本比较符合要求
第3次、第4次、第5次提交作废
为了避免冲突，应保留第3次、第4次、第5次提交，使用 revert 回退到第2次提交
  1. 以单行形式查看前面5次提交的 commitid
    2. $ git log --oneline -5
95b598e (HEAD -> main, origin/main, origin/HEAD) v5 // HEAD
8206d43 v4 // HEAD~1
14b00dc v3 // HEAD~2
688d789 v2 // HEAD~3
de89d7e v1
  2. 撤销最近3次提交；起点：688d789（不包含本身），终点：HEAD（包含）
    3. git revert --no-commit 688d789..HEAD
  3. 或者使用 HEAD 偏移指定，无需查看 HASH
    4. git revert --no-commit HEAD~3..HEAD
  4. 继续 add
  5. 继续 commit
  6. 继续 push

A..B 表示：从 A 之后到 B 之间的所有提交

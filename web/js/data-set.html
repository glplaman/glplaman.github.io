@Set
ES6 新增数据类型
无序、唯一
数据类型仍然归类于 Object
Set 的设计初衷是只存储唯一值的集合，不像 Object/Map 那样是键值对 - store unique values of any type
Set 结构通常没有键名，只有键值；或者说键名和键值是同一个值
Set 更多的是 存储值和使用值
为了与 Map 接口保持一致，也提供了类似的键值方法
更多信息，请访问 MDN - Set

Set 转换成 Array
方案1：使用扩展运算符 ... 直接展开
let arr = [...set]
方案2：使用数组方法构建 Array.from(set)
let arr = Array.from(set)
Array 转换成 Set
转换过程中，如果 Array 有重复的指，将被去重 
let arr = [1, 1, 2, 2]
let tmp1 = new Set(arr)
let tmp2 = [...new Set(arr)]
遍历集合 Set
Set 是一个特殊的集合类型，没有传统意义上的“属性名”或“索引”
遍历一个 Set 集合时，必须使用 for...of，而不是 for...in。这是由 JavaScript 语言规范和数据结构特性决定的
for (let item of set) {
  console.log(item);
}
forEach
set.forEach(item => {
  console.log(item);
})

应用 Application

Set 的主要价值在于它的 自动去重 和 高效的成员检测/查找成员、交集
现实场景
合并多个数据源，比如本地缓存 + 网络新数据，可能有交集
用户多次点击导致重复提交，前端未防抖，造成同一项被多次加入列表
分页/筛选切换时状态管理错误，导致旧数据和新数据混合
测试或 mock 数据不规范，开发阶段临时数据可能重复
简单数组去重
先把数组转换为集合；再把集合转换为数组
let arr = [1, 1, 2, 2]
let set = new Set(arr)
let res = [...set]
字符串去重
字符串本身也是数组 - 字符类型的数组
let str='helloworld'
let set=[...new Set(str)]
对象数组去重
去除 id 相同的值
let arr = [
  { id: 1, name: 'Alice' },
  { id: 1, name: 'Alice' },
  { id: 2, name: 'Bob' }
];
生成 key 唯一 的 Map
let map = new Map( arr.map(item=>[item.id,item]))
获取 Map 的值
let vals = map.values()
使用扩展运算符 ...
arr = [... vals]
一步到位
arr =[... new Map(arr.map(item=>[item.id, item])).values()]

集合

@Set
ES6 新增数据类型
数据类型仍然归类于 Object
Set 的设计初衷是只存储唯一值的集合，不像 Object/Map 那样是键值对
Set 结构通常没有键名，只有键值；或者说键名和键值是同一个值
Set 更多的是 存储值和使用值
为了与 Map 接口保持一致，也提供了类似的键值方法
更多信息，请访问 MDN - Set
使用构造函数
let set = new Set()
使用迭代对象
let set = new Set([1,2,3])
let set = new Set([{id:0},{id:1},{id:2}])

应用 Application

Set 的主要价值在于它的 自动去重 和 高效的成员检测
现实场景
合并多个数据源，比如本地缓存 + 网络新数据，可能有交集
用户多次点击导致重复提交，前端未防抖，造成同一项被多次加入列表
分页/筛选切换时状态管理错误，导致旧数据和新数据混合
测试或 mock 数据不规范，开发阶段临时数据可能重复
简单数组去重
先把 Array 转换为 Set
再把 Set 转换为 Arrayy
let arr = [1, 2, 3, 4, 5, 3, 2, 5, 6, 7, 8]
arr = [...Array.from(new Set(arr))]
console.log(arr);
字符串去重
let str='helloworld'
let set=[...new Set(str)]
对象数组去重
去除 id 相同的值
let arr = [
  { id: 1, name: 'Alice' },
  { id: 1, name: 'Alice' },
  { id: 2, name: 'Bob' }
];
生成 key 唯一 的 Map
let map = new Map( arr.map(item=>[item.id,item]))
获取 Map 的值
let vals = map.values()
使用扩展运算符 ...
arr = [... vals]
一步到位
arr =[... new Map(arr.map(item=>[item.id, item])).values()]
虽然我们可以事后去重，但更优的做法是在数据进入集合前就防止重复

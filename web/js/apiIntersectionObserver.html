IntersectionObserver

IntersectionObserver 是现代浏览器提供的一种高性能API，用于异步监测目标元素与其祖先元素或视口的交叉状态
相比传统的滚动事件监听方式，它具有更好的性能表现
const observer = new IntersectionObserver(callback, options);
参数说明
callback: 当元素交叉状态发生变化时触发的回调函数

进入视口，触发

离开视口，触发

options (可选): 配置对象，定义观测条件
核心方法 Methods
observe(target)：开始观察指定的目标元素
unobserve(target)：停止观察指定的目标元素
disconnect()：停止观察所有目标元素
回调函数参数 callback
回调函数接收一个 entries 数组，可以批量处理多个元素的状态变化

如：不只一个元素进入视口

每个元素包含以下属性：

target: 被观察的目标元素

isIntersecting: 布尔值，表示目标元素是否与视口相交

intersectionRatio: 相交比例 (0-1)

boundingClientRect: 目标元素的边界矩形

rootBounds: 根元素的边界矩形

intersectionRect: 相交区域的边界矩形

淡入淡出
触底加载/动态加载/无限
侦听最后一项
如果有交叉，就开始加载
图片懒加载
图片进入视口时，指定src属性，开始渲染图片
<img class="ob-img" loading="lazy" data-src="/utils/zeng/0.jfif" alt="" src="">
// 创建观察器实例
const ob = new IntersectionObserver(cb);

// 获取所有图片 .ob-img，开始观察
const obImgs = document.querySelectorAll('.ob-img');
obImgs.forEach(img => {
  ob.observe(img);
});

// 观察回调函数
function cb(entries) {
  entries.forEach(entry => {
    // 当图片进入视口时
    if (entry.isIntersecting) {
      // 获取对象实例
      let img = entry.target;
      // 获取对象自定义数据并设置对象图片src属性
      img.setAttribute('src', img.getAttribute('data-src'));
      // 停止观察当前对象
      ob.unobserve(img);
    }
  });
}
选项 Options
threshold

0 - 元素任何部分可见就触发；默认

0.5 - 元素 50% 可见时触发

1.0 - 元素 100% 可见时触发

root

指定根元素

默认是视口

也可以指定特定元素作为容器

root: document.querySelector('.scroll-container')
rootMargin

根边距；如提前 100px 触发

rootMargin: '100px'

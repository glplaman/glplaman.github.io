参数传递

@Argument

基本类型：传递的是数据的拷贝

引用类型：传递的是内存地址的拷贝

无论传递的是基本类型还是引用类型，本质上都是将值的 副本 传递给函数
基本数据类型
对于数字、字符串、布尔值等，把变量的值复制一份，给到形参
函数内部如果修改了形参，完全不会影响外部变量
引用数据类型
变量名代表的是对象的内存地址
传递的是地址的副本 - 调用函数时，把这个地址的副本传给了形参
如果传递整个对象本身，太耗内存
因为都指向同一个内存地址，所以修改会影响原对象
let a = {
  name: 'glpla',
  age: 20
}
function change(o) {
  // a 和 o 指向堆内存中的同一个对象
  // 对 o 的操作会影响到 a
  o.age = 10 
  // o 重新指向其它地址；a 的指向不变
  o = {
    name: 'fuck',
    age: 30
  }
  return o
}
// b 指向了 o 的地址
let b = change(a)
console.log(b.age);
console.log(a.age);
console.log('done');

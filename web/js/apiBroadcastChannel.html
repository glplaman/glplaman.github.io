BroadcastChannel

2026-05-24

同域标签页之间的通信/频道广播

通信的标签页 都 声明 BroadcastChannel

一个发送消息；另外一个接受消息

标签A：发送信息；这里使用按钮的单击事件触发

const channel = new BroadcastChannel('my_channel');
let btn = document.getElementById('btn')
btn.addEventListener('click', fn)
function fn() {
  channel.postMessage({ text: '你好，标签B，我是标签A！' });
}

标签B：接受信息；这里使用 Console 查看

const channel = new BroadcastChannel('my_channel');
channel.onmessage = function (event) {
  console.log('收到消息：', event.data);
};

映射

@Map
ES6 新增数据类型
数据类型仍然归类于 Object
存储键值对 key-value pairs
每个 key 只能出现一次；key 唯一
有序、不唯一
无法触发视图更新
更多信息，请访问 Map()
构造函数 constructor
new Map()
一个可迭代对象
new Map(iterable)
或是一个二元数组
const map = new Map([['name', 'glpla'], ['gender', 'male'], ['age', 18]])
可以从数组 map() 的处理结果中获取
const map=new Map(arr.map(item=>[item.id,item.title]))
也可以从对象中获取：Object.entries() 
const arr = new Map(Object.entries({ id: 1, name: 'glpla', age: 18 }))
实例属性 Instance properties
大小：size
实例方法 Instance methods
增：set(key,value)；没有增加；有则改之
删：delete(key)
查：get(key)
清：clear()
是否存在：has(key)
遍历：forEach
迭代对象：entries()；包含 Map 对象中所有键值对 [key, value] 二元数组
[] Map 转换成 Array
方法1：Array.from(map) - 从一个 Map 转换为 Array
方法2：[...Map] - 扩展运算符，从一个map展开为 Array
[] 商品的收藏和取消；更多案例，请访问 数组 Array
利用映射作为判断依据
单击时，如果为真，则收藏，key 为商品 id，value 为收藏时间
favorites.set(product._id, new Date().toLocaleString())
单击时，如果为假，删除对应的key
删除时，是否需要判断 key 是否存在 
favorites.delete(product._id)
更新全局数据
app.globalData.favorites = favorites
无法直接本地存储，会丢失数据的映射特性
wx.setStorageSync('favorites', favorites)// x
将 Map 的键值对经过 Object.fromEntries() 处理后，转换成对象，然后再缓存 
wx.setStorageSync('favorites', Object.fromEntries(favorites))
相应的，启动/获取/初始化时，也不能直接获取，必须使用 Object.entries() 重新创建 
favorites = new Map(Object.entries(wx.getStorageSync('favorites') || {})) || new Map(),

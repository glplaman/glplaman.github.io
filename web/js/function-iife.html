立即执行函数

@IIFE
IIFE - Immediately Invoked Function Expression
定义一个匿名函数并立即调用这个函数/执行
函数仅仅执行1次；不需要多次调用函数
创建一个独立的作用域，避免变量污染全局命名空间
应用
数据隐私
状态初始化
执行异步代码
实现
方案1：使用普通函数；分号;：防御性编程习惯，防止与前一行代码发生语法错误，尤其是在代码被压缩（minify）或拼接时
;(function() {
  // 函数体
})();
方案2：使用箭头函数
;(()=> {
  // 函数体
})();
加载数据
避免封装函数
使用异步等待 async-await 加载数据 Fetch、Supabase.com
;(async () => {
  let res = await fetch('https://glpla.github.io/utils/data/coffee.json')
  let data = await res.json()
  console.log(data)
})();

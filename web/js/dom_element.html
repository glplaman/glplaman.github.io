滚动相关 Scroll
1. element.scrollIntoView()
滚动进入视图 - 滚动父级容器，使当前元素可见
默认和可滚动的祖先容器顶部对齐

aligned to the top of the visible area of the scrollable ancestor

选项 options

behavior：滚动行为，auto | smooth | instant；smooth也可以由 CSS 实现

block：垂直方向和容器的对齐方式：start | end | center | nearest；通常指定 nearest，仅最近的可滚动容器受滚动影响

container：all | nearest

inline：start | end | center | nearest；水平方向和容器的对齐方式；多使用 center

可以代替 <a>实现页面内部导航/锚点跳转
适合用于导航、焦点定位等场景
const links = document.querySelectorAll('.nav-item')
const conts = document.querySelectorAll('.nav-cont')
links.forEach((link, ind) => {
    link.addEventListener('click', () => {
        // container 属性存疑，请使用 block
        conts[ind].scrollIntoView({ behavior: 'smooth', block: 'nearest' })
    })
})

const cart = document.querySelector('.cart');
const icons = document.querySelectorAll('.icon');

const cartPos = cart.getBoundingClientRect()
icons.forEach((icon, ind) => {
  icon.addEventListener('click', () => {
    const iconPos = icon.getBoundingClientRect()
    const ball = document.createElement('span');
    ball.style.setProperty('--start-left', `${cartPos.left - cartPos.width / 2 + 10 - iconPos.left}px`);
    ball.style.setProperty('--start-top', `${cartPos.top + 10 - iconPos.top}px`);
    icon.appendChild(ball);
    ball.addEventListener('animationend', () => {
      ball.remove();
    })
  })
})

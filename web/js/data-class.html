ES6 新增数据类型
数据类型仍然归类于 Object
class 类
是一种蓝图或模板
用于创建具有相同属性和方法的对象
使用关键字 class 定义
类名采用大驼峰
1. 创建；包括3部分：构造函数、属性和方法
class Stu {
  // part1：constructor
  constructor(name, age) {
    this.name = name
    this.age = age
  }

  // part2：attributes

  // part3：methods
  getAge() {
    return this.age
  }
}
2. 使用；实例化
let stu = new Stu('gl', 18)
console.log(stu.getAge());
分析下面类的特点并思考：类的定义中，哪些地方可以使用 this？哪些地方不可以使用 this？
class Singleton {
  static _instance = null;
  constructor(name) {
    if (Singleton._instance) {
      return Singleton._instance;
    }

    this.name = name;
    this.instanceId = Math.random().toString(36).substring(2, 10);
    Singleton._instance = this;

    return this;
  }

  static getInstance(name) {
    if (!Singleton._instance) {
      Singleton._instance = new Singleton(name);
    }
    return Singleton._instance;
  }

  static resetInstance() {
    Singleton._instance = null;
  }
}

正则表达式

@RegExp
Overview
功能强大
在 / / 内定义正则表达式
更多信息，请访问 i hate regex
\d
数字
\S
非空白字符：除了空格、制表符、换行符等空白字符以外的所有字符
\s
空白字符：空格、制表符\t、换行符\n、回车符\r、换页符\f、垂直制表符\v等
g
全局标志，表示在整个字符串中进行匹配，而不是在找到第一个匹配项后停止
$
尾/结束
+
1个或多个
*
0个或多个
{}
量词 uantifier
精确指定前面的字符（或组合）需要重复出现的次数
{n}：匹配 n 次；精确匹配
{n,}：至少匹配 n 次，无上限
{n,m}：匹配 n 到 m 次
^
出现在正则表达式的最前面，且不在方括号 [] 里时，代表行的开始
出现在方括号 [] 内部，并且是第一个字符时，代表取反/非/不是 Not
()
捕获分组
() 圈起来的部分，会被暂时捕获/存起来；使用$和数字表示第几个分组
在替换时，可以使用 $1、$2 引用这些分组

应用

match
查找匹配的串并输出结果
> let re=/\d+/g;
undefined
> re
/\d+/g
> console.log('123 234 456'.match(re))
[ '123', '234', '456' ]
replace
替换匹配的串
隐藏手机中间4位
隐藏前：52188881314
隐藏后：521****1314
let cell = '52188881314';
let reg = /^(\d{3})\d{4}(\d{4})$/
let res = 'cell'.replace(reg, '$1****$2')
DD打车只显示手机后4位
隐藏前：52188881314
隐藏后：*******1314
let cell = '52188881314'
let reg = /^\d{7}(\d{4})$/
let res = cell.replace(reg, '*******$1')
移除空格
移除串前面的所有空格
str = str.replace(/^\s+/, '');
移除串后面的所有空格
str = str.replace(/\s+$/, '');
移除串前面、后面的所有空格 - 分俩次处理即可
为什么使用 + 而不使用 *
编辑结构 - 将每个非空白字符都套上1个<span>
let msg = 'hi,there.'
let res = msg.replace(/\S/g, '<span>$&</span>')
$&：一个特殊的替换模式，用于表示整个匹配的子字符串
将所有 dd 中的 data-title 属性移动到 a 中
移动前
<dd data-title="RollABall"><a href="./index.html">吃掉你</a></dd>
移动后
<dd><a href="./index.html" data-title="RollABall">吃掉你</a></dd>
思路

捕获 dd 中所有 data-title 的值到第一分组

捕获 a 的所有内容到第2分组

使用的查找正则表达式为
<dd\s+data-title="([^"]*)"\s*><a\s+([^>]*)>
替换的正则表达式为
<dd><a $2 data-title="$1">
编辑结构 - 瑞幸咖啡(高新万达店) 处理为 高新万达店

Form

<form>自带校验属性 pattern；比事件处理中的校验优先级高；如果同时存在，事件处理的校验无效
<form @submit.prevent="submit">
  <input type="text" v-model="user.name" placeholder="6位数字" :pattern="reg" title="请输入6位数字">
  <p v-if="errorMsg" style="color: red;">{{ errorMsg }}</p>
  <button>submit</button>
</form>
const reg = /^\d{6}$/;
const errorMsg = ref('');
const user = ref({
  name: ''
})
const submit = () => {
  const value = user.value.name;

  if (!reg.test(value)) {
    errorMsg.value = '请输入正确的6位数字';
    return;
  }

  errorMsg.value = '';
  console.log('提交成功:', value);
};

映射

@Map
ES6 新增数据类型
数据类型仍然归类于 Object
也叫字典
存储键值对 - holds key-value pairs
key 可以是任意类型；普通对象的键只能是字符串或 Symbol
每个 key 只能出现一次/唯一 - may only occur once/unique
利用 key 的唯一，可以去重；后续同名的 key 会覆盖前面 key 的值
更多信息，请访问 MDN - Map

构造函数 Constructor
const m = new Map()
一个可迭代对象
const m = new Map(iterable)
或是一个二元数组
const m = new Map([['name', 'glpla'], ['gender', 'male'], ['age', 18]])
可以从数组 map() 的处理结果中获取
const m = new Map(arr.map(item=>[item.id,item.title]))
也可以从对象中获取：Object.entries() 
const arr = new Map(Object.entries({ id: 1, name: 'glpla', age: 18 }))

基本使用
const map = new Map()
map.set('name', 'glpla')
map.set('gender', 'male')
map.set('age', 18)
console.log(map.keys());// [name, gender, age]
console.log(map.values());// [glpla, male, 18]
console.log(map.size);// 3
map.delete('name')
console.log(map.size);// 2
Map 转换成 Array
方法1：Array.from(map) - 从一个 Map 转换为 Array
方法2：[...Map] - 扩展运算符，从一个 Map 展开为 Array

应用 Application

相比普通对象 Object，Map 在键的类型、插入顺序、性能和语义清晰度等方面具有显著优势
商品的收藏和取消
利用映射作为判断依据
单击时，如果为真，则收藏，key 为商品 id，value 为收藏时间
favorites.set(product._id, new Date().toLocaleString())
单击时，如果为假，删除对应的key
删除时，是否需要判断 key 是否存在 
favorites.delete(product._id)

简介 overview
inline
Scalable Vector Graphics - 可缩放矢量图形
使用 XML 描述 2D 图形；是万维网联盟的标准
SVG 基于 XML：每个元素都可用附加 JavaScript 事件处理器
每个绘制的 SVG 图形均被视为对象。如果 SVG 对象的属性发生变化，浏览器能够自动重绘
更多信息，请访问 MDN - SVG、SVG Path Visualizer
特点 Features
可以使用 SVG 属性
也可以使用内联样式或外部 CSS 样式，更加方便 JavaScript 控制
CSS 的优先级高于元素的属性
可以使用 CSS 变量
SVG vs Canvas
Canvas 是 HTML5 提供的新标签元素，而 SVG 存在的历史要比 Canvas 久远，已经有十几年
Canvas 绘制出来的图形或传入的图片都依赖分辨率，能够以 .png 和 .jpg 格式保存存储图像，是位图|标量图；SVG 绘制的是矢量图
Canvas 不支持事件处理器，SVG 支持事件处理器
Canvas多用于统计用的图表、大型的网络游戏；SVG：地图、动态的小图标 icon

线 <line>
起点：(x1,y1)
终点：(x2,y2)
笔触/线条颜色：stroke；默认透明色 transparent；必须指定 stroke，否则线条不可见
笔触/线条粗细：stroke-width；默认是 1
stroke、stroke-width 可以使用 CSS 指定
配合 stroke-dasharray 和 stroke-dashoffset 绘制更丰富的线条
<svg class="svg-basic">
    <line class="svg-line" x1=0 y1=0 x2=300 y2=300 stroke="#089" stroke-width="2"></line>
</svg>
或使用 CSS 指定笔触和粗细
.svg-line {
    stroke: #f40;
    stroke-width: 2px;
}
点划线：改变数字，查看点划线起点的偏移情况
.svg-line-dash {
    stroke: #f40;
    stroke-width: 4px;
    stroke-dasharray: 10 20;
    stroke-dashoffset: 0;
}
stroke-dashoffset:
加载器/进度条：stroke-dasharray的占空比从开始到较大的值
#loader-circle {
  fill: transparent;
  stroke: #f40;
  stroke-width: 2px;
  stroke-dasharray: 0 1000;
  animation: alternate loader 5s linear forwards;
}

@keyframes loader {
  to {
      stroke-dasharray: 1000;
  }
}
矩形 <rect>
位置：x、y
宽高：width、height
填充：fill；默认是黑色；如不需要，可以设置为 none
可以指定圆角属性：x、y方向上的圆角 rx、ry
可以指定线条属性
<svg class="svg-basic">
    <rect x=40 y=40 width=220 height=220 rx=10 ry=10 fill=#f40></rect>
</svg>
圆 <circle>
圆点 cx、cy； 默认左上角(0, 0)
半径 r
<svg class="svg-basic">
    <circle cx=150 cy=150 r="150" fill="#f40"></circle>
</svg>
.svg-basic:hover circle {
  fill: #f489f3;
}
椭圆 <ellipse>
位置：cx、cy；
圆角：x、y方向上的圆角 rx、ry
<svg class="svg-basic">
    <ellipse cx=150 cy=150 rx="100" ry="80" fill="#f40"></ellipse>
</svg>
多边形 <polygon>
点的集合 points，使用空格分割每个点坐标；如果没有回到起始点，会自动闭合
笔触颜色 stroke
宽度 stroke-width
填充 fill
还有一个 <polyline>元素；可以是闭合；也可以是不闭合 
<svg class="svg-basic">
    <polygon class="svg-polygon" points="80,80 220,80 150,220"></polygon>
</svg>
.svg-polygon {
    stroke: #f40;
    stroke-width: 2px;
    fill: none;
}

基本概念 Concepts

工作簿 Workbook

- 特指 Excel 文件

- 也称文档 Document 或文件 File

- 由一个或多个工作表 Sheet 组成

- 文件扩展名 .xlsx

工作表 Sheet

- 由行 Row 和列 Column 决定的单元格 Cell 组成

- 结构和表格 Table 相似

单元格 Cell

- 存放数据的最小单元 Unit

- 每个单元格都有一个地址 Address，由所在的行和列决定

- 行：阿拉伯数字，1、2、3、4...

- 列：大写字母，A、B、C、D...

条件格式 Conditional Formatting

- 突出显示 Highlight

- 最前/最后 Top/Bottom

- 数据条 Data Bars

- 色阶 Color Scales

- 图标集 Icon Sets

引用单元格的数据时，根据行、列变化情况，分为

- 相对地址，行、列都会变化，C3

- 绝对地址，行、列固定不变，$C$3

- 混合地址，行、列其中一个会变化，$C3、C$3

- 使用 F4 切换地址模式

语法 Syntax
CSS 由选择器 选择器 Selector 和声明块 Declaration 组成
选择器

选择一个或多个元素，以便应用样式

选择器可以是标签、类、ID 等单一选择器或其它复合选择器

声明块

用 花括号 {} 括起来，由一条或多条规则 rule 构成，为选出来的元素指定样式

多条规则使用 分号 ; 分隔

规则：

每个规则都包含一个 CSS 值对：属性名 Properties 和属性值 Value

值对使用 冒号 : 分隔

Selector {
  Properties1: Value1;
  Properties1: Value2;
}
类名为 warn 的 CSS 样式，包含2条规则，指定了被选中的元素/应用该类样式的元素的颜色和字体重量/加粗 
.warn {
  color: #eb2f06;
  font-weight: 600;
}

使用 Usage

行内样式/内联样式
使用 style 属性为元素定义样式
仅适用当前元素
行内样式具有最高优先级，并且将覆盖外部和内部样式以及浏览器默认样式
style 还可以指定 内联变量 供当前元素的样式使用；内联样式和内联变量互不影响
通常配合 JavaScript 来动态改变
不符合结构 - 样式 - 逻辑分离的开发原则
内部样式
在 HTML 页面 <head> 区使用 <style> 定义样式
仅适用当前 HTML 页面的元素
不可跨页面使用
不符合结构 - 样式 - 逻辑分离的开发原则
外部样式
以样式文件的形式定义；后缀名为 .css
可以使用任何文本编辑器编写
在 HTML 页面 <head> 中使用 <link> 引入样式文件
可以在样式文件中使用 @import 导入其它样式文件；应在样式文件 首行 引入
样式文件不能包含任何 HTML 标签
适合多个 HTML 页面、多个元素
可以 缓存 到本地，加快页面访问速度
符合结构 - 样式 - 逻辑分离的开发原则
样式应用示例
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS introduction</title>

  /* 外部样式 - link */
  <link rel="stylesheet" href="./css/style.css">

  /* 内部样式 - style */
  <style>
    /* 引入其它样式文件 */
    @import url(https://at.alicdn.com/t/c/font_3859342_yxk1peemmtq.css);

    .p-txt {
        /* 全局变量 */
        color: var(--txt-wran-color);
        /* 局部变量 */
        opacity: var(--sn);
    }
  </style>
</head>

<body>
  <!-- 内联样式 -->
  <h1 style="color: #F40;">hello, world</h1>
  <!-- 内联变量 -->
  <p class=“p-txt” style="--sn: 0.1;">第1段</p>
  <p class=“p-txt” style="--sn: 0.3;">第2段</p>
</body>

</html>

特性 Features

继承性
子元素会继承父元素的某些样式
不是所有的样式都可以被继承，特别是表单类元素和超链接 <a>，很多样式不会继承父元素
叠加性
CSS 文件是按照从上到下的顺序执行；因此，同一个元素的样式，后面的样式会覆盖前面的样式
特别要注意：样式的叠加和元素上样式类的书写顺序无关，和 CSS 文件中的顺序有关
有利于实现类的复用
同类型多个功能按钮往往需要先指定公共样式，包括静态样式、动态样式，再根据功能指定专有样式
优先级
一般来说，多个样式同时作用于一个元素时，由优先级决定
优先级高的样式会覆盖优先级低的；同时还要结合不同 选择器 - selector 共同决定
样式异常或无效，请使用浏览器的开发者工具视图检查：按 F12 打开并检查
样式顺序和书写顺序对结果的影响
.active-color {
    color: #f40;
}

.color {
    color: #000;
}
    
//颜色为黑色
<div class="active-color color">CSS的样式顺序</div>

//颜色为黑色
<div class="color active-color">CSS的样式顺序</div>

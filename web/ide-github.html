HTTPS
使用用户名和密码才可以使用仓库
SSH
官话：使用 SSH 公钥可以让你在你的电脑和 Gitee 通讯的时候使用安全连接（Git 的 Remote 要使用 SSH 地址）
人话：设置本机绑定 SSH 密钥，实现免密登陆，建议安排
一个 SSH 密钥对，可以支持多个仓库
也可以单独为每个仓库创建密钥对
  1. 生成 SSH 密钥对；-t：key 类型；-C：注释
    2. ssh-keygen -t ed25519 -C "Gitee SSH Key"
  2. 添加 SSH 公钥
  3. 配置远程仓库
    4. # GitHub
git remote set-url origin git@github.com:yourusername/yourproject.git

# Gitee
git remote set-url gitee git@gitee.com:yourusername/yourproject.git
  4. 测试链接；如果不测试，会在第一次提交的时候，进行测试
    5. # 测试 GitHub
ssh -T git@github.com

# 测试 Gitee
ssh -T git@gitee.com

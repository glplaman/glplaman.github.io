表单

<form>
概述 Overview
人机交互 - 通过种类多样的表单元素，以值对 name-value 的形式收集/采集数据，提交给后端服务器 backend server处理
表单本身并不可见，除了承载脚本外，更多是作为一个壳/ 容器，提供数据请求的能力
更多信息，请访问 MDN - <form>
除了表单可以发送请求外，HTML页面解析时，碰到 <link>、<img>、<audio>、<video>、<script>等会主动请求对应的资源
表单 <form>
容器
块元素 block
表单基本结构及属性 Attribute 如下
<form action="" method="" target="" name=""></form>
<form>属性
item desc
action 表单提交给后端处理的脚本或接口
method 表单提交方式：
get：默认；请求数据；参数通过 URL 传递；参数地址栏可见
post：提交数据；数据不可见
target 展示响应的位置:
_self：默认，当前页面
_blank：新页面
_parent：父页面
_top：最顶层页面
iframe：<iframe> 页面
其他：指定页面名称
name 区分页面中不同的表单
GET方式默认不指定请求体，而是使用query的形式指定参数，易于分享
url?id=12123
表单元素
表单作为一个容器，可以容纳的表单元素类型很多；常见的表单元素和属性如下
常见表单元素
item desc
<input> 供用户输入/选择，类型最为丰富，应用最多
<select> 下拉列表
<textarea> 多行输入
<button> 按钮；通过 type 可以指定：
提交 submit：默认
清除 reset：清除表单数据，重新填写
也可使用 <input> 指定对应类型 type
<fieldset> 分组表单元素
<legend> 分组的标题
操作整个分组，如使用 disabled 属性禁止整个分组
<datalist> 数据列表，为 <input> 等文本输入元素提供一个输入可选项
permissible or recommended options available to choose
常见表单元素的属性
item desc
name 用于提交数据；还用于单选和多选的分组
value 提交数据的值
id 通常用和 <label> 的属性 for 绑定，改善用户体验
hidden 隐藏；也可以使用 CSS 隐藏 display: none

Selector
  • 属性选择器
    • // 为属性为 radio 的 input 指定强调色
input[type='radio'] {
  accent-color: #f40;
}
    // 为了保持一致，通常使用CSS变量全局定义
:root{

}
  • 伪类选择器
    • // 单行输入文本框获取焦点时指定边框

}
  • 伪元素选择器
    • // 单行输入文本框的占位符样式
input::placeholder {
  color: #f40;
}      
    // 可以不使用具体的元素而统一指定样式
::placeholder {
  color: #f40;
}

事件 Event

更多信息，请访问 事件 Event
表单事件
item desc
submit 表单提交
reset 表单重置
formdata 表单提交时构建数据
提交 submit
表单的默认事件；单击提交按钮或按回车触发
表单提交数据时，要求表单元素必须指定 name 属性，否则提交时无法获取数据
表单提交时，默认页面会跳转
本例提交使用 <input>
<form action="https://www.baidu.com" method="get" name="demo">
  <input type="text" name="uname" id="">
  <input type="password" name="upass" id="">
  <input type="submit" value="submit">
  <input type="reset" value="reset">
</form>
有时/现在需要阻止表单的默认提交事件；需要 JavaScript 参与才能提交数据
提交数据并取消默认跳转 - 使用 JavaScript
本例提交使用 <button>
<form action="https://www.baidu.com" method="get" name="demo">
  <input type="text" name="uname" id="">
  <input type="password" name="upass" id="">
  <button type="submit" value="submit">submit</button>
  <button type="reset" value="reset">reset</button>
</form>
const form = document.querySelector('form')
form.addEventListener('submit', (e) => {
  e.preventDefault()
  // ...
  // 提交数据
})
清除 reset
清除各表单元素数据，重新填写

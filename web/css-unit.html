相对单位

%
百分比
宽度 width

块级元素（Block-level elements）在水平方向上默认就是填满父容器的

即使父元素没有设置宽度（width: auto），它的计算宽度也是确定的（通常是视口宽度或上级容器的宽度）

因此，子元素的 width: 100% 依然有效，即子元素的 100% 永远有一个明确的参考基准

高度 height

块级元素在垂直方向默认是不填满的，高度完全随内容变化

CSS 规范规定：当一个元素的 height 设置为百分比时，它是相对于其包含块（Containing Block）的 height 计算的

如果包含块的 height 计算结果是 auto（即由内容撑开），那么子元素的百分比高度就会被视为 auto

只要父级没有明确高度，子级的百分比就失效，退化为 auto

宽度 width、填充 padding、空白 margin 使用百分比时，相对于父级的宽度
用于自适应布局
设置根字体
html {
    font-size: 62.5%;
}
em
相对于上一级/父级元素字体大小
如果父级没有显示的设置 font-size，则继续往上查找，直到根元素 HTML
参考过于凌乱，不建议使用。主要应用场合是设置段落的2个字符首行缩进和段落间距
p {
  text-indent: 2em;
  margin-bottom: 1em;
}
rem
相对于根元素 html 字体大小
参考唯一，比较容易调整
采用 rem 单位时，为了换算方便，通常设置 HTML 的 font-size: 62.5%，即16*62.5%=10; 16px = 1.6rem;1rem = 10px;
用于设置根字体
视口
每个视口 viewport 水平垂直各分为100份
viewpoint
item desc
vh 视口高度
vw 视口宽度
svw Small Viewport Width 安全视口宽度
svh Small Viewport Height 安全视口高度
svmin Small Viewport Minimum 安全视口中较小的尺寸
svmax Small Viewport Maximum 安全视口中较大的尺寸
最佳实践：桌面端使用 vw/vh；移动端使用svw/svh并兼容
selector {
  height: 100vh;
  height: 100svh;
}
fr
fraction | 份数；子项相对于容器的份数；多用于网格布局 grid
flex
子项在容器中的比例；多用于弹性盒子布局 flex
前端UI框架中多采用12份、24份进行布局，如 Bootstrap、element UI；更多信息，请访问 the lengths of css、The Power of em Units in CSS
em 父级参考
<div>
    <p>Lorem ipsum dolor sit amet.</p>
</div>
p {
    font-size: 2em;
}
[解读]只设置<p>元素字体大小，因为父级<div>没有设置，最终参考的是<html>的大小16px。所以最后<p>元素字体大小为 2*16px = 32px
[解读]如果<div>显式的设置了字体大小为20px，则<p>字体大小为2*20px = 40px
div {
    font-size: 20px;
}

p {
    font-size: 2em;
}

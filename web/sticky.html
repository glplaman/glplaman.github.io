粘性定位

@Sticky
兼有固定定位和相对定位的特性
更多信息，请访问 MDN - position
容器
必须有滚动；容器的内容，包括粘性元素，总高度要大于容器，容器才会出现滚动条
不能设置溢出隐藏 overflow:hidden
粘性元素
粘性定位元素位置，是由以下两个因素共同决定：

它的包含块 containing block

它的最近可滚动祖先 nearest scrolling ancestor

通常粘性元素通常是滚动容器的 直接 子元素
粘性定位元素不会脱离文档流；但是层级提升 - 比普通元素高
有距离：必须指定粘性元素到容器的位置：left、top、right、bottom之一；多使用 top
注意 z-index 的影响，应确保粘性元素位于上层
应用
适合 banner/swiper + 主导航 + 内容的网页。网页滚动时候，banner 移出，导航保留/黏贴在顶端/吸顶，内容也逐步移出
包含块 Containing block
包括以下4个部分：
内容块 Content area
填充块 Padding area
边框块 Border area
空白块 Margin area
粘性定位需要在其包含块（通常是父元素）中工作，当父元素没有明确的滚动边界时，子元素的 sticky 定位可能无法正常生效
多数情况下是父块级元素；但不总是这样

案例 cases

粘性定位；参见本页顶部导航和示例标题
页面没有滚动时，导航/标题停留在原来位置
当页面向下滚动时，导航/标题驻留/黏住在顶部一定位置
当页面向上滚动时，导航/标题返回其原来位置

  position: sticky;
  top: -15vh;
  z-index: 99;

    top: var(--chap-h);
    z-index: 2;

粘性表格标题
不能直接对表格使用粘性定位
使用额外的容器包裹表格，当表格内容超出容器高度时，表格的表头粘性定位在容器顶部
分别对 <caption> 和 <thead> 使用粘性定位
table caption {
  position: sticky;
  top: 0;
}

table thead {
  position: sticky;
  top: 30px;
  text-align: left;
  background-color: #fff;
  z-index: 1;
}
JS粘性定位 - 网站顶部导航、网站顶部导航 - codepen
滚动到一定距离后，添加粘性类
let nav = document.querySelector("nav");
window.addEventListener("scroll", () => {
	if (window.scrollY >= nav.offsetTop) {
		nav.classList.add("sticky");
	}
});

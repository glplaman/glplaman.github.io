初体验；新版本，旧语法
  1. 打开 打开 CDN.js，搜索 fontawesome
  2. 选择最新版本 7.0.1
  3. 复制样式标签到 html
    4. <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.0.1/css/all.min.css" />
  4. 在结构中使用 <i> 并指定类名；前向兼容，保留了 fa 这个传统类并指定图标名 fa-home 
    5. <i class="fa fa-home"></i>
  5. 按照新规范使用 
    6. <i class="fa-solid fa-home"></i>

免费的图标比较重，有点丑。。。

避免使用 fa 前缀：这是 v4 时代的遗留写法，在 v7 中虽能运行，但可能被未来版本废弃

概述
相比阿里字体图标 Iconfont，FontAwesome 功能更强大；但是字体图标的管理不如 Iconfont
可以指定动画、旋转、颜色和尺寸，还可以下载为 SVG 格式使用，相当给力
Fontawesome 最新版本是 7
Fontawesome 提供

多个家族系列：Classic、Sharp 和 Brands。。。

多个样式：Solid, Regular, Light。。。

普通用户可以免费使用 Classic 系列的 部分样式和 Brands 系列的 brands 样式
其它仅限 Pro 用户使用
更多使用细节，请访问 Fontawesome、Styling with Font Awesome、Fontawesome4.7
样式使用格式约定
分别指定以 fa- 开头的样式类 style class 和图标名类 icon name class
使用 <i> 或 <span> 作为字体容器
fa-family fa-style fa-icon-name
fa-solid 默认为 fa-classic，可以略去 fa-classic
官网 solid 类型图标，显示为 classic-solid
当你写 fa-solid 时，系统会自动将其解析为 fa-classic fa-solid
这种设计是为了向后兼容和简化开发——绝大多数用户使用的都是 Classic 系列，因此无需每次都显式声明 fa-classic
初体验；新版本，新语法
<i class="fa-classic fa-solid fa-home"></i>
// Brands 家族只有这一个样式 brands：写法也是最直接，同时指明了家族和样式
<i class="fa-brands fa-github"></i>

如果只需要使用静态图标，仅仅引入 CSS 样式文件即可

如果需要使用动画，还需要额外引入 js 文件

更多效果
基本使用：
<i class="fa-brands fa-servicestack"></i>
动画：
<i class="fa-brands fa-servicestack fa-beat"></i>
颜色：
<i class="fa-brands fa-servicestack" style="color: #e71352;"></i>
旋转：
<i class="fa-brands fa-servicestack fa-flip-horizontal"></i>
大小：
<i class="fa-brands fa-servicestack fa-xl"></i>

本地使用
以上都是在线使用
本地使用需要下载并引入特定的文件
1. 下载最新版的字体文件并解压
2. 拷贝/webfonts 和 /css 文件夹到项目中
/webfonts：字体图标依赖
/css：免费版除了必要的核心样式文件 fontawesome.css 外，只能使用 brands 样式和 solid 样式，对应的样式文件为 brands.css 和 solid.css，其它样式文件都可以删除 
<link href="/your-path-to-fontawesome/css/fontawesome.css" rel="stylesheet">
<link href="/your-path-to-fontawesome/css/brands.css" rel="stylesheet">
<link href="/your-path-to-fontawesome/css/solid.css" rel="stylesheet">
工具包 kit
Kit 就是 Font Awesome 官方提供的一个专属“个人定制包” - 你自己图标库的后台管理器和专属快递通道
根据自己的项目需求“定制”出来的一个专属工具包，生成后会给你一个独一无二的网址（嵌入代码）
区分：免费和付费；免费版足够用了
在 Fontawesome 官网，注册账号，创建并管理工具包 kit

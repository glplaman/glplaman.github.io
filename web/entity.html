实体

@Entity
除了直接使用对应的符号外 - 依赖输入法的支持，还可以使用符号对应的实体
实体是一段以连字号 & 开头、以分号 ; 结尾的文本/字符串
常用于显示保留字符和不可见的字符、或其他难以用标准键盘键入的字符
可以应用在结构或样式中
更多信息，请访问 MDN - Entity、CSS - entities、Unicode Lookup
Unicode
每个符号，包括实体，都有对应的 Unicode 编码，如 U+0041，表示大写字母 A
U：代表 Unicode
+：表示后面跟着的是十六进制数字
U+XXXX：至少4位十六进制数，不足补零
ASCII
ASCII 是 Unicode 的子集，且编码完全兼容、无冲突
Unicode 的前 128 个码点（U+0000 到 U+007F）与 ASCII 完全一致
ASCII 中的 'A' = 0x41
Unicode 中的 'A' = U+0041 = 0x41

使用

以 @ 符号为例，Unicode 编码为 U+00040
结构中使用
使用实体；只有标准命名实体支持
<span>&commat;</span>
使用十六进制编码；通用性强
<span>&#x40;</span>
使用十进制编码
<span>&#64;</span>
样式中使用
在伪元素中使用 \ 引用
只能使用十六进制编码
不区分大小写；建议使用实际编码大写
ul li::marker {
  content: "\0040";
}

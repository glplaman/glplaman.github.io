动态表格
  • 标题行样式始终保持不变
  • 当鼠标悬停 :hover 时，当前行颜色变化
  • 使用 过渡动画 实现
滚动表格
  • 内容多的情况下，表头始终显示 - 冻结首行
  • 多表格配合使用 - 模拟固定表头表格
  • <tabel>本身并不能实现滚动条，需在<tabel>外面增加一个容器；当<tabel>高度超过容器高度时，让容器出现滚动条
  • 也可以使用 粘性定位实现
  • 现在多使用 分页器 - pager 设计
渐变边框表格
  • 边框不能重叠
  • 表格边框使用 边框图像 border-image 实现
  • 也可以使用 伪元素 实现；对边框重叠没有要求
[] 排序表格
  • 借助 JavaScript 实现
  • 可以是本地数据；也可以通过网络请求数据，如 Fetch
  • 图标由阿里字体图标 Iconfont 实现

实现方案之一
  1. 隐藏表头 <thead>。方法很多；最好不要 none 掉，而应使用定位将其移走
  2. 将 <tr> 显示属性由 table-row（类 inline-block）调整为 block，以便独占一行
  3. 将 <td> 显示属性由 table-cell（类 inline-block）调整为 block，从而将数据由一行展示改为多行展示
  4. 设置 <td> 为相对定位，并保持左侧50%的 padding，预留给其伪元素；或使用 弹性盒子
  5. 为每个 <td> 设置不同的伪元素 ::before 内容，和隐藏的表头内容相对应；可以单独指定或使用 自定义数据 data-
  6. 根据需要指定行和单元格的其它样式，如边框、背景色(略)
  7. 其它布局应根据实际情况具体分析

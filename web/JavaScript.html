Introduction
布兰登艾奇 Brandon Eich 于1995年5月，利用10天开发出 JavaScript 语言
单线程、客户端脚本、解释性语言，由浏览器解释执行；浏览器本身不会执行 JavaScript，而是通过内置的JS引擎/解释器逐行解释并执行 JavaScript
区分大小写 - Case Sensitivity
每条语句以 分号; 结束[非强制性，但是建议]
三大部分：ECMAScript 规范 、DOM - 文档对象模型 Document Object Model 和 BOM-浏览器对象模型 Browser Object Model
JavaScript = ECMAScript + DOM + BOM
ECMA Script，简称 ES；现在已发展到ES14
快速上手，请访问 fadocodecamp - javascript

Usage

Inline
写在元素上，仅适用 当前元素；通常只用于简单的逻辑
不符合结构 - 样式 - 行为三分离的原则，原生开发使用较少；框架中应用较多，如 React.js
<div onclick="alert('hi')">click me</div>
Internal
写在页面的 <script> 内
仅适用 当前页面，不便于逻辑共享
<div onclick="fn()">click me</div>
<script>
  function fn() {
    alert('hi');
  }
</script>
如果 JavaScript 需要操作元素，为保证元素已就绪，通常将 <script> 放在 <body> 的最后面
<body>
  // ...
  <script>
    // ...
  </script>
</body>
也可以写在 onload 函数中，此时脚本可以放在页面任何地方
<script>
  window.onload=function(){
    // ...
  }
</script>
External
将业务逻辑放在单独的 JavaScript 文件中，后缀名是 .js；使用 <script> 的 src 属性引入[]
便于共享逻辑
库文件都是以外部 JavaScript 的形式引入，可以服务于多个项目|页面|模块
可以 缓存 到本地，加快页面访问速度
大部分都放在 <body> 最后面；有些 <script> 引入需要放在头部 <head>，如设置字体
<body>
  // ...
  <script src="./tmp.js"></script>
</body>

动画自定义属性

@Property
某些复合属性无法直接使用
定义某个 CSS 属性以便参与动画运算
@property --deg {
  syntax: "<angle>";
  initial-value: 0deg;
  inherits: false;
}
创建动画
@keyframes scroll {
  from {
    --deg: 0deg
  }

  to {
    --deg: 360deg
  }
}
使用动画
.box {
  width: 300px;
  height: 200px;
  background-image: conic-gradient(from var(--deg), red, yellow, blue);
  animation: scroll 1s linear infinite;
}

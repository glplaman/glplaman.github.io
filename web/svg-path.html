路径绘制

@path
SVG 基本形状中最强大的一个
通用绘图工具 - generic element to define a shape
可以创建线条、曲线、弧形等基本图形 - the basic shapes
通过属性 d 定义：命令 + 参数的序列
每个命令以字母开头，后跟数字参数
命令可以是绝对定位（大写字母）或相对定位（小写字母）
路径使用 M 开始，Z 结束闭合；M 表示 Move To

直线命令 (L, H, V, Z)

Line Commands
L - Line To
绘制一条从当前点到指定点的直线
绝对：L x y
相对：l dx dy
H - Horizontal Line To
绘制水平线到指定 X 坐标
绝对：H x
相对：h dx
V - Vertical Line To
绘制垂直线到指定 Y 坐标
绝对：V y
相对：v dy
Z - Close Path
从当前点画一条直线回到路径起点
无参数，常用于闭合多边形

三次贝塞尔曲线 (C, S)

Cubic Bezier Curves
C - Cubic Bezier Curve
三次贝塞尔曲线
使用两个控制点定义曲线
绝对：C cx1, cy1, cx2, cy2, x, y
相对：c dx1, dy1, dx2, dy2, dx, dy
S - Smooth Cubic Bezier Curve
平滑三次贝塞尔曲线
简化版 C，自动计算第一个控制点
仅当上一段是 C 或 S 时才有效
绝对：S cx2, cy2, x, y
相对：s dx2, dy2, dx, dy

二次贝塞尔曲线 (Q, T)

Quadratic Bezier Curves
Q - Quadratic Bezier Curve
二次贝塞尔曲线
使用一个控制点定义曲线
绝对：Q cx, cy, x, y
相对：q dx, dy, dx, dy
T - Smooth Quadratic Bezier Curve
平滑二次贝塞尔曲线
简化版 Q，自动计算控制点
仅当上一段是 Q 或 T 时才有效
绝对：T x, y
相对：t dx, dy

圆弧 (A)

椭圆弧 Arcs
A - Elliptical Arc
在当前位置和坐标 x,y 之间绘制一条椭圆曲线

如何在椭圆上选取部分圆弧

绝对：A rx, ry, x-axis-rotation, large-arc-flag, sweep-flag, x, y
相对：a rx, ry, x-axis-rotation, large-arc-flag, sweep-flag, dx, dy
A
item desc
rx,ry 椭圆的 x 轴y 轴半径
x-axis-rotation 椭圆相对于 x 轴的旋转角度；椭圆的x轴方向不再平行于坐标x轴
large-arc-flag 0=短弧，1=长弧
sweep-flag 0=逆时针，1=顺时针
x, y 终点坐标
[] 绘制爱心

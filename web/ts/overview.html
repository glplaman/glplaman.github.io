Deployment
install
npm i -g typescript
check version
tsc -v
Version 6.0.3
compile
tsc filename.ts
编译配置 tsconfig.json
include：编译的源文件位于哪里；可以简单粗暴指定 src
"include": ["src"]
完整配置如下
{
  "compilerOptions": {
    "target": "es6",
    "module": "commonjs",
    "strict": true,
    "outDir": "dist",
    "skipLibCheck": true
  },
  "include": ["src/**/*.ts"]
}

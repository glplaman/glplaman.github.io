锥向渐变

@conic-gradient
角度渐变
适合做圆锥图/饼状图
默认从 0/12点 方向开始；可以使用 from 指定起始位置
默认从容器中心 center 绘制；可以使用 at x y 指定绘制位置
可以使用度 deg 或百分比 %
使用 0 表示从前面部分结束的位置开始
更多信息，请访问 MDN - conic-gradient
background-image:
  conic-gradient([from angle] [at position,] color degree, color degree, ...);
示例 Demo
1. 默认 0 - 360deg
background-image: 
  conic-gradient(#f1f2f3, #1393c7);
2. 划分1个区域：0-60deg
background-image:
  conic-gradient(#1393c7 60deg, #f1f2f3 0);
3. 划分3个区域：0-40deg、40-120deg、120-360deg
第2个色块的 0 表示前一个值 40deg
第3个色块的 0 表示前一个值 120deg；因为它是最后一个，可以省略，表示到 360deg
background-image: 
  conic-gradient(
    #1393c7 40deg, 
    #890 0 120deg, 
    #f1f2f3 0);

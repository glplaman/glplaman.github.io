媒体查询案例

@Cases
样式需求
设置全局字体大小
桌面端初始化为 1rem=10px，即 62.5%
移动端调整为 55%
不需要再为 body 指定大小
html {
  font-size: 62.5%;
}
@media screen and (max-width: 768px) {
  html {
    font-size: 55%;
  }
}
画廊
内部样式
默认是大屏，>1200px，显式4列
≤1200px，显式3列
≤992px，显式2列
≤768px，显式1列

  <img src="./imgs/1.jpg" alt="">

方案1：使用 grid 实现 - 桌面优先
.wrap {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 1rem;
}

@media screen and (max-width: 1200px) {
  .wrap {
    grid-template-columns: repeat(3, 1fr);
  }
}

@media screen and (max-width: 992px) {
  .wrap {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media screen and (max-width: 768px) {
  .wrap {
    grid-template-columns: repeat(1, 1fr);
  }
}
方案 2：使用 % 实现 - 移动优先；采用了 float，记得清除浮动
.wrap img {
  float: left;
  width: 100%;
  aspect-ratio: 16/9;
}

@media (min-width:768px) {
  .wrap img {
    width: 50%;
  }
}

@media (min-width:992px) {
  .wrap img {
    width: 33.3%;
  }
}

@media (min-width:1200px) {
  .wrap img {
    width: 25%;
  }
}
其它方案：请参考 grid 万能的自适应布局 gird 布局
汉堡菜单1、汉堡菜单2、汉堡菜单3
主导航nav、logo、和 ham
传统方式下：大尺寸下，只显示 nav 和 logo，隐藏 ham；小尺寸时，再显示 ham
改进：大尺寸下，ham 的h5指定结构但是内容为空，小尺寸下才设计 ham 的具体内容，这样就不需要先隐藏再显示。适合开始弹性布局的 flex-start 和结束 flex-end
如果使用 space-between 则0元素也会被分隔 [好大的坑！！！]
功能需求
面向桌面端；移动端没有 hover；且100vh默认是包含底部操作栏
@media (hover: hover) {
  body{
    height: 100vh;
  }
  a:hover {
    color: #f40;
  }
}
分页打印表格
建议使用容器包裹表格
@media print {
  table {
    break-before: page;
    break-after: page;
  }
}
标签和媒体查询的使用
小尺寸时使用普通小图；大尺寸时，使用高清大图
体会 <picture>、<img> 和 background-image 的特点
  1. <picture> - 组合标签；指定不同的备选图片以适应不同的设备；如果都不满足就使用 <img> 指定的内容
    2. <picture>
  <source srcset="https://picsum.photos/400/300?random=0" media="(max-width:768px)">
  <img src="https://picsum.photos/800/600?random=0" alt="">
</picture>
  2. <link> - 使用属性preload 实现预加载 - preload
    3. <link
  rel="preload"
  href="bg-image-narrow.png"
  as="image"
  media="(max-width: 600px)" />

<link
  rel="preload"
  href="bg-image-wide.png"
  as="image"
  media="(min-width: 601px)" />

<link rel="stylesheet" href="main.css" />
